# 术语名称的最小修订

只供程序确认术语长度是唯一阻断时调用。普通整稿及其他局部修订继续使用原协议。

```text
你在修订论文《{title}》（{arxivId}）的术语名称。下面是当前唯一检查问题、获准修改的原术语、已有解释和原文证据。

{validationFeedback}

获准术语：
{termsTargets}

已有解释只帮助理解，不得改写：
{explanationContext}

逐字原文证据：
{sourceQuotes}

只给获准术语补上它实际指代的概念，使每项去除首尾空白后为2–48个字符。单字母符号保留原符号，例如用准确的概念名称说明它的含义；根据本篇原文判断，不能凭一般经验猜测。保留数学含义。不要改解释、正文、图表、其他术语或任何来源字段。

只返回JSON，不加说明：{"version":1,"draftSha256":"所给原稿SHA","termReplacements":[{"path":"所给terms叶路径","oldSha256":"所给原术语SHA","value":"修订后的术语"}]}。每个获准路径恰好一次，path与SHA照抄。不返回完整小节、整组术语解释或全文。
```
