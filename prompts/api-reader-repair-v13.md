# 论文解读的按目标局部修复

~~~
修复论文解读中明确列出的错误，只输出获准修改项。正确事实、数字单位、方法归属、比较条件、原文引文及已有标记保持准确。正文只讲论文，不复制检查要求。术语组合可以包含2–4个不同概念，各项为2–48字符，解释全部概念的分工、搭配原因和新增作用。
用平和朴实的中文说明具体对象和处理过程，不写宣传语，不生硬直译。critic 按实际任务称为价值评估模型或辅助分数模型；FID 保留原名并解释它比较的特征分布，patch FID 说明是在图像块上计算。只使用原文涉及的概念，不能把这些写作规则抄入正文。
在本次获准目标内，把读者缺少的解释补清：概念处理什么对象，前一步产生什么、怎样进入下一步，公式中的关键运算起什么作用，比较条件和指标含义是什么。以当前错误和原文证据为限，不补造维度、梯度、数值、消融或因果，不改无关正确解释。术语和符号沿用本篇已核准的含义，原表、公式、标记、引用及来源字段保持原协议约束。
正文或解释目标包含多个自然段时，每段说明一个问题，段间留一行空白，JSON 字符串用合法 \n\n 转义。转到新步骤或不同证据再分段，不机械重复句首和总结。术语叶子、原句等窄目标不得借此扩写成段落或越过授权；章节、表格、公式和图片的数量及位置只按本轮明确操作协议修改。
表格修正须保留真实方法、条件、指标、单位及对应数值，按原表真实列数呈现，不为固定宽度补解释列。禁止把引文中的任意数字或参考文献编号、年份、页码拼成“来源证据／来源句一／量化值一”占位结果表；sourceQuotes 须对应实际实验的条件、方法、指标和原结果，逐字数字存在不代表结果归属成立。它只核验来源，不生成或搬动表格，也不能靠几个相同数字选择原表。只在已授权正文及绑定节点内按同一原表或完整连续结果句恢复语义行列，缺证据时保留失败，不补造对应关系。

{validationFeedback}

{repairTargets}

{"version":1,"draftSha256":"复制本次草稿SHA","replacements":[{"path":"复制授权路径","oldSha256":"复制该目标SHA","value":"修复后的完整目标值"}]}
只提交1–8个授权目标，目标类型保持一致，父子路径不同时修改。修改后必须实际消除当前问题；不要逐字回传仍有错误的旧值。其他字段由程序保留。正文目标回传完整正文，术语解释目标回传完整对象，数组数量只在本轮明确授权时才可改变。来源证据不足时不能补造事实，也不能用占位文字或重复内容凑长度。

{operationProtocol}
