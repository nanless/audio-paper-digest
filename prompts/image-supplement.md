# 选择论文插图并补充读图说明

## 用途

双模型模式专用：主模型先完成最终纯文本分析，副模型（多模态）只查看候选论文图片并生成结构化插图计划。副模型不重写完整分析，不修改评分、摘要、标签或评分理由。

## 调用方式

代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{arxivId}` → arXiv ID
- `{imageList}` → 论文图片列表（编号、URL、图注）
- `{anchorCatalog}` → 代码生成的稳定段落 ID、章节和段落预览
- `{primaryAnalysis}` → 主模型输出的完整分析（Markdown 格式）

## 选图与插入位置

只解释本次实际收到的图片。仅有图注而没有像素时，不猜坐标轴、颜色、曲线或模块位置。

逐张查看候选图片，优先选择与论文内容密切相关的流程图、模型或系统架构图、模块图、语谱图、波形图、实验结果、消融、对比和可视化分析图。排除标志、页眉页脚、作者照片、装饰图、重复图、截断或不可读的图、没有本篇信息的通用示意图，以及与正文主题无明显关系的图。

最多选择 4 张，按信息价值从高到低排列 `insertions`。只保留有用且互不重复的图片，可以少选或不选。插入章节仅限 `核心摘要`、`方法概述和架构`、`核心创新点`、`实验结果`、`细节详述`。

## 图前与图后说明

`lead` 是图前的一句说明。承接 `paragraph_id` 对应段落的具体内容，复用其中至少一个论文特有术语，并提出明确的读图任务，如核对某条分支、比较两条曲线或追踪输入到输出。`conclusion_paragraph_id` 指向同节中不早于插入点的段落，作为图后解释所联系的后续论证或结论。

`explanation` 用图后的一到两句说明实际可见的结构、曲线、色块、样例或对照，再联系 `conclusion_paragraph_id` 的具体结论及适用条件，并复用该段至少一个论文特有术语。说明范围时写清本图的对象和设置，如“这条曲线只覆盖 LibriSpeech test-clean 的 WER，不说明流式延迟”。不要套用“逐项对照”“不代表额外阶段”“不替代未报告配置”“只支持对应设置、不能外推”等通用免责声明。

本步骤不能改写、替换或删除已有文本，也不能修改评分、机器摘要、标签、作者与机构、`毒舌点评`、评分理由、局限与问题、开源详情。不要输出 `replacement`、`rewrite` 或其他替换字段，代码会忽略这些字段。图片与文字分析冲突时，仍不能改动原有结论；只能在 `explanation` 中谨慎说明图中可见的补充信息，避免据此推翻已有分析的结论。

精确数量、比例、名次、技术计数和参数都使用阿拉伯数字，中文与 ASCII 技术词之间保留空格。句子要自然完整，避免重复词、重复连接和分号拼接的残句。检查重复字时，不要把“具有有限”“具有有界”“功能能否”“性能能够”等正常结构误改成病句。

## 输出格式

只输出一个 JSON 对象，不要 Markdown，不要代码块，不要解释。以下只示意字段格式。图中的分支、融合位置和训练信息必须以本次实际图片及相邻段落为准，不能照抄示例：

{
  "insertions": [
    {
      "image": 1,
      "section": "方法概述和架构",
      "paragraph_id": "s2p3",
      "conclusion_paragraph_id": "s2p4",
      "lead": "声学编码与语义编码在前面的步骤中分别处理输入，沿下图的两条箭头可以查看它们在哪里开始共享上下文。",
      "explanation": "下图的两路箭头在跨模态融合块汇合，随后进入任务头。这一连接说明了本节介绍的融合顺序，图中没有提供训练损失的细节。"
    }
  ]
}

字段规则：
- `image` 必须是候选编号数字，仅用于引用本次输入中的候选图片。候选编号不是论文原始 Figure 编号，不能据此推断正文中的“图N/Figure N”。
- `section` 必须是允许章节之一。
- `paragraph_id` 必须从“可选插入位置”原样选择，并且所属章节必须与 `section` 一致。不要输出自由文本 `anchor`；代码会按段落 ID 精确定位，非法 ID 会被拒绝且不会回退到章节末尾。
- `conclusion_paragraph_id` 也必须来自同一章节，且在目录顺序中不得早于 `paragraph_id`。代码会检查 `lead` 与插入点段落、`explanation` 与结论段是否共享论文特有术语；不能联系前后论证的插图会被拒绝。
- `lead` 和 `explanation` 引用当前图片时统一写“下图”，不要写候选编号“图1/图2/Figure 1”；代码会按最终正文出现顺序生成展示编号。
- `lead` 和 `explanation` 必须是中文，且只包含图像相关说明。
- 如果没有任何图片值得插入，输出 `{"insertions":[]}`。
