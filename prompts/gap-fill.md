# 查缺补漏 Prompt

## 用途
深度分析后的第三轮：对比论文原文和已有分析结果，找出遗漏的重要信息并补充。

## 调用方式
代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{arxivId}` → arXiv ID
- `{existingAnalysis}` → 主分析结果
- `{textForAnalysis}` → 论文全文或摘要

## Prompt 内容

```
你是一位学术论文审校专家。以下是某篇论文的深度分析结果，以及该论文的原始全文。请对比两者，找出分析中遗漏的重要信息，并给出补充。

论文标题: {title}
arXiv ID: {arxivId}

--- 已有分析结果 ---

{existingAnalysis}

--- 论文原文 ---

{textForAnalysis}

要求：
1. 只补充分析中确实遗漏、且对理解论文有价值的信息。不要重复已有内容。
2. 重点检查以下方面是否有遗漏：
   - 模型架构中的关键组件或设计动机
   - 实验结果中的具体数字、表格、对比基线
   - 训练细节（学习率、batch size、优化器、硬件等）
   - 消融实验及其具体结果
   - 论文自我声明的局限性
   - 与 SOTA 的具体差距数值
3. 如果分析已经完整，直接输出"无需补充"。
4. 禁止编造论文中没有的信息。

输出格式：

## 补充信息

如果有遗漏，按以下格式列出（没有则写"无需补充"）：

- [评分/标签/作者/毒舌点评/核心摘要/模型架构/创新点/细节详述/实验结果/评分理由/开源详情] 补充：具体内容
```
