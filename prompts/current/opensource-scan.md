# 提取论文中的开源与复现信息

## 用途
深度分析之后的第二轮，专门扫描论文里的开源链接和复现信息，补全第一轮可能漏掉的具体 URL。

## 调用方式
代码读取这个文件后，把占位符替换成实际值：
- `{title}` → 论文标题
- `{arxivId}` → arXiv ID
- `{textForAnalysis}` → 论文全文或摘要

## 提示词内容

```
请阅读文末 `<paper_input>` 中的论文，提取代码、模型权重、数据集、在线演示和复现材料的具体信息。

请分别列出论文第一方发布的代码仓库、模型权重、数据集、在线演示和复现材料的具体 URL 或获取方式（含原文披露的开源协议，如 MIT/Apache-2.0/CC-BY-NC），项目主页、GitHub、GitLab、HuggingFace、ModelScope 等一并提取；论文引用的第三方开源基线或工具单列在最后一项，严禁混入第一方资源行。若论文仅承诺“未来开源”或仅放演示页而无代码仓库，须如实写明，不把演示页或第三方依赖当成已开源代码；某类信息未提及则明确写“论文中未提及”。

只逐字复制当前论文证据中真实出现的 HTTPS URL，不补全地址、不改写域名、不凭项目名猜测仓库地址，也不声称“可访问/返回 200/已验证”（网络可用性与重定向由代码后续核验）。若正文中出现通用平台首页链接（如泛播客或泛官网首页，非具体论文资源），不要列入论文开源资源。

精确版本、参数规模、文件数、设备数和资源成本都用阿拉伯数字，中文与由英文字母组成的技术词之间保留空格。各项说明写成自然、完整的句子，不要重复用词或连接，也不要用分号把残句拼起来。

输出格式（严格按以下格式，不要增删一级标题）：

## 开源详情
- 代码：（具体仓库链接，如 https://github.com/xxx/xxx；若论文中未给出明确链接则写"论文中未提及代码链接"）
- 模型权重：（具体 HuggingFace/ModelScope 链接或"论文中未提及"）
- 数据集：（具体名称、获取链接或开源协议；若未提及则写"论文中未提及"）
- Demo：（在线演示链接或"论文中未提及"）
- 复现材料：（训练配置、检查点、附录等具体信息，或"论文中未提及"）
- 论文中引用的开源项目：（列出具体项目名和链接，没有则写"未提及"）

<paper_input>
论文标题: {title}
arXiv ID: {arxivId}

{textForAnalysis}
</paper_input>
```
