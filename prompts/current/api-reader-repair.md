# 论文解读的按目标局部修复

~~~
修复论文解读中明确列出的错误，只输出获准修改项。正确事实、数字单位、方法归属、比较条件、原文引文及已有标记保持准确；正文只讲论文，不复制检查要求。术语组合含 2–4 个不同概念（各项 2–48 字符），解释全部分工、搭配原因与新增作用。

### 一、中文表达、术语与排版规范
- **自然术语与标准缩写**：用平和朴实的中文说明对象与处理过程，不写宣传语、不生硬直译（`nuisance parameter` 译为“干扰参数/无关参数”而非“讨厌参数”；保留 ViSQOL、STOI、PESQ、WER、CER、MOS、RTF、GPU、CPU、FFT、MDCT 等标准指标与硬件原名并首次括号解释，不把 ViSQOL 译成“虚拟语音质量客观听众”；`logit` 译为“对数几率”而非“对数值”；`critic` 按任务称“价值评估模型”或“辅助分数模型”，不译成“评论家/评论更新/评论与学生”）。
- **禁用中英夹杂与校验口癖**：严禁在中文正文或标题夹杂裸英文普通词（如 alone、over、abstain、noisy、without、embodied、grounding、pending、backchannel、scaling、alignment、rollout、tradeoff、lookahead、pipeline、baseline 等），严禁使用“记住这个顺序”“务必记住”“不要忘记”等说教口吻、模板化校验套话（“这张图确实可见/从像素可见/比较问题是：/这张表支撑的判断是/本表数值与单位依据论文 PDF”）及提示词核验口癖（“该式的三层含义/可分三层理解/三层读法/怎样进入下一步/可写作者/本次核验返回 200/资源清单未标明”）。
- **数字与空格规范**：中英文及阿拉伯数字之间留一个半角空格（如“185 个样本”“35B-A3B”“84.0%”）；数学专名及自然中文序数、逐指词、构词短语保留纯正汉字（最小二乘、一阶/二阶、二维频谱、一对一、置信区间半宽、第一个/第二步、每一帧/每一维、两阶段/三阶段、两段式、哪一帧/两者/任何一级，绝不写成“最小 2 乘/1/2 宽/第 3 个/每 1 帧/2 者之间/哪 1 帧”）。

### 二、获准目标内的解释与结构约束
- **实质补清、杜绝注水**：在获准目标内补清概念对象、模块数据与因果衔接、公式背后的数学动机/极端取值行为/下游作用（行内数学用 `\(...\)`，不顺着符号硬念绕口令）及比较条件与指标含义。扩写只能补充原文未展开的机制、条件或实验细节，不换词重复已有规模/步骤，不套用“……为何……”“前一步……后一步……”凑字数；不补造维度、梯度、数值、消融或因果，不硬塞“建议做网格搜索”，不改无关正确内容，沿用本篇已核准术语符号与来源协议。
- **段落、标题与专有字段**：多段目标保持 120–320 汉字（硬上限 420 字），散文超过 950 汉字的小节须使用 `####` 子标题或结构化列表（至少 2 项）建立层次，段间留空行（JSON 字符串用合法 \n\n 转义），不遇分号或两三句就碎切，不重复句首或段尾免责句；窄目标不得越权扩段。任何标题不得含“图 1/Figure 1/表 1/Table 1”，且不得连续 3 节及以上套用“问题本质：/方法全景：/核心机制：/主实验验证：”等模板化前缀。`figurePlacements` 的 `chineseCaption` 为 12–120 字单行自然中文图注（不含“图 N / Figure N”前缀）并保持图-节语义就位；`implementationSpecs` 保留六个必填单行纯文本来源核实字段（`trainingData`/`computeHardware`/`keyHyperparams`/`inferenceCost`/`openSourceArtifacts`/`appendixHighlights`）及可选 `audioSignalSpecs`（无换行/Markdown/HTML/核验话术，行内公式用 `\(...\)`，无训练阶段标明无模型训练阶段，真正缺失再写“原文未披露”）。章节、表格、公式和图片的数量及位置仅按本轮明确操作协议修改。

### 三、表格、极值与图表像素核对
- **极值与图表核验**：声称表内“最优/最低/最高/第一/SOTA”前，逐格核对同表同列全部可比行及指标方向（`↑/↓`），绝不颠倒方向或误报非最优；描述图例颜色、柱体实心或斜纹填充（如 p <= 0.05 实心与 p > 0.05 斜纹）及子图轴向时，用“全部”“所有”“只有”“唯一”前须逐组核对无例外，不混淆条件、图例颜色与方法行名。
- **表格来源与防重复**：保留真实方法、条件、指标、单位与数值，按原表真实列数呈现，不为宽表补解释列；同一原表（相同 `sourceTableOrdinal`）不得重复展示相同完整表或数据格重合 >= 50% 的重叠子集，严禁把消融表冒充主结果表放进 `result` 小节（主结果原表 DOM 不可编译时改用 `source_quotes` 构建主结果表）；使用 `selection` 时 `sourceRows[0]` 须为含具体指标列名的真实表头行（不选空列分隔行），表前后表述与实际行列数一致，不对精简子表宣称“列出全部 N 项”；表后评述提炼跨行规律、代价权衡与未胜出项而非逐行复述。
- **`source_quotes` 严审**：严禁把任意数字或参考文献编号、年份、页码拼成占位表；`sourceQuotes` 须对应实际实验条件、方法、指标与原结果（逐字数字存在不代表归属成立，也不靠相同数字选原表），仅在授权正文与绑定节点内按同一原表或完整连续结果句恢复行列，缺证据时保留失败。列头单位（如 `%`、`s`、`GiB`）须在对应来源行有逐字单位证据，原文裸数字时优先绑原表或不在列头硬加括号单位符号；守住最低表数要求（可用原表不少于 4 张时至少保留 4 张表），每表紧邻评述只对应本表。

### 四、输出 JSON 结构与补丁规则
没有明确的原子操作时，只输出下面的JSON结构，不输出完整文章：

只提交1–8个授权目标，目标类型保持一致，父子路径不同时修改。修改后必须实际消除当前问题；不要逐字回传仍有错误的旧值。其他字段由程序保留。正文目标回传完整正文，术语解释目标回传完整对象，数组数量只在本轮明确授权时才可改变。来源证据不足时不能补造事实，也不能用占位文字或重复内容凑长度。
