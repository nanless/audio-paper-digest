# 筛选 Prompt — 判断论文是否与语音/音频相关

## 用途
用于 LLM 筛选阶段，判断单篇论文是否与语音、音频、声音处理相关。

## 调用方式
代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{abstract}` → 论文摘要

## Prompt 内容

```
请根据以下论文标题和摘要判断该论文是否与语音、音频、声音处理相关。

论文标题：{title}
论文摘要：{abstract}

判断标准（必须同时满足才算"是"）：
1. 论文的核心任务、核心方法或核心数据集必须与语音（speech）或音频（audio）信号直接相关。
2. 如果论文声称"多模态"，但语音/音频只是作为可选输入或边缘评测维度，而非核心研究对象 → 否。
3. 如果论文研究的是通用机器学习理论、通用大语言模型（LLM）评测、通用计算机视觉方法，仅在实验部分附带了一个语音/音频数据集作为辅助验证 → 否。

明确排除（直接判"否"）：
- 纯自然语言处理：意图理解、文本分类、机器翻译、文本生成、问答系统、知识图谱
- 纯计算机视觉：图像分类、目标检测、图像生成、视频理解（无音频核心贡献）
- 通用大模型评测：除非评测任务明确包含语音/音频理解或生成，否则仅因模型"支持多模态"而评测文本能力 → 否
- 通用机器学习理论：优化理论、神经网络缩放定律、等变网络数学框架等，除非论文核心贡献专门针对语音/音频信号特性
- 机器人/强化学习：除非语音/音频感知是机器人决策的核心输入之一
- 手势生成/动作生成：除非手势/动作是由语音/音频直接驱动且论文核心研究的是跨模态语音-动作映射，而非单纯的动作合成

边界案例示例：
- ✅ "基于语音的手势生成" — 核心输入是语音，输出是手势，研究的是语音到动作的映射 → 是
- ✅ "音视频联合生成模型评测" — 音频是核心评测对象之一 → 是
- ❌ "大语言模型意图理解基准测试" — 纯文本NLP任务，与语音无关 → 否
- ❌ "意大利语大语言模型性能评测" — 评测对象是文本LLM，无语音任务 → 否
- ❌ "神经网络缩放定律的跨模态验证" — 通用ML理论，语音只是验证模态之一 → 否
- ❌ "等变群论神经网络工具库" — 通用数学/ML工具，无语音特化 → 否

请只回答 "是" 或 "否"，不要解释。
```

## 输出要求
模型只应回答 "是" 或 "否"，代码通过匹配 "是"/"yes"/"y" 或 "否"/"no"/"n" 来判断。
