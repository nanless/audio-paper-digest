# 筛选与语音、音乐或音频相关的论文

## 用途
用于 LLM 筛选阶段，判断单篇论文是否与语音、音频或音乐处理相关。

## 调用方式
代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{abstract}` → 论文摘要
- `{categories}` → arXiv 类别（如 cs.SD, eess.AS, cs.CL 等，逗号分隔）

## 提示词内容

```
请判断以下论文是否与语音、音频或音乐处理相关。

论文标题：{title}
论文摘要：{abstract}
arXiv 类别：{categories}

论文满足以下任意一项时，判为“相关”：
1. 核心任务是语音、音乐或音频处理，如语音识别（ASR）、语音合成（TTS）、语音增强、语音分离、语音转换、声源定位、音频分类、音频事件检测、音乐生成或理解。
2. 核心任务与说话人有关，如说话人识别、验证、分割、声纹识别、语音情感识别或语音属性识别。
3. 研究多模态模型或系统，语音或音频作为输入、输出、训练目标、评测维度或核心能力之一。
4. 研究语音、音乐或音频信号的表示学习、特征提取、编解码或预训练模型。

以下情况判为“不相关”：
- 纯自然语言处理，如意图理解、文本分类、机器翻译、文本生成、问答或知识图谱。即使模型名称含有“multimodal”，摘要完全没有涉及语音、音乐或音频时也不纳入。
- 纯计算机视觉，如图像分类、目标检测、图像生成或视频理解。只有明确将视频中的音频作为研究核心时才纳入。
- 仅评测文本能力的通用大语言模型论文，如只使用 MMLU、GSM8K 或 HumanEval 的研究。声称模型支持多模态，不能代替实际的语音、音乐或音频评测。
- 通用机器学习理论，如优化理论、神经网络缩放定律或等变网络的数学框架。只有核心贡献专门针对语音、音乐或音频信号特性时才纳入。

arXiv 类别可以辅助判断。`cs.SD`（Sound）和 `eess.AS`（Audio and Speech Processing）通常高度相关；`cs.CL`（Computation and Language）、`cs.CV`（Computer Vision）和 `cs.LG`（Machine Learning）则须结合标题与摘要判断，它们也可能分别属于纯文本、纯视觉或通用机器学习理论研究。

输出以下两行，不增加其他内容。“结论”只能填写“相关”或“不相关”：

理由：[1-2句话说明判断依据]
结论：[相关/不相关]

示例1：
理由：该论文研究语音合成，核心任务是音频生成，与语音直接相关。
结论：相关

示例2：
理由：该论文是纯文本分类，摘要中未提及任何语音或音频内容。
结论：不相关

示例3：
理由：该论文评测多模态大模型，语音理解是核心评测维度之一。
结论：相关

示例4：
理由：该论文是通用神经网络缩放定律研究，语音只是验证模态之一，核心贡献不针对语音特性。
结论：不相关

```

## 输出要求
模型必须输出 "结论：相关" 或 "结论：不相关"。代码通过以下优先级解析：
1. JSON 中的 `decision` / `related` / `conclusion` 字段（兼容 `related` / `not_related`）
2. 结构化结论行："结论/判断/是否相关/Conclusion/Judgment/Related：相关|不相关|related|not related"
3. 最后一行是否为 "相关" / "不相关" / "是" / "否" / "related" / "not related"
4. 若以上结构化格式均无法解析，短语命中只作为格式修复的提示，不会直接形成正式决定
5. 格式修复仍无法得到固定结论时，标记为待重试；完整筛选决定未覆盖全部候选前不得把结果标记为 complete

关键词预筛优先避免漏掉相关论文。核心音频类别、摘要少于 80 字符的论文，以及命中音频词族的论文，都必须交给 LLM 判断。即使摘要含有 withdrawn/retracted，核心类别和短摘要也仍按上述规则放行。只有摘要完整、未命中词表且属于补充类别的论文，才能由预筛直接判为不相关。
