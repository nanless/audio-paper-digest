# 筛选 Prompt — 判断论文是否与语音/音频相关

## 用途
用于 LLM 筛选阶段，判断单篇论文是否与语音、音频、声音处理相关。

## 调用方式
代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{abstract}` → 论文摘要

## Prompt 内容

```
请根据以下论文标题和摘要判断该论文是否与语音、音频、声音处理相关。

论文标题：{title}
论文摘要：{abstract}

判断标准：
1. 如果论文主要研究语音合成(TTS)、语音识别(ASR)、语音克隆、语音转换、语音增强、语音分离等语音处理任务 → 是
2. 如果论文主要研究音频生成、音频理解、音乐生成、声音事件检测、音频分类等音频处理任务 → 是
3. 如果论文主要研究说话人识别、说话人验证、说话人分割等说话人相关任务 → 是
4. 如果论文主要研究语音/音频相关的深度学习模型、表示学习、预训练等 → 是
5. 如果是多模态模型，只要明确涉及语音/音频（作为输入、输出、训练目标、评测任务或核心能力之一）→ 是
6. 如果论文主要研究其他领域（如计算机视觉、自然语言处理、强化学习等），且没有实质性的语音/音频方法或任务 → 否

冲突处理（必须遵循）：
- 若同时满足第 5 条和第 6 条，优先按第 5 条判定为"是"。

请只回答 "是" 或 "否"，不要解释。
```

## 输出要求
模型只应回答 "是" 或 "否"，代码通过匹配 "是"/"yes"/"y" 或 "否"/"no"/"n" 来判断。
