# 筛选 Prompt — 判断论文是否与语音/音频相关

## 用途
用于 LLM 筛选阶段，判断单篇论文是否与语音、音频、声音处理相关。

## 调用方式
代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{abstract}` → 论文摘要

## Prompt 内容

```
请根据以下论文标题和摘要判断该论文是否与语音、音频、声音处理相关。

论文标题：{title}
论文摘要：{abstract}

判断标准（满足任意一条即判"是"）：
1. 论文的核心任务是语音/音频处理：语音识别(ASR)、语音合成(TTS)、语音增强、语音分离、语音转换、声源定位、音频分类、音频事件检测、音乐生成/理解、生物声学等 → 是
2. 论文的核心任务是说话人相关：说话人识别、说话人验证、说话人分割、声纹识别、语音情感识别等 → 是
3. 论文研究的是多模态模型/系统，且语音或音频是其中的模态之一（作为输入、输出、训练目标、评测维度或核心能力之一）→ 是
4. 论文研究的是语音/音频信号的表示学习、特征提取、编解码、预训练模型等 → 是

明确排除（直接判"否"）：
- 纯自然语言处理：意图理解、文本分类、机器翻译、文本生成、问答系统、知识图谱——即使模型名称里带"multimodal"但摘要里完全没提语音/音频
- 纯计算机视觉：图像分类、目标检测、图像生成、视频理解——除非明确说明视频中的音频是研究核心
- 通用大语言模型评测：仅评测文本能力（如MMLU、GSM8K、HumanEval等），即使模型声称"多模态"但评测不涉及语音/音频任务 → 否
- 通用机器学习理论：优化理论、神经网络缩放定律、等变网络数学框架等——除非论文核心贡献专门针对语音/音频信号特性

边界案例示例：
- ✅ "基于语音的手势生成" — 语音是核心输入模态 → 是
- ✅ "音视频联合生成模型评测" — 音频是评测对象之一 → 是
- ✅ "多模态大模型语音理解能力分析" — 语音是核心评测维度 → 是
- ❌ "大语言模型意图理解基准测试" — 纯文本NLP任务，摘要中无语音/音频 → 否
- ❌ "意大利语大语言模型性能评测" — 评测文本LLM，无语音任务 → 否
- ❌ "神经网络缩放定律的跨模态验证" — 通用ML理论，语音只是验证模态之一 → 否

请只回答 "是" 或 "否"，不要解释。
```

## 输出要求
模型只应回答 "是" 或 "否"，代码通过匹配 "是"/"yes"/"y" 或 "否"/"no"/"n" 来判断。
