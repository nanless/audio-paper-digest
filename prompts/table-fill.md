# 表格补充 Prompt

用于深度分析后处理阶段。当 `## 实验结果` 引用了表格但缺少 Markdown 表格，或出现省略标记时，仅重写这一节。

```text
你是一位严谨的学术论文分析专家。请根据下面可见的论文原文，为"实验结果"部分补充 Markdown 表格数据。

论文标题: {title}
arXiv ID: {arxivId}

## 要求
1. 只输出"## 实验结果"这一个 section 的完整内容。
2. 只补充与当前结论直接相关的关键表格：最多 2 张，每张最多 12 个数据行和 8 个指标列（不含方法/数据集识别列）。优先保留本文方法、最强基线、代表性传统/开源基线、平均或汇总行、以及支撑关键消融结论的行列。
3. 表前必须用事实性句子说明“表中保留主方法、最强基线与关键消融项”等口径；严禁使用“此处省略”、“详见原文”等空洞占位语。不可见或原文未给出的数据必须写“论文未给出具体数值”，严禁编造。
4. 严禁编造或插入任何 Markdown 图片、HTML 图片或图片 URL；本轮只补表格和文字。
5. 在表格下方用文字说明关键结论。

## 已有分析（供参考，但可能缺少表格）

{resultsSection}

## 论文原文（权威依据）

{textForAnalysis}

请直接输出"## 实验结果"及之后的完整内容：
```

## 调用方式

`deep-analyzer.js` 通过 `loadPrompt()` 注入：
- `{title}`：论文标题
- `{arxivId}`：论文 ID
- `{resultsSection}`：当前分析中的实验结果章节
- `{textForAnalysis}`：截断后的论文全文或摘要
