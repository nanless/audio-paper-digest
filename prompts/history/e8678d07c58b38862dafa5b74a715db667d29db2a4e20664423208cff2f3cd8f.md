# 筛选 Prompt — 判断论文是否与语音/音乐/音频相关

## 用途
用于 LLM 筛选阶段，判断单篇论文是否与语音、音频或音乐处理相关。

## 调用方式
代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{abstract}` → 论文摘要
- `{categories}` → arXiv 类别（如 cs.SD, eess.AS, cs.CL 等，逗号分隔）

## Prompt 内容

```
请判断以下论文是否与语音、音频或音乐处理相关。

论文标题：{title}
论文摘要：{abstract}
arXiv 类别：{categories}

判断标准（满足任意一条即判"相关"）：
1. 论文的核心任务是语音/音乐/音频处理：语音识别(ASR)、语音合成(TTS)、语音增强、语音分离、语音转换、声源定位、音频分类、音频事件检测、音乐生成/理解等
2. 论文的核心任务是说话人相关：说话人识别、说话人验证、说话人分割、声纹识别、语音情感识别、语音属性识别等
3. 论文研究的是多模态模型/系统，且语音或音频是其中的模态之一（作为输入、输出、训练目标、评测维度或核心能力之一）
4. 论文研究的是语音/音乐/音频信号的表示学习、特征提取、编解码、预训练模型等

明确排除（直接判"不相关"）：
- 纯自然语言处理：意图理解、文本分类、机器翻译、文本生成、问答系统、知识图谱——即使模型名称里带"multimodal"但摘要里完全没提语音/音乐/音频
- 纯计算机视觉：图像分类、目标检测、图像生成、视频理解——除非明确说明视频中的音频是研究核心
- 通用大语言模型评测：仅评测文本能力（如MMLU、GSM8K、HumanEval等），即使模型声称"多模态"但评测不涉及语音/音乐/音频任务
- 通用机器学习理论：优化理论、神经网络缩放定律、等变网络数学框架等——除非论文核心贡献专门针对语音/音乐/音频信号特性

辅助参考（arXiv 类别提示）：
- cs.SD (Sound)、eess.AS (Audio and Speech Processing) → 高度相关
- cs.CL (Computation and Language) → 需结合标题/摘要判断，可能是纯 NLP
- cs.CV (Computer Vision) → 需结合标题/摘要判断，可能是纯 CV
- cs.LG (Machine Learning) → 需结合标题/摘要判断，可能是通用 ML 理论

请按以下固定格式输出，不要增删格式：

理由：[1-2句话说明判断依据]
结论：[相关/不相关]

示例1：
理由：该论文研究语音合成，核心任务是音频生成，与语音直接相关。
结论：相关

示例2：
理由：该论文是纯文本分类，摘要中未提及任何语音或音频内容。
结论：不相关

示例3：
理由：该论文评测多模态大模型，语音理解是核心评测维度之一。
结论：相关

示例4：
理由：该论文是通用神经网络缩放定律研究，语音只是验证模态之一，核心贡献不针对语音特性。
结论：不相关

重要：必须输出"结论：相关"或"结论：不相关"。
```

## 输出要求
模型必须输出 "结论：相关" 或 "结论：不相关"。代码通过以下优先级解析：
1. JSON 中的 `decision` / `related` / `conclusion` 字段（兼容 `related` / `not_related`）
2. 结构化结论行："结论/判断/是否相关/Conclusion/Judgment/Related：相关|不相关|related|not related"
3. 最后一行是否为 "相关" / "不相关" / "是" / "否" / "related" / "not related"
4. 若以上结构化格式均无法解析，短语命中只作为格式修复的提示，不会直接形成正式决定
5. 格式修复仍无法得到固定结论时，标记为待重试；完整筛选决定未覆盖全部候选前不得把结果标记为 complete

关键词预筛遵守高召回契约：核心音频类别、摘要少于 80 字符的证据不足项，以及命中音频词族的论文必须交给 LLM。即使摘要包含 withdrawn/retracted，核心类别与短摘要也不得绕过上述放行规则；只有摘要完整且未命中词表的补充类别论文可形成确定性否定决定。
