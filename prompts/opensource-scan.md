# 开源扫描 Prompt

## 用途
深度分析后的第二轮：专门扫描论文中的开源链接和复现信息，补全第一轮可能遗漏的具体 URL。

## 调用方式
代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{arxivId}` → arXiv ID
- `{textForAnalysis}` → 论文全文或摘要

## Prompt 内容

```
你是一位专门扫描学术论文开源信息的专家。请仔细阅读以下论文全文，提取所有与开源、复现、数据集相关的具体信息。

论文标题: {title}
arXiv ID: {arxivId}

{textForAnalysis}

要求：
1. 必须提取具体的 URL 链接（GitHub、HuggingFace、ModelScope、项目主页、Demo 地址等），不要泛泛地说"提供了链接"，要把实际 URL 写出来。
2. 如果论文中确实没有提到某类信息，明确写"论文中未提及"。
3. 模型权重、数据集、代码仓库必须分别列出具体链接或获取方式。
4. 论文中引用的所有第三方开源项目/工具也要列出名称和链接。
5. 禁止编造任何 URL 或信息。
6. `开源详情` 中出现的精确版本、参数规模、文件数、设备数和资源成本一律使用阿拉伯数字；中文与 ASCII 技术词之间保留空格，句子不得出现重复词、双重连接或分号断段。
7. 只能逐字复制当前论文证据中真实出现的 HTTPS URL；不得补全、猜测、改写域名或把项目名称臆测成仓库地址。URL 的网络可用性、重定向终点和安全性由代码另行验证，你不得声称“可访问”“已验证”或根据常识推断资源类型。

输出格式（严格按以下格式，不要增删一级标题）：

## 开源详情
- 代码：（具体仓库链接，如 https://github.com/xxx/xxx；若论文中未给出明确链接则写"论文中未提及代码链接"）
- 模型权重：（具体 HuggingFace/ModelScope 链接或"论文中未提及"）
- 数据集：（具体名称、获取链接或开源协议；若未提及则写"论文中未提及"）
- Demo：（在线演示链接或"论文中未提及"）
- 复现材料：（训练配置、检查点、附录等具体信息，或"论文中未提及"）
- 论文中引用的开源项目：（列出具体项目名和链接，没有则写"未提及"）
```
