# 提取论文中的开源与复现信息

## 用途
深度分析后的第二轮：专门扫描论文中的开源链接和复现信息，补全第一轮可能遗漏的具体 URL。

## 调用方式
代码读取此文件后，将占位符替换为实际值：
- `{title}` → 论文标题
- `{arxivId}` → arXiv ID
- `{textForAnalysis}` → 论文全文或摘要

## 提示词内容

```
请阅读下方论文，提取代码、模型权重、数据集、演示和复现材料的具体信息。

论文标题: {title}
arXiv ID: {arxivId}

{textForAnalysis}

分别列出代码仓库、模型权重和数据集的链接或获取方式，以及项目主页、GitHub、HuggingFace、ModelScope 和 Demo 等资源的具体 URL。论文引用的第三方开源项目或工具也要列出名称与链接，并与本文交付的资源区分。某类信息没有提及，就明确写“论文中未提及”；不要用“提供了链接”代替实际地址，也不要编造信息。

只逐字复制当前论文证据中真实出现的 HTTPS URL。不得补全地址、改写域名，或根据项目名称猜测仓库地址。网络可用性、重定向终点和安全性由代码另行验证，此处不能声称“可访问”或“已验证”，也不能凭常识推断资源类型。

精确版本、参数规模、文件数、设备数和资源成本都使用阿拉伯数字，中文与 ASCII 技术词之间保留空格。各项说明应是自然、完整的句子，避免重复词、重复连接和用分号拼接残句。

输出格式（严格按以下格式，不要增删一级标题）：

## 开源详情
- 代码：（具体仓库链接，如 https://github.com/xxx/xxx；若论文中未给出明确链接则写"论文中未提及代码链接"）
- 模型权重：（具体 HuggingFace/ModelScope 链接或"论文中未提及"）
- 数据集：（具体名称、获取链接或开源协议；若未提及则写"论文中未提及"）
- Demo：（在线演示链接或"论文中未提及"）
- 复现材料：（训练配置、检查点、附录等具体信息，或"论文中未提及"）
- 论文中引用的开源项目：（列出具体项目名和链接，没有则写"未提及"）
```
