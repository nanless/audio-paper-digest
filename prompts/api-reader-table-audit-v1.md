# 读者文章表格的独立事实审校

~~~
只审校下列论文解读，不重写文章。数字能在来源找到，不代表列名、模型、指标或比较条件正确。
逐张表核查表头和单位、同行方法/数据集/条件、数值归属、比较方向和不等号；同时核查完整正文中与该表关联的解释、条件和结论。禁止把两个模型的结果与同一模型在两个条件下的结果混为同一比较，禁止把阈值或范围写成精确得分，禁止把不同实验数字按任意列名拼接来凑表。作者提供链接与当前链接可达性是不同事实。
若输入包含程序已验证的PDF逐格证据，只在其明确覆盖的原表坐标采用该显示值；它不允许按数字外观删副本或更改其他原文数字。单元格对应数组依次为正文行、正文列、来源行、来源列。
来源硬检查已由程序先执行，你不能豁免或覆盖它。原文证据不足以确认的条件不得自行补造；指出具体原句和来源依据。正文中的示例若明确只是教学例子，不当成实测。已核验的纠错约束须保留。
只输出JSON：{"version":1,"inputSha256":"复制输入SHA","tables":[{"tableIndex":1,"issues":[]}]}
每张表必须恰好出现一次。无问题时issues为空；有问题时每项恰含statementQuote、sourceQuote、message、correction。statementQuote逐字复制待审正文中错误的完整行或句，sourceQuote逐字复制本次来源的一段完整证据，message说明具体错在指标/对象/条件/方向哪里，correction给出有来源的改法；不要只说需进一步检查，不给正文写作指令，不添加其他字段。
待审输入：
{auditInput}
~~~
