# 实验表格补充提示词

当 `## 实验结果` 引用了表格却没有提供表格，或用省略标记代替数据时，依据原文重写这一节。

```text
请根据下方可见的论文原文补充实验表格及解释。只输出 `## 实验结果` 及其完整正文。

论文标题：{title}
arXiv ID：{arxivId}

只保留直接支撑当前结论的关键表格，最多 2 张。每张最多 12 个数据行和 8 个指标列，方法、模型和数据集等识别列不计入指标列数。实证论文的表格合计至少有 3 个数据行和 2 个可核对数字。选表时优先保留本文方法、最强基线，以及有代表性的传统或开源基线；平均或汇总行、关键消融和负结果也要保留。原文同时提供主结果与消融或效率证据时，优先各保留一张。

每张表都要有说明方法、数据集或实验设置的识别列。指标有明确优化方向时，在表头标出 `↑/↓`。不要用“结果”“数值”“观察”“说明”“解释”“含义”“方向”或“结论”等叙述型列代替指标。

表前说明具体在比较什么问题、比较条件是什么，以及为什么保留这些方法和消融项。表后解释最关键的差异、原因或代价，并指出证据支持到什么范围。解释要与前后文自然衔接，不逐行复述或重复整张表，也不在每篇文章里套用“关键比较问题是：”这类固定句首。

表格及相邻解释中的精确数量、比例、名次、技术计数和参数都用阿拉伯数字。负号用 ASCII `-`，百分号用半角 `%`，小数保留前导零，例如 `p<0.001`，不能写 `p<.001`。中文与英文字母组成的技术词之间留空格。

这次只补充表格和文字，不插入 Markdown 图片、HTML 图片或图片网址。不可见或原文未给出的数据写“论文未给出具体数值”，不估算或编造。

## 已有实验结果

{resultsSection}

## 论文原文

{textForAnalysis}
```

## 调用方式

`deep-analyzer.js` 通过 `loadPrompt()` 替换 `{title}`、`{arxivId}`、`{resultsSection}` 和 `{textForAnalysis}`。这四项依次是论文标题、论文 ID、已有实验结果和本次可用的论文证据。
