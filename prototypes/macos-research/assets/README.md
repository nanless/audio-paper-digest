# 本机论文样稿

此目录存放原型使用的原始 MiCLA PDF 和 3 张科学图裁图，不纳入 Git。正文及公开元数据在上级 `sample.json` 中，原 PDF 与图的版权仍属于原作者。

原论文：https://arxiv.org/abs/2610.27491v1

PDF：https://arxiv.org/pdf/2610.27491v1.pdf

中文导读：https://nanless.github.io/audio-paper-digest-blog/posts/2026-10-21-micla-mixture-to-constituent-latent-alignment-for-2610-27491/

准备方法见上级 README。准备脚本只读取明确指定的 PDF，不连接网络、不启动论文生产、不修改封存来源。界面会重新核对每份资产的 SHA-256；缺失或内容不符时显示未准备好，不显示完成。
