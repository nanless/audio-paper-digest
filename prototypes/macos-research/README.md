# Mac 论文研究原型

这套可交互原型用于评审 Mac 窗口布局、单栏导读、按需 PDF 双栏、论文列表、个人解析、笔记、后台任务、独立设置与 Zotero 存档。它是本地浏览器运行的桌面界面原型，尚未打包为原生 Mac 应用。

导读、科学图、表格、公式、论文列表和 PDF 都来自真实已发布材料。PDF 直接由 PDF.js 渲染，支持翻页、缩放和实际文字选择；选区回跳绑定已渲染页。模型与 Zotero 保持未连接，不发送 API 请求，不写入文库，不产生虚构解析。

## 打开原型

在本目录执行 `npm start`，打开 `http://127.0.0.1:8766/`。服务只绑定本机。1440 × 900 是设计基准，实际桌面窗口支持调整大小；最低预览宽度为 1000 CSS 像素，不做手机版重排。

当前工作机已准备好真实资产。新检出需要先准备同一份 PDF：

```bash
python3 -m pip install PyMuPDF==1.26.5
python3 prepare_assets.py --pdf /absolute/path/to/2610.27491v1.pdf
```

PDF 公开地址见 [资产说明](assets/README.md)。使用项目已有封存 PDF 时，只把明确路径交给该脚本，源文件保持不变。此入口不联网、不读 `.env`、不扫描内部运行记录。三张图按 `sample.json` 中原 PDF 页码、点坐标和 3 倍倍率重建，每张图与 PDF 都核对预期 SHA；缺失及不符时，界面准确显示未准备好。

## 评审操作

- 默认单栏导读，点击“打开 PDF”显示解释在左、原文在右的工作区；关闭保留阅读位置。
- 拖动分隔线或用方向键调节；原文可翻至 1–13 页、放大、选择文字，回到个人解析时能查看实际选区和页码。
- 图可打开大图并跳到对应 PDF 页；原图注和八维评分可以展开查看。
- 论文库有 15 条真实已发布样本，支持标题、作者、编号搜索以及三种排序。只有 MiCLA 缓存完整正文，其他条目明确提供网站导读链接。
- 收藏、待读和纯文本笔记保存在当前浏览器本地空间；刷新可恢复。保存失败时保留编辑文字并显示错误。
- 通过顶部应用菜单或 `⌘,` 打开非模态设置窗口；窗口可移动，缩窗后仍完整可达。密钥不保存，关闭时清空。
- 任务页面展示当前样稿实检及未连接服务的状态。Zotero 面板展示归档范围和未连接状态，没有模拟成功写入。
- 外观支持跟随系统、浅色与深色；科学图和 PDF 保留原色。

## 测试

首次执行 `npm install --ignore-scripts` 安装固定版本的 Playwright。浏览器可使用本机 Chrome，或按 Playwright 官方说明准备 Chromium。保持预览服务运行，再执行 `npm test`。

测试可通过 `MAC_PROTOTYPE_PLAYWRIGHT` 指定已有 Playwright 模块路径，通过 `MAC_PROTOTYPE_BROWSER` 指定 Chrome 可执行文件，通过 `MAC_PROTOTYPE_URL` 指定本机预览地址。结果和截图写入已忽略的 `.qa/`，使用独立浏览器上下文，不改用户原型中的笔记。

实际验收还需人工查看单栏、双栏、科学图、公式、宽表、资料库、解析、笔记、任务、设置、归档、深色外观与不同桌面尺寸；自动化通过不等于审美检查完成。

## 依赖与数据边界

本机渲染无需 CDN，第三方代码已放在 `vendor/`：PDF.js 5.6.205（Apache-2.0）、Marked 17.0.5（MIT）、Lucide 1.8.0（ISC，部分图标 MIT）。各自许可证一并保留；不是本项目原创代码。

`sample.json` 保存用户已有公开导读、书目、结构化原公式和公开内容指纹，不包含模型配置、API 密钥、费用账、内部请求或完整生产状态。它是界面小样合同，不能冒充全站同步 API。

正式数据接入建议见 [桌面数据合同](../../docs/desktop-data-contract.md)。网站生成、审查与发布规则保持原流程，客户端读取专门导出的已发布快照。
