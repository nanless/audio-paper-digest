# 论文速递工作台：安全与资料保护

Mac 和 Android 客户端统一称为“论文速递工作台”；项目和网站仍叫“论文速递”。应用标识、密钥服务和资料目录保持不变，Android 沿用原发行签名。同签名正式版本覆盖升级时保留原有资料。

2026-10-29 对源码、历史记录及安装附件的检查未发现项目生产凭据或签名私钥。当前保护措施包括请求错误脱敏、认证请求拒绝自动重定向、发行包的私人资料排除，以及备份和同步的本机密钥保护。

## 版本与设备范围

| 客户端 | 版本与系统要求 | 签名与设备覆盖 |
|---|---|---|
| Mac | 1.0.1，构建号1；Apple Silicon（arm64），macOS 15及以上；内置Node 24.19.0 | 本地签名，未经过Apple公证 |

安装、配置及格式支持见[Mac说明](../apps/macos/README.md)和[Android说明](../apps/android/README.md)。下载入口为[项目发行页](https://github.com/nanless/audio-paper-digest/releases)；每个版本的构建信息、来源清单和SHA-256校验表随安装附件提供。

## 检查范围与结果

| 范围 | 检查内容 |
|---|---|
| 客户端、脚本与配置 | 网络请求、认证头、凭据存取、错误输出、备份、导出及打包输入 |
| 文档、测试、提示词与历史 | 受控文件、可达Git历史、已识别的压缩或编码材料 |
| v1.0.0和v1.0.1附件 | 两端各版本的12件附件；文件大小、校验值、来源、APK/ZIP/DMG内容、资源、DEX字符串及原生程序可识别字符串 |
| 本机已知配置 | 只在内存中比较凭据及其可识别表示，未发现匹配 |

疑似机密的内容只在本机处理，公开记录仅保留位置、类型、数量和脱敏结论。公开许可证署名、公共CA证书、软件校验和与测试假数据按真实来源和用途分类。

当前请求与数据处理采用以下保护：

- 认证头构造、代理和服务错误使用固定安全提示，避免将凭据带入界面或公开日志。
- 模型认证请求拒绝自动重定向，防止认证信息或请求体被转交另一地址。
- 发行输入排除环境配置、账号口令、签名私钥、本机记忆库、私人研究材料及私有审计目录。
- Android安装包中的网络、备份和设备迁移安全配置按实际编译资源检查。
- 本机研究完整性校验密钥不进入备份或云同步；恢复资料时保留当前设备的这类密钥。
- 研究正文、原始模型回答、费用和恢复记录按原规则保留；公开诊断使用脱敏摘要。

## 配置、备份与升级

1. **在设备上配置凭据。** 模型、网盘和Zotero账号由用户自行设置。Mac使用原生Keychain，Android使用本机安全存储。
2. **按平台覆盖升级。** Mac退出旧版后，将新应用放入应用程序文件夹。Android覆盖升级使用相同应用标识和发行签名，且内部版本号更高；若旧版是调试包或签名不同，先导出完整备份并确认可恢复，再卸载旧版。
3. **在新设备配置凭据。** 研究资料与设备凭据分开处理；跨设备恢复资料后，在新设备填写连接凭据。
4. **将完整备份作为私人文件保管。** 研究原文、笔记、模型回答和上游服务正文都可能含私人内容。分享前检查导出内容，日志或问题反馈中只提供脱敏摘要。

## 凭据泄漏处理

如发现真实凭据泄漏，及时撤销或轮换凭据并检查访问记录；分发方停止提供受影响版本，修复后重新发布。问题反馈请通过安全渠道提交脱敏信息，保留原始记录供本机核查。
