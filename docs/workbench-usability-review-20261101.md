# 工作台体验审改：收藏、操作效率与界面逻辑

本轮从 1.1.0 发行后的代码继续，维护目标为 1.2.0（Mac 构建号 3、Android 构建号 6）。公开状态以[发行页](https://github.com/nanless/audio-paper-digest/releases)的实际附件为准。Mac、Android 与独立审查分别检查实现、脚本、数据和实际界面，按可验证的变更分轮修复；不把阅读代码或重复跑同一检查算作修改轮次。每组稳定后中文提交、推送，未完成的检查保留待验。

## 已确认的问题与处理范围

| 范围 | 实际问题 | 处理 |
|---|---|---|
| Android 安装脚本 | 未选设备时默认安装旧模拟器 | 要求明确的唯一设备，先核就绪与 QA 名称 |
| Android 设置 | 正常取消被当作失败，保存取消可能继续进入密码步骤 | 取消独立上抛、忙碌状态复位、保留草稿 |
| 两端收藏 | 仅编号，无真实收藏时间或自建分类 | 可选跨端分类资料、真实新时间、旧时间未知 |
| 收藏并发 | 两个视图把旧整列写回，互相覆盖 | 原生增量、分类修订校验与一次原子保存 |
| 资料库选择 | 隐藏已选项仍参与批量操作，未清楚说明 | 区分可见与隐藏选择，提供清空及明确批量语义 |
| Mac 资料库 | 已归档的下架论文及超过一万条的数据可能不在列表 | 正常合并保留项并完整分页，来源资格仍独立核验 |
| 导航与筛选 | 视图共用筛选、往返或刷新重置工作位置 | 按实际视图保存搜索、筛选、分页与阅读上下文 |
