# Reader 清晰度与 Token 效率改进计划

状态：工程实现与完整回归已完成；真实试写仍有事实阻断，未发布、未宣布质量目标达成。继续执行用户追加的全量源文重写及事实验收。基线：`e39fff3`。

## 不变的边界

- 保留 canonical 的 13 个解析标题、Reader 12–18 节、5000–18000 中文字、4–10 组术语桥。
- 保留全文来源、数字/单位、公式、图片像素、作者机构与资源身份门禁。
- 保留论文锁、原子写、generation、review 只读、精确 Git delta 和远端 OID 验证。
- 不恢复本机助手，不运行整批日更，不自动重写或发布已有博客。
- 所有项目脚本和测试在沙箱外运行；不绕过环境守卫。

## 本轮实施包

| 工作包 | 负责人 | 交付 | 必须验证 |
| --- | --- | --- | --- |
| A. Reader 局部修复与恢复 | Reader Agent | 受限块补丁、输入 SHA 校验、失败候选持久化、无进展检测、相关证据上下文 | 多错定位；未改节点不变；拒绝越权/陈旧补丁；失败恢复不当作成功 |
| B. 发布前置检查与缓存 | Publication Agent | 确定性/Hugo 先于 LLM；协议匹配缓存；结构化阻断记录 | 已知机械错误调用 LLM 为零；模型/Prompt 漂移不复用旧通过；字节与事务回归 |
| C. 统一验证与 CI | Verification Agent | 完整验证入口、固定 Hugo 与必跑集成检查、离线回放框架、分层验证说明 | 全套 JS、默认/Manual Python、语法、数据、Hugo；不能静默 skip 关键集成 |
| D. 用量与成本归因 | 主 Agent | 请求级真实 usage/不可得状态、论文/阶段上下文、成本汇总命令 | Responses/Chat/Anthropic usage；失败计数；不记录正文/密钥；估算不混入实际值 |
| E. Reader 契约与确定性表格 | 集成阶段 | 共享机械契约、原表选择后由代码渲染、实际章节文风检查、精简写作规则 | Prompt/代码一致；表格位置与数字关联；Reader 跨节近重复；最终旧协议兼容 |
| F. 验证闭环与交付 | 主 Agent + 独立复核 | 基线回放、故障注入、完整回归、一篇受控真实验证、结果报告 | 有失败即定位修复并重跑；不宣称未实测的节省比例 |

模块所有权按文件/函数区段分开；并行修改不得覆盖其他 Agent 的变更。公共配置与包命令由主 Agent 协调。

## 详细实现顺序

1. 建立基线：记录工作树、现有成功产物 SHA；不对 canonical 或线上页面做实验性写入。
2. A/B/C 并行，主 Agent 实现 D；各工作包先完成故障用例再运行针对性回归。
3. 集成 A/D/E：原表仅选择来源行列，代码生成表格及绑定；模型专注解释。局部补丁合并后仍完整解析、验源和验文风。
4. 保留现有硬约束但消除提示冲突；章节近重复检查以真实 Reader 章节为单位。通用规则与论文特定反馈分离。
5. 所有便宜确定性检查在付费审查前完成；审查缓存须绑定实际审查协议与输入，旧指纹不能冒充当前结果。
6. 离线回放至少覆盖：多个错误、错误数字/单位、图 marker 错位、坏 JSON、陈旧补丁、候选损坏、恢复、无进展、协议漂移、Hugo 失败、真实跨节重复。
7. 运行完整验证。任何失败均修复后重新运行受影响套件，再运行完整入口。
8. 真实验证先限制为一篇已归档同源论文的隔离 Reader 实验；显式控制请求次数和输出预算，使用项目公共请求路由。失败保留记录，不无限追加调用，不覆盖已发布 canonical。
9. 独立复核结果，记录实际 usage、修复范围、内容质量与剩余限制，再交付。

## 指标与验收

- 机械错误场景：LLM 调用数为 0；本地排版/表格组装不得改变来源事实。
- 补丁场景：只修改允许节点，未触及节点 SHA 全部不变；合并后全门禁通过才可成功。
- 恢复场景：相同输入可续失败候选；来源、模型、Prompt 或契约变化时拒绝错误复用。
- 缓存场景：审查要求/模型变更必须触发相关重审；不能只凭页面 SHA 复用旧协议。
- 统计场景：服务未给 usage 时标记不可得，不以字符估算冒充计费量；记录失败调用及完整生命周期。
- 内容场景：学习依赖、执行链、实验条件、指标方向和证据边界正确；字数/节数达标不是质量充分条件。
- 目标值（需后续固定评测集验证）：累计 Token 降低 30%、首轮机械通过率 85%、p95 局部修复不超过两轮。单篇实验不能证明这些总体目标达成。

## 明确不做的大迁移

本轮不废除 13 标题 canonical，不降低字数/章节要求，不替换模型，不取消事实审查，不把全部成功缓存直接改成宽松复用。
结构化 canonical 全量迁移、评分分歧维度裁决和大规模模型 A/B 留作独立迁移；先以本轮可回归的局部机制建立可靠基础。

独立复核三张原图与全文后拒绝该稿：DNS WER 方向解释反转；把数据集密度分布与单例竖线混淆；将末步结果外推全程；
遗漏其他三集的可运行预测停止结果及逻辑回归训练/应用条件；将更高干净密度推成更强判别；将停止梯度写成消除二阶梯度。
部分错误与输入 canonical 的未证实解释高度重合。原始展示公式未被篡改，但这不能证明周围讲解正确。

因此继续做一项范围明确的输入修正：Reader 默认直接依据原文证据与原图，不再重复输入生成的 canonical 评论；
13 标题 canonical 仍保留给机器字段、评分及其他消费者。保留显式修订模式，但正常 source-only 生成不得借入旧稿。
同时减少诱导无来源反事实解释的要求，明确图例对象、时间范围和实际可运行策略的比较。下一次限额实验不注入本论文专属纠错答案。
