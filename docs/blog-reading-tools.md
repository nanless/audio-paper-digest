# 音频研究门户网页阅读工具

音频研究门户（[Audio Research Portal](https://nanless.github.io/audio-research-portal/)）的所有阅读、检索、图表交互与引用导出工具均在浏览器内直接运行，无需安装本机助手、克隆仓库或配置 API 密钥。门户采用 **Studio Monograph 2.0** 排版与前端交互脚本，由 [audio-research-portal 仓库](https://github.com/nanless/audio-research-portal)维护，新日更发布时自动沿用同一套模板。

## 快捷检索与八大专题导航

- **命令面板全文检索（`⌘K` / `Ctrl+K` / `/`）**：在站内任意页面按下快捷键即可呼出命令面板，结合静态索引与 Pagefind 分片搜索论文标题、正文与编号，支持按 `全部`、`论文解读`、`高分 ≥8.0`、`含开源`、`含试听`、`每日研究` 与 `会议专题` 快速切换分面筛选，以及一键直达论文库、研究方向树、顶会目录与主题切换。
- **八大音频研究专题（`/hubs/`）**：按已核验的九维音频分类实时聚合 **自动语音识别（ASR）**、**语音合成与声音克隆（TTS & Voice Cloning）**、**语音增强与声源分离**、**音频/语音大模型与神经编解码**、**音乐生成与音乐信息检索**、**空间音频与声学定位**、**音频理解、分类与事件检测** 与 **音色转换与可控语音编辑** 八大方向的高分精选、顶会分布与近期收录趋势。
- **相关论文与章节导航**：单篇论文页左侧提供实时跟随滚动的目录树（移动端为可搜索章节抽屉），文末提供基于分类与主题关联的相关论文推荐，帮助顺着同一研究问题横向深读。

## 原图检视器、表格工作台与每日播客

- **论文原图检视器（`1×–6×` 缩放）**：点击正文中的论文原图即可进入灯箱检视，支持滚轮、双击（`2.5×`）与双指捏合在 `1×–6×` 之间缩放拖拽、左右切换全篇原图；在深色主题下提供单图“原色 / 反色”切换与暖纸底托，避免科研曲线与谱图被深色样式扭曲。
- **交互式表格工作台**：对结构规整的实验结果表提供按列数值/文本排序（自动识别 `k/M/B`、`ms/s`、`Hz/kHz`、`dB`、`%` 与科学计数法，缺失值始终固定在底部）、首列冻结横向对比以及宽表全屏展开，原始表头与核验数值保持不变。
- **每日音频播客播放器与标准 RSS**：已发布播客音频的每日研究页内置网页播放器，仅从受控 GitHub Release HTTPS 地址加载音频，支持 `0.75× / 1.0× / 1.25× / 1.5× / 2.0×` 倍速、按章节时间戳一键跳听并高亮当前小节，也提供直接下载 MP3。外部播客客户端（如 Apple Podcasts、Pocket Casts、小宇宙等）可订阅门户标准 Podcast 2.0 RSS [`feeds/podcast.xml`](https://nanless.github.io/audio-research-portal/feeds/podcast.xml)。

## 核对原论文，下载导读、Obsidian 笔记与引用

- **核对原论文**：从文章“原文与引用”面板打开已核验的 arXiv、官方会议页面或原 PDF。本站导读属于对论文的二次讲解，不替代原论文；保存材料时保留原始来源和导读版本提示。
- **引用与 Obsidian 导出**：单篇页提供 `复制引用`、`复制 BibTeX`、`复制 Obsidian 笔记`（含结构化 YAML front matter，缺失字段如实留空省略）以及静态 `Citation JSON`、`BibTeX`、`RIS` 下载。旧页面仅根据已有题目、arXiv ID 与官方链接生成简要引用，缺失作者或日期时不会猜补。
- **单篇研究资料包**：可下载当前论文的 Markdown 导读与引用汇总，包含本页可见导读、官方链接与来源版本提示；论文身份尚未核实时仍可保存导读，但不会生成未经核验的论文引用。

## 导出多篇清单，交给其他工具

在论文库勾选多篇论文后，可批量下载 Markdown、CSV、BibTeX 或 RIS。Markdown 适合阅读和继续写作，CSV 适合在表格工具中整理清单；两者保留原签发快照的可核验分类路径，缺失新分类时明确标注，不从旧标签推断。

需要存入文献库时，下载 RIS 或 BibTeX 后自行导入。门户网页不直接连接 Zotero 或其他本机文献库，“下载成功”不等于已经归档到文库；如需一键归档书目、原文 PDF、导读与笔记到 Zotero，请使用 [Mac 版](../apps/macos/README.md) 或 [Android 版](../apps/android/README.md) 原生工作台。

需要与外部 AI 协作时，把导出资料和自行取得的原论文交给所选工具，并说明本站导读属于二次解读。站内没有 AI 提问按钮，也不会替用户发起模型请求。

## 分享与降级兼容

页面支持复制链接与浏览器原生系统分享；自动复制被浏览器拒绝时，会展开已选中的纯文本区域供手动复制。JavaScript 不可用时，官方链接、静态正文与静态引用下载仍可正常使用。无法确认论文身份的历史页仍可下载导读与访问已有链接，但不会生成未经核实的论文引用。

## 维护说明

门户网页不承担个人数据持久化，不提供站内收藏、待读、阅读笔记、云端备份、直接写入 Zotero 或本机模型调用；这些个人工作区能力统一由 Mac 与 Android 原生工作台提供。前端不再向本机服务传递地址或参数，构建检查确保不会重新引入本机助手依赖。

新页面的元数据 `paper_digest_sidecars` 描述四份静态附属文件：三份引用文件使用 `researcher-sidecars`，上下文文件另声明 `paper-research-context` 和结构指纹。文件发布在 `client/papers/`，清单记录每份文件的 SHA-256。已经发布的页面按其原有路径和格式读取。
