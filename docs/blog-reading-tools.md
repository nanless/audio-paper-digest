# 无需助手的博客阅读工具

这些工具在浏览器中运行，无需配置本机助手、项目环境或 API 密钥。博客模板与前端脚本由 `audio-paper-digest-blog` 仓库维护，新日更继续使用这些模板。

| 功能 | 使用方式 |
|---|---|
| 原文与 PDF | 打开已经识别的官方 arXiv、会议论文页面或 PDF，再用浏览器保存文件。 |
| 引用下载 | 优先下载发布时生成的 Citation JSON、BibTeX 或 RIS。历史页根据已有题目、arXiv ID 和官方链接生成简要引用；缺少作者或日期时，不补猜。 |
| 单篇导读 | 将本页可见导读、官方链接和已有引用字段下载为 Markdown，保留来源及版本提示。论文身份尚未核实时，不生成论文引用。 |
| 批量导出 | 在论文库勾选论文，下载 Markdown、CSV、BibTeX 或 RIS。Markdown 和 CSV 保留可核验的分类路径；没有新分类时会明确标注，不从旧标签推断。 |
| 外部文献库 | 下载 RIS 或 BibTeX 后，自行导入文献管理工具。博客不直接连接 Zotero 或其他文献库。 |
| 与外部 AI 协作 | 把导出资料和自行取得的原论文交给选择的 AI 工具，并注明本站导读属于二次解读。具体方法见博客资源指南；站内没有 AI 提问按钮。 |
| 分享 | 复制文章链接；浏览器支持时，也可手动调用系统分享。 |

自动复制失败时，页面会显示可手动选择的文本。JavaScript 不可用时，官方链接和静态引用下载仍可使用。无法确认论文身份的历史页仍可下载本站导读，正文已有链接也保持可用，但不会生成未经核实的论文链接或引用。

## 维护说明

博客已取消收藏、待读、阅读笔记、备份与恢复、复制 AI 提问、直接保存到 Zotero、本机模型调用、Zotero 确认导入、本机 PDF 下载和助手启动指引。前端也不再向本机服务传递地址或参数；博客构建检查应防止这些依赖重新出现。

`researcher-sidecars-v1` 定义的四个静态文件及其 SHA 和生成清单仍保持兼容。取消交互入口不要求重写已发布文章、评分或发布记录。
