# 无需助手的博客阅读工具

博客阅读工具在浏览器中运行，不依赖本机助手、项目环境或 API key。全站模板与前端脚本
由 `audio-paper-digest-blog` 仓库维护；新日更继续使用这些模板。

| 功能 | 使用方式 |
|---|---|
| 原文与 PDF | 打开已识别的官方 arXiv、会议论文页面或 PDF，使用浏览器保存文件。 |
| 引用下载 | 优先使用发布时生成的 Citation JSON、BibTeX、RIS；历史页使用已有题目、arXiv ID、官方链接生成简要引用，缺失作者/日期不补猜。 |
| 单篇导读 | 下载本页可见导读、官方链接与可得引用字段为 Markdown，并保留来源和版本提示；身份待核时不生成论文引用。 |
| 批量导出 | 在论文库勾选候选，下载 Markdown、CSV、BibTeX 或 RIS。Markdown / CSV 保留可核验的分类路径；没有新分类时明确标注，不从旧标签推断。 |
| 外部文献库 | 下载 RIS/BibTeX 后自行导入自己的文献管理工具；博客不直接连接 Zotero 或其他文献库。 |
| 与外部 AI 协作 | 将导出资料与自己取得的原论文交给选择的 AI 工具，标注本站导读属于二次解读。具体流程见博客资源指南；站内不提供 AI 提问按钮。 |
| 分享 | 复制文章链接；浏览器支持时可以手动调用系统分享。 |

自动复制失败时展示可手动选择的文本；JavaScript 不可用时仍保留官方链接和静态引用下载。
没有可靠论文身份的历史页仍可下载本站导读；正文已有链接保持可用，不伪造论文链接或引用记录。

已取消的功能包括收藏、待读、阅读笔记、备份与恢复、复制到 AI 提问、保存到 Zotero、
本机模型调用、Zotero 确认导入、本机 PDF 附件下载、助手启动指引，
以及前端到 loopback 服务的 URL 和参数传递。博客构建检查应阻止这些依赖重新出现。

现有 `researcher-sidecars-v1` 的四个静态文件及 SHA/manifest 契约保持兼容；
取消交互入口不要求改写已发布的论文正文、评分或 production proof。
