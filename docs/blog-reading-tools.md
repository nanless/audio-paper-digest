# 无需助手的博客阅读工具

这些工具在浏览器中运行，无需配置本机助手、项目环境或 API 密钥。博客模板与前端脚本由 `audio-paper-digest-blog` 仓库维护，新日更继续使用这些模板。

## 核对原论文，下载导读和引用

从文章中的官方链接打开已经识别的 arXiv、会议论文页面或 PDF，再使用浏览器保存原文件。本站导读属于对论文的二次讲解，不替代原论文；原始来源和导读版本提示应随保存的材料一起保留。

引用优先使用发布时生成的 Citation JSON、BibTeX 或 RIS。Citation JSON 保存结构化书目信息，BibTeX 和 RIS 是文献管理工具常见的导入格式。旧页面只根据已有题目、arXiv ID 和官方链接生成简要引用；缺少作者或日期时，不会猜补。

单篇导读可以下载为 Markdown 文本，包含本页可见导读、官方链接和已有引用字段，并保留来源与版本提示。论文身份尚未核实时，仍可保存导读，但不会生成未经核验的论文引用。

## 导出多篇清单，交给其他工具

在论文库勾选论文后，可下载 Markdown、CSV、BibTeX 或 RIS。Markdown 适合阅读和继续写作，CSV 适合在表格工具中查看清单；两者保留可核验的分类路径，没有新分类时会明确标注，不从旧标签推断。

需要存入文献库时，下载 RIS 或 BibTeX 后自行导入。博客不直接连接 Zotero 或其他文献库，所以“下载成功”不等于已经归档到文库。

需要与外部 AI 协作时，把导出资料和自行取得的原论文交给选择的 AI 工具，并说明本站导读属于二次解读。具体方法见博客资源指南；站内没有 AI 提问按钮，也不会替你发起这项模型请求。

## 分享与无法自动复制时的处理

可以复制文章链接；浏览器支持时，也可手动调用系统分享。

自动复制失败时，页面会显示可手动选择的文本。JavaScript 不可用时，官方链接和静态引用下载仍可使用。无法确认论文身份的历史页仍可下载本站导读，正文已有链接也保持可用，但不会生成未经核实的论文链接或引用。

## 维护说明

博客已取消收藏、待读、阅读笔记、备份与恢复、复制 AI 提问、直接保存到 Zotero、本机模型调用、Zotero 确认导入、通过本机助手下载 PDF，以及助手启动指引。浏览器按官方链接手动保存原 PDF 仍可使用。前端不再向本机服务传递地址或参数；博客构建检查应防止这些依赖重新出现。

新页面的页面元数据 `paper_digest_sidecars` 描述四份静态附属文件：三份引用文件使用 `researcher-sidecars`，上下文文件另声明 `paper-research-context` 和结构指纹。文件发布在 `client/papers/`，清单记录每份文件的 SHA-256。已经发布的页面按其原有路径和格式读取。
