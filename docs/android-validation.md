## 当前结论

阅读、PDF、个人研究、系统文件操作、Zotero 与坚果云的功能验证已完成相应范围。实际 Android 环境为 API 28、API 35 模拟器，覆盖手机窄窗、宽窗、折叠半展开与大字号；实体品牌手机不在本次测试范围内。[86 项功能表](<android-feature-parity.md>)列出各项结果和发行待办。

API 28、API 35 是 Android 系统接口级别，不是应用版本号。模拟器能重复检查指定系统和窗口条件，但不能替代各品牌实体设备的后台、电源与文件提供方行为。下表汇总不同历史批次的证据；当前 1.3.0 新增检查以页首和该版发行记录为准。

## 备份中的本机材料

研究材料和本机凭据采用不同的保存规则。恢复要取回笔记、回答与来源，也要避免把另一台设备的登录和校验能力一起带入。

新备份、导出和云上传排除 `ModelUsage/response-integrity.key` 与 `ModelUsage/response-integrity.android.key` 两个精确路径及其大小写别名。其他隐藏研究文件和普通 `.key` 文件继续按合同处理。

旧包按原清单完整解码并保留原件；有效恢复目录使用当前设备的完整性密钥，不安装旧包内密钥。历史研究的输入、回答、费用和来源保持。含本机密钥的旧待传包停止继续传输，原包保留在本机，用户可结束旧操作后新建快照。规则见[备份合同](<android-cloud-contract.md>)。

## 已知使用限制

- 后台任务由 Android 按网络、电量、存储与系统配额安排，非精确定时；强制停止后不保证继续运行。
- 备份采用独立版本和显式恢复，不实时合并多设备笔记；资料包没有额外端到端加密。
- 历史模型记录可保留阅读，实际复用仍需受支持合同与完整证明。已派发且结果未知的请求不自动重发，未知金额不记为零。
- 当前不提供 OCR、未经输入图像的模型视觉理解、PDF 原件写回或 Zotero 标注双向编辑。
- 旧离线导读可能缺少当前 MathML 合同。界面保留来源提示，并可查看原 PDF；新包继续执行现行公式和资源校验。
- 官方 Zotero 离线读取结果适用于已测试的 1.0.0-247 和指定归档。群组附件不使用 WebDAV。
