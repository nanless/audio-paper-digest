本页把用户“除Zotero另行研究决定，其余与Mac一致、Android原生适配、美观、坚果云、两端最终GitHub Release”的要求逐项落实。依据[Mac需求](mac-app-requirements.md)、[原69项](mac-app-acceptance.md)与[新增17项](mac-app-cloud.md)，不减少原功能，也不将Mac通过记录授予Android。原始核查日期2026-10-26；当前事实补记2026-10-28，以下保留各批身份。第14c两台模拟器各执行87项、通过86项；第14d的257项JVM及必要设备复测已通过，API28完整阅读预热后的48MiB全库同步、API35原生PDF关闭已复验成功，必要消费者分别33/33与34/34通过，真实Android目录XML解析各3/3通过。这不是重跑全部87项。各行保留直接覆盖的部分范围，第16批引用原件、加密PDF、保留导出和跨端恢复已有较新局部结果，公开合并工程399项单测及17项资源检查通过；详细范围见[验收记录](android-validation.md#第16批核心与第17次公开源码合并检查)，未完成最终86项验收。

`A-`编号对应同名Mac原项。Zotero最终选择完整Web API v3可选联动，系统分享只作补充；官方能力及限制见[研究说明](android-zotero-research.md)。用户不配置Zotero不影响阅读、模型或坚果云，但实现和发行说明不能将未验完整归档说成已完成。

## 所有平台必须保持的合同

- 从同一公开发布成果读取目录、原评分、分类、完整导读和引用，不重跑已有论文，不读取生产.env/runtime。基础论文身份、原件版本、导读修订和私人会话分别保存，未知值保留。
- 共用数据/材料合同、错误语义、真实测试材料、原输入封存与用量记账规则。Swift/AppKit不是Android运行库；Kotlin适配器必须用共同正反例交叉核，不能只写同名函数就称流程共用。
- 已露出的按钮、菜单、配置和后台动作都必须接通真实服务；不以演示回答、虚构任务或假百分比过关。所有功能仍须经历修改、测试、非作者审查与实际设备验证。
- 坚果云保不可变设备版本，恢复是明确时间点切换并保前副本。没有实现实时逐字段合并时不承诺该能力；不把另一设备的模型端点、密钥或云账户覆盖本机。

## 原生布局和系统行为

手机以底导航进入论文库、任务、笔记和设置；大窗口改用导航rail。无PDF时完整单页导读，打开PDF且可用宽度足够才左导读/解析/笔记、右原文；窄窗提供保状态的聚焦切换，不把Mac双栏等比压缩。按实际窗口dp、折叠姿态、IME和系统栏决定布局，符合[Android自适应布局](https://developer.android.com/develop/ui/compose/layouts/adaptive/get-started-with-adaptive-apps)原则。

图标延续用户选定第三个C石墨边注的品牌关系，按Android自适应图标重新适配。科学图/PDF原色、中文排版、字号、留白、列表和所有错误/空/禁用/焦点状态都用真实论文验证。导入导出使用[系统文件选择器](https://developer.android.com/training/data-storage/shared/documents-files)，共享用[系统分享](https://developer.android.com/develop/ui/compose/sharing/send)，打印原文用[系统打印服务](https://developer.android.com/training/printing)。

[WorkManager](https://developer.android.com/develop/background-work/background-tasks/persistent?hl=en)支持适合持久调度的工作，但不是精确闹钟；[周期执行](https://developer.android.com/reference/androidx/work/PeriodicWorkRequest)受省电和约束影响。返回桌面、划掉最近任务、系统回收、强制停止、重启和显式停用各自验收，不声称被强制停止后还能持续执行。后台重试不得重发可能已经付费的模型请求。

## Android特有的验收条件

这些条件落实平台差异，不替换上述86项，也不让未支持功能自动变为不适用。

| 场景 | 需要取得的实际证据 |
|---|---|
| 手机与大窗口 | 至少覆盖320/360/412dp窄宽、约600dp中窗和840dp以上宽窗的真实可用区域；横竖屏、折痕/分屏/自由窗口、字体放大、IME遮挡时主操作和正文完整。具体支持SDK/设备范围以实际构建记录固定，不能只锁横屏掩盖。 |
| 返回与状态恢复 | 手势/预测返回、外部文件选择器/浏览器回来、旋转、系统回收、设备重启和包升级都不串论文、页、选区或草稿；恢复路由不能使用已退休原生文档的回调。 |
| 真实辅助功能 | TalkBack逐项阅读导航/科学正文/表和表单，焦点按顺序移动；大字、触控目标、键盘/开关控制的核心旅程。PDF文本层是否可读与位图可见分别记录。 |
| PDF引擎 | API兼容范围内真实文本提取、查找、选择/复制、注释、旋转/加密和大PDF；图片可显示不能代替文字几何与真实选择。依赖组件许可、版本和分发权有记录，未做OCR不称支持。 |
| 用户选文件 | SAF取消、只读/失效URI、云文件提供者、重启后许可、超限/非PDF、选择器中进程被回收；导入实际复制核SHA。导出完成才报已保存，零字节/写失败不假成功。 |
| 屏幕外工作 | 未允许通知、Doze、省电/计费网络、返回桌面、系统回收/强制停止及重启；前台/持久任务和取消真实，通知状态不与任务页分叉。不要靠全时唤醒或要求关闭系统省电证明可靠。 |
| 存储与密钥 | Keystore不可用/密钥失效、设备换锁、应用升级、备份迁移及空间不足；明文不进日志/普通JSON/导出，密文和目标控制不进入研究快照。系统Auto Backup/D2D规则单独检查，不假定其等于本App完整备份。 |

| 移动端资源 | 8MiB传输与有限缓冲/临时文件管理，长文/大PDF/完整编码不能一次吞满RAM；OOM/空间不足保原快照，不为能运行而丢研究文件。 |

| 升级与发行 | 正式证书一致、versionCode递增；新安装、覆盖升级与卸载说明。APK包含实际所需ABI/资源/许可，签名/ZIP检查和下载SHA在最终Release逐资产核对。 |

[Android Keystore](https://developer.android.com/privacy-and-security/keystore)保护设备加密密钥，token应加密存储而非硬编码。依据[系统Auto Backup](https://developer.android.com/identity/data/autobackup)，默认会纳入多类私有文件，因此必须显式管理备份/设备迁移排除规则，不能只因存在私有目录就声称凭据不会迁移。

APK按[官方签名机制](https://developer.android.com/studio/publish/app-signing)验证正式证书及可升级性。应用私钥不进仓库/发行资产；GitHub Release和Google Play是不同渠道，本轮要求前者，不自动宣称后者已完成。

## 实现分工、验证次序与未验边界

共享发布数据、个人研究记录、材料合同、费用/派发连续性、Zotero journal和云快照规则是业务核心；Android原生导航、PDF、文件选择、Keystore和后台调度是平台适配层。本轮Kotlin/Compose的具体库/版本由构建锁定并实际编译，不在研究文档虚构一个已经存在的稳定SDK组合。

先核真实网站全库与完整长文，再把导读/原PDF/个人研究、离线/导出/恢复、坚果云与Zotero分别贯通。每个阶段先用隔离故障验证保存/恢复，再在独立可识别的真实数据上取证。保每轮失败及修复版本，不通过降低断言或把假回答塞进演示来凑完成。

Mac的`release_tools.py`来源检查已明确允许Android独立代码树以及该工具和两份验证测试的受控变化，其余非运行差异单独登记。原Mac来源字节、实际包、签名与69+17门禁保持；这项合同升级不等于APK签名、Android验收或GitHub发行通过。两端仍须按各自最终可追溯来源构建并核实际资产。

第14c已在API28与API35模拟器完整执行各87项，真实Main旅程、在线MiCLA科学图文、系统保存及必要隔离检查有直接证据；两端仍各有1项失败，完整结果与历史见[验收记录](android-validation.md)。较新的第18批已完成真实模型和坚果云的限定服务路径，并通过465项JVM与两端各18项相关设备回归，详见[最新记录](android-validation.md#第18批真实服务与必要修复)；实际服务的固定主APK与18b公开工程分开记录。以上是当时的边界。后来74冷续传的父书目加五类材料已完成并回读，宽窗、半展开和200%字号科学内容也有较新分段结果；其后重复续传/预览、系统辅助树与整轮PDF观测失败均独立保留。官方Android Zotero客户端打开、真实选区研究、未覆盖的生命周期及最终Release仍按当前证据核对；不把用户已接受的模拟器阶段另加为必须取得物理手机。Mac本地Zotero的99项回读只属于Mac路线，不授予Android Web API或官方客户端同步通过。

当前系统汇总页重开仍有特定链接读出缺口，正常两代三链接回归虽通过，旧实际counter失败不洗为通过。真实选区研究尚未发起；整页5回答不替选区。官方Android客户端打开尚未取得实际记录，稳定版HTML快照兼容性按官方渠道如实说明，本轮不临时新增PDF转换功能。这些剩余条件及最终Release均不手填通过。
