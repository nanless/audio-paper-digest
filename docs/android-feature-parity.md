# Android 与 Mac 功能表

论文速递工作台的 Android 实现对应 Mac 的 69 项功能与 17 项云端、发行要求。`A-` 编号保持原对应关系。下表保留每项要求，验证范围在表后说明；操作与版本状态见[Android 验证说明](<android-validation.md>)。

当前 **86 项全部通过**。功能验证覆盖相应范围；1.0.1/code4 已通过本地正式包安全核验和同签名覆盖升级，并与 Mac 安装包在[同一版本发行](https://github.com/nanless/audio-paper-digest/releases/tag/v1.0.1)公开。公开后逐件下载的大小与 SHA 与实际安装包一致。

## 共同规则

- 目录、评分、导读和引用来自网站已发布成果；阅读、同步和备份不重新调用写作模型。
- 原文、网站导读和私人回答分别保存。研究先确认材料与预算，再保存输入和派发事实；未知费用保持未知，已派发请求不自动重发。
- 每份资料绑定实际来源、版本、PDF SHA 与物理页。未知字段、旧稿、费用和历史保留；设备授权、本机密钥不随研究快照迁移。
- 恢复保留本机连接、派发计数和恢复前副本。多设备使用独立版本与显式恢复，不自动合并并行编辑。

## 验证范围

<a id="e1"></a>**原生功能。** API 28、API 35 模拟器覆盖设置、草稿、系统返回、页面重建、任务取消、PDF 选区与来源隔离。测试环境为专用模拟器，实体品牌手机不在本次范围内。

<a id="e2"></a>**文件与恢复。** 两代 Android 实际执行加密 PDF 导入、错误密码和取消、系统保存与重选、备份预检和确认恢复；Android 保存包由 Mac 逐文件核验，Mac 研究包在 Android 恢复后保留用量、会话、本机配置和前副本。新备份按当前本机完整性密钥排除规则生成。

<a id="e3"></a>**研究与费用。** 真实模型请求完成回答并保存原输入、响应和用量；一份已验证整页回答为 1486 输入、6329 输出、共 7815 tokens，推理用量已包含在输出内，金额未知。截断、认证、配额、取消与保存失败分别记录，复用已有结果不新增调用。

<a id="e4"></a>**坚果云。** 真实分块备份在首块回读后取消，冷启动继续同一快照，完成全部块和清单回读及本机回执保存。原生确认恢复保留研究材料和本机配置；版本列表、目标切换、坏块、丢应答和保存失败由对应测试覆盖。

<a id="e5"></a>**Zotero。** 同一归档父书目与来源信息、PDF、导读、研究、笔记五类子材料逐项回读。取消后冷启动继续原对象；权限、版本、用户编辑、目标变化和网络失败分别处理。附件后端及授权说明见 [Zotero 使用说明](<android-zotero-research.md>)。

<a id="e6"></a>**网站汇总。** 真实日更与汇总页可通过原生触摸进入对应论文，支持同页链接和外部来源保护；同步与导航保留论文身份及阅读状态。

<a id="e7"></a>**科学阅读与布局。** 真实 MiCLA 的三幅图、四个公式、四张表及十三页原 PDF 在手机、宽窗、半展开和 200% 字号下分别验证。原 PDF 查找、文字选择、翻页、宽窄切换、四种旋转和裁切框坐标按实际页核对。

<a id="e8"></a>**发行状态。** 1.0.1 已公开，标签与最终提交一致，Mac 与 Android 共 12 件附件可下载，下载文件大小和 SHA 与本机实际包相同。本地包另核源码记录、签名、资源和许可；A-REL-01 至 A-REL-05 均已完成。

<a id="e9"></a>**资料库。** 真实全站分片目录同步、搜索、筛选、缓存与空间测量已在两代 Android 检查。API 28 保持原 48 MiB 堆限制；坏分片、旧回调和取消保留上一份完整资料库。

<a id="e10"></a>**选区研究与回原文。** MiCLA 物理页 5 的实际选区经明确发送得到完整回答；原输入、PDF SHA、物理页、响应和用量对应。点击来源回到同一 PDF 第 5/13 页，回答滚动位置在重开和冷启动后保留。页级定位不提供逐句高亮，未输入的图像不作为模型已读材料。

<a id="e11"></a>**自动备份。** 一次实际 WorkManager 请求按网络、电量和存储条件执行完整上传，并保存完成状态。调度采用与手动保存相同的资料与校验流程，间隔为 6–168 小时、默认 24 小时；执行时刻受系统约束，强制停止后不保证继续运行。

<a id="e12"></a>**官方 Zotero 客户端。** 官网稳定版 1.0.0-247 实际同步指定 MiCLA 归档，PDF、导读和笔记在断网冷启动后仍可打开；导读混合公式和方法图实际显示。该范围适用于已测试版本和归档。

<a id="e13"></a>**引用。** 引用 JSON、BibTeX 和 RIS 使用原论文身份、来源与版本，保留完整作者和未知字段；生成文件经系统交付及独立读取核验。

<a id="e14"></a>**键盘与辅助功能。** 系统辅助功能节点定位和点击汇总链接、真实键盘导航、200% 字号下焦点与可达动作已验证。范围为实际节点与操作，不包含未测的语音输出或动画像素表现。

<a id="e15"></a>**导出与打印。** 引用、笔记、研究、导读及 PDF 通过系统保存并重新选择，由独立读取方核字节和归属。原 PDF 保持原 SHA；系统打印派生件核页数与文字，单独标识为派生文件。

<a id="e16"></a>**1.0.1 安装与升级。** 正式 APK 为 1.0.1/code4、minSdk 28、targetSdk 37，原签名与四种架构保持，16 KiB 对齐和包内许可通过核验。在隔离 API 35 ARM64 模拟器中从 1.0.0/code3 正常覆盖升级，十三项检查通过；UID、资料目录、单个公开测试标记保持，系统名称和原生空资料库启动正常。最终远端下载文件仍按发行流程核对。

<a id="e17"></a>**编辑与输入。** 真实中文输入、选择、复制粘贴、撤销重做和保存通过，普通 Return 换行，明确发送才发起研究。用户新建笔记可保存模型摘录并标明其来源；云设置在字号放大和输入法开启时可操作。

<a id="e18"></a>**离线旧稿。** 已保存的 MiCLA 包可在断网冷启动后读取正文、资源和原 PDF。旧 HTML 缺少当前 MathML 合同时显示相应来源提示；原 PDF 可供核对，新包继续执行现行资源和公式校验。

<a id="e19"></a>**列表与持久化。** 查询、评分和收藏筛选、进入阅读与返回列表保持上下文；收藏和非空待读列表在强制停止后仍正确。冷启动保留笔记、批注、设置、会话与已派发记录。

## 平台和安全约束

- 系统文件选择器用于导入导出；临时文件共享只授予所需 URI 的只读权限。卸载或清数据会删除本机私有资料，使用前自行备份。
- 明文网络关闭，TLS 和主机名正常验证；外域图片或附件不得获得模型或 Zotero 认证头。系统备份与设备迁移排除规则按实际编译资源核验。
- 模型密钥、网盘密码、设备授权和两份本机响应完整性密钥不进入新研究快照。旧包保留原件，有效恢复使用当前设备密钥；含本机密钥的旧待传包停止传输并保留。
- 研究资料上限为原文件 512 MiB、编码 750 MiB、100000 项，分块 8 MiB；超限整体拒绝，保存失败保留材料。恢复不返还已派发请求次数。
- 当前不提供 OCR、未经输入的模型视觉理解、PDF 原件写回、Zotero 标注双向编辑、全库 PDF 索引或实时多设备合并。

实现入口见 [Android README](<../apps/android/README.md>)，完整数据字段和请求预算见[备份合同](<android-cloud-contract.md>)。
