# 论文速递工作台 Mac 版：数据与恢复

客户端读取论文速递公开网站的目录、正文与引用资料。日更、会议和历史文章进入同一资料库，原评分、分类、来源和版本保持不变。数据读取由 [LibraryService](../apps/macos/Sources/LibraryService.swift) 实现；规划中的 [desktop/v1 专用出口](desktop-data-contract.md)尚未部署。

## 网站资料与个人研究

资料库从 `/index.json` 和搜索分片取得目录，完整核对分片字节、大小、条数和 SHA 后替换本机快照。取消或失败保留上一次完整目录。相同论文依据明确的论文身份合并多个出现页面，标题相似不作为合并依据。

正文、图片、引用文件与 PDF 按需读取。目录移除的论文仍保留旧元数据及已有研究，并显示移除提示；目录缺失不直接判为论文撤稿。作者、机构、DOI 和论文日期以来源为准，缺项保持未知。

| 资料 | 保存范围 |
|---|---|
| 网站缓存 | `PublishedLibrary/` 下的目录、正文修订、图片、指定版本 PDF 与引用记录 |
| 个人存储 | 笔记、标注、收藏、待读、阅读状态、任务及模型会话 |
| 模型材料 | `ModelUsage/` 下的实际输入、响应、来源、用量和恢复记录 |
| Zotero 记录 | 目标身份、选定材料、逐步结果与续传检查点 |
| 凭据 | 本应用自己的钥匙串；网盘密码也可仅本次保存在内存 |

个人资料根为 `~/Library/Application Support/PaperDigest/`，与生产仓库分开。网站同步不覆盖个人研究；客户端不读取生产 `.env`、账号池或运行账本。

## 正文与 PDF 版本

正文仅提取已发布文章区域，清除脚本、表单、危险链接和外部实体，保留科学图、表、公式及原出处。引用导出读取实际发布的 BibTeX、RIS 或 JSON 原字节，缺失或身份错误会提示，不在本机拼造一份已发布引用。

正文和可变 PDF 按目录验证周期与六小时时限重新核对，显式刷新可立即重试。读取失败时已有副本仍可阅读，界面显示陈旧状态和原核对时间；自动重试有五分钟退避。明确的 arXiv 版本固定保存，版本不符时停止下载。

PDF 保存实际字节 SHA、来源、版本和物理页数。原链接更新后，新旧 PDF 分开保存；旧回答、摘录和标注仍绑定原 SHA，不自动迁到新文件。扫描页能显示原件，但没有 OCR 或可提取文字时不能作为文字解析材料。

外部下载只接受规定的官方 HTTPS 来源，检查每次重定向与连接地址。arXiv 下载需要应用设置中的 HTTP CONNECT 代理。单张图片上限 16 MiB、单篇最多 32 张且累计 64 MiB；PDF 上限 100 MiB。取消一个任务只清理该任务未完成的传输，保留已有资料。

## 搜索与离线

资料库搜索覆盖标题、作者、编号、标签、已读导读和个人笔记。PDF 原文在阅读器内查找，不参与资料库全文搜索。

完整离线包保存指定版本的图文导读、科学图片、公式所需资源和原始 PDF。缺图或缺 PDF 时显示缺项。缓存管理先展示容量、引用关系和清理预览；私人研究、固定离线包及研究依赖版本受保护。

正式 `release` 包首次启动为空目录，不捆绑论文样稿。开发者可使用 `private-qa` 通道准备带 MiCLA 原件的测试包；该通道仅用于本机测试，不能用于正式发行。

## 模型记录与恢复

模型请求前保存不含 API 密钥的完整输入与待处理会话。返回的成功或失败结果先保存原始响应，再保存个人会话。来源、输入字节与本机响应校验通过后，重启可以直接恢复已有结果，不增加模型请求；失败或中断仍保留实际状态与费用未知标记。

**响应校验密钥仅属于本机，不随备份迁移。** `ModelUsage/response-integrity.key` 和 `ModelUsage/response-integrity.android.key` 及其大小写别名在备份读取内容前排除。其他输入、响应、用量和恢复记录照常保存。迁移来的响应若不能通过目的端校验，不会被重新签成成功；原始研究材料仍保留。

## 备份与恢复

本地和云端备份采用 `paperdigest-backup-v2`：最多 512 MiB 原文件、750 MiB 编码、100000 项，包含隐藏的普通研究文件，排除上述本机校验密钥及目录外资料。系统钥匙串不进入备份。

1. 下载或选择完整备份，先核对合同、路径、大小与全部原始 SHA。
2. 在原生窗口确认；取消时保留当前资料。
3. 保留恢复前副本，再完成暂存验证与替换，初始化失败时回滚。
4. 保留本机模型、协议、端点、网络和预算配置；已派发请求身份与时间合并保留，不因恢复旧版本清零次数。

旧备份仍先验证全部原字节，包括其中历史校验密钥条目的 SHA；恢复时不导入这些密钥，并保留目的端原本机密钥。含本机密钥的旧快照禁止继续上传或重新导出，原文件与检查点留在本机，可先保留旧快照再新建合规备份。来源、响应、费用和归档历史不为路径迁移改写；目录变化通过单独受限路径映射处理。

研究资料恢复到所选快照时点，之后的笔记、回答和原始费用可从恢复前副本找回。Zotero 原目标与授权继续核对，旧归档记录不取得新授权。云端操作见[坚果云保存与恢复](mac-app-cloud.md)。

## 开发接口与依据

公开桥接口包括 `library.status`、`library.sync`、`library.list`、`library.search`、`library.article`、`library.citationFile`、`library.downloadPDF`、`library.network` 与 `library.cancel`。读取论文、来源与版本时使用明确身份；进度返回实际阶段、完成数与总量。

实现依据：[BackupCodec](../apps/macos/Sources/BackupCodec.swift)、[RestoreLocalPolicy](../apps/macos/Sources/RestoreLocalPolicy.swift)、[ModelService](../apps/macos/Sources/ModelService.swift)。当前测试与实际操作范围见[验证说明](mac-app-validation.md)。
