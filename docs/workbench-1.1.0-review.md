# 工作台 1.1.0：导航、加载和首次配置

这次维护围绕 Mac 与 Android 的日更、会议、返回、页面切换和连接配置。应用继续读取网站已经发布的内容，不参与论文生产。包内版本为 1.1.0；Mac 构建号为 2，Android 构建号为 5。正式下载、来源提交、签名与校验值以 [GitHub 发行页](https://github.com/nanless/audio-paper-digest/releases)中的实际文件为准。

## 阅读路径

两端默认进入日更，提供论文库、会议和网站说明入口。日更按实际发布日期排列，不要求北京时间当天有更新；会议先展示完整目录，再展示总览与研究专题。真实网站索引未提供 `conferenceScope` 时，只用已知页面路径辅助分组，不改原来源身份。

从日更或会议进入论文后，可返回原汇总。会议目录、总览、专题之间逐级返回；同一清单、页面和 HTML 修订恢复阅读位置。Android 路径最多保留 24 层；每次返回重新走正常来源读取和链接签发，不复用已经退休的链接。

## 加载与刷新

目录空闲预热，两端最多预载两个最近日更、一个会议目录和一个会议总览的公开 HTML。预载不下载图片、PDF，不调用模型。预载失败保留前台正常读取，不能由“已经安排预载”推断材料已齐全。

先显示正文，再补图片。Mac 已存汇总先显示经过原件核验的本机快照，可用“重新读取网站”获取当前正文；不会把保存时间冒称本次网站核验时间。Android 在线正常打开缓存正文时可补同一 HTML 的图片，显式读取历史保存版本时保持只读。切页、刷新和目录变化使旧请求失效，迟到内容不能覆盖当前阅读。

Mac 在一次同步读取内合并重复的全站目录解析，返回前重新读取原文件完整字节，核对 SHA、路径和文件身份。范围不能跨异步、线程或调用使用。合成 10,001 条目录、21 分片、8 个保存修订的本地基准中，完整目录解析从 10 次降为 1 次，文件读取从 255 次降为 81 次，耗时从 2.970 秒降为 0.372 秒。此结果仅代表该本地路径，不代表整台应用或 Android 的整体加速比例。

## 首次配置

首次提醒可分别打开 WebDAV 备份或 Zotero，也可以稍后配置并先阅读。设置说明各自用途与步骤。

| 连接 | 用途 | 首次需要什么 |
|---|---|---|
| WebDAV 备份（坚果云） | 保存完整工作台、笔记与个人研究版本 | 坚果云账号、独立应用密码；服务器内置，目录默认 `PaperDigest` |
| Mac Zotero | 归档所选论文、PDF、导读和笔记 | 打开 Zotero Desktop，开启本地 API，检查连接并在 Zotero 中授权；无需 Web API 密钥 |
| Android Zotero | 使用官方 Web API 归档 | 在官网创建专用 API key，填写目标文库 ID，安全保存并检查 |

Zotero 附件的 WebDAV 与工作台整体备份分别设置，不静默共用密码。凭据继续留在各设备安全存储；Android 明确区分“凭据已保存”和“连接检查通过”，网络检查失败后只重试检查，不重复保存。

多个执行者分别负责 Mac、Android 和独立审查，主执行者负责集成、原生加载与分轮提交。已完成的八轮实质变更如下；后续发现真实问题仍继续修复，不用轮数代替结果。

| 轮次 | 改动与复查 |
|---|---|
| 1 | Mac 汇总入口、会议归位、原汇总返回及目录失效竞态 |
| 2 | Android 首级日更与会议、正文先显、受控预载、首次配置 |
| 3 | Mac 首次提醒、连接总览、分步配置与主导航 |

已执行的定向检查包括：Mac 汇总 20 项、渐进界面 5 项、同步 5 项、首用 2 项、设置 36 项、云端 64 项、Zotero 界面 10 项；原生正文与来源 57 项、就绪和竞态 17 项、原生 WebKit 与操作栏 38 项、预载 6 项、读取范围 8 项以及原来源目录 8 项。Android 图片、链接、导航和返回栈共 44 项；另在隔离 API 35 模拟器执行 4 项凭据状态界面检查。不同测试的数量不相加宣称一次完整实机验收。

公开站点目录在 2026-11-01 实际下载并逐片核对大小、SHA 和条数：22 个分片、8,875 条记录，其中 8,518 条论文、212 条会议汇总、142 条日更、3 条说明页。目录验证、原生来源测试与最终安装包验证各有独立范围。

## 升级和证据范围

应用标识、资料目录、钥匙串服务、持久化格式和原归档映射不变；本轮新增导航与加载状态主要保存在内存。原笔记、费用、正文修订和来源材料继续由原读取器核验，不重新生成或清零。

未改变的模型、Zotero 写入、备份恢复等服务功能复用原版本已有实测证据；这不表示新版重新对真实账号执行全部操作。原 [Mac 功能状态](mac-app-acceptance-status.md)、[云端与发行表](mac-app-cloud.md)和 [Android 功能表](android-feature-parity.md)中的旧发行记录仍只证明其原版本。1.1.0 的最终构建、覆盖升级、远端草稿及下载检查另绑定本轮实际安装包；旧版远端检查不作为新版的通过凭据。
