# 论文速递工作台 Mac 版：坚果云保存与恢复

工作台通过坚果云 WebDAV 保存独立的完整研究版本。使用前请为工作台单独生成第三方应用密码；系统登录密码及 Zotero 的附件连接不用于此功能。服务地址为 `https://dav.jianguoyun.com/dav/`，应用密码规则见[坚果云官方说明](https://help.jianguoyun.com/?p=2064)。

## 同步收藏和笔记

在论文库或 WebDAV 设置点击“一键同步 WebDAV”，就能与同账号、同目录的安卓设备合并网站论文的收藏、收藏时间、待读、笔记、批注和阅读进度。若两端编辑了同一条笔记且正文不同，工作台会保留各自的版本。文件和研究历史通过下文的完整备份保存。[两端同步规则](android-cloud-contract.md#一键同步个人资料)

## 配置与保存

一次保存先取得研究目录在同一时点的完整材料，再上传这份固定材料。后续编辑不会混入正在上传的旧版本；这也是中断后必须选择“继续保存同一快照”，而不能重新采集资料覆盖原版本的原因。

1. 打开“设置→WebDAV 备份”（旧版本称“坚果云资料”），填写账号与独立目录，默认目录为 `PaperDigest`。目录名为 1–64 位英文字母、数字、连字符、下划线或点，以字母或数字开头，不能包含连续两点或使用 `Zotero` 名称。
2. 在原生安全窗口选择“仅本次使用应用密码…”或“保存应用密码到钥匙串…”，主动检查连接。
3. 编辑保存完成且没有其他任务后，选择保存完整研究空间。采集期间短暂冻结资料，取得一致快照后可继续阅读和编辑；后续改动进入下一份快照。
4. 查看上传与回读结果。已有未完成快照时，“继续保存同一快照”沿用原编码、目标与检查点，不重新采集后来的改动。

### 仅本次密码与持久保存有什么区别

选择“仅本次使用”时，密码只在当前进程内存中，退出或更换目标后清除，不读写钥匙串。自动保存先暂停；本次检查通过后可以继续，重启后仍暂停，需要重新提供本次密码并检查。

选择持久保存时，密码进入本应用钥匙串，重启后可主动检查，无需每次重填。打开设置或刷新本机状态不会自动读取钥匙串或联网。两种方式都须通过真实连接检查，密码已经保存不等于远端目录已经可用。

## 备份内容与限制

备份保存应用研究目录中的笔记、标注、收藏、待读、阅读状态、个人文献、模型原始输入与响应、用量、离线资料及 Zotero 归档记录，包括隐藏的普通研究文件。**本机响应校验密钥不迁移**：两类 `ModelUsage/response-integrity` 密钥及其大小写别名在读取内容前排除。系统钥匙串、Zotero 自身数据库和应用目录外的文件不在备份范围。

| 项目 | 当前范围 |
|---|---|
| 原文件总量 | 最多 512 MiB |
| 编码总量 | 最多 750 MiB |
| 文件数 | 最多 100000 项 |
| 分块大小 | 8 MiB |
| 自动保存 | 默认关闭；应用运行时每 6–168 小时，默认间隔 24 小时 |
| 传输与存储 | HTTPS 传输；没有额外端到端加密 |
| 多设备 | 各版本独立保存，无逐字段双向合并 |

超限时整份备份停止，不裁掉文件来凑成“完整”。每个版本用 UUID 这一唯一编号建立独立目录；文件按 8 MiB 分块上传，再逐块下载回来比较实际字节。所有块以及最后的完成清单均核对成功后，才登记完成。不同设备的旧版本保留，不按较新的时间戳覆盖对方资料。

全新上传和续传的分块顺序不同。Mac 在没有续传检查点时，对每块直接 PUT 并带 `If-None-Match:*`；收到 412 或丢失应答后仍回读该块并逐字节核对，不再先逐块 GET 探测。Mac 续传和 Android 当前实现仍先 GET 已有对象，缺失时才 PUT。目录建立也按端区分：Mac 只在本次快照自己的 UUID 目录上信任 `MKCOL 201`，`/dav/`、目标目录和月份等共享路径仍用 `PROPFIND Depth:0` 确认它确实是集合；Android 目前对每个新建目录都执行 `PROPFIND`。

这些顺序变化没有放宽限流、冷却、请求预算、检查点保存顺序或远端字节核验。每块仍回读比对，完成清单仍最后写入并读回，字节不符、丢失应答和预算耗尽仍停止并保留材料。

版本按 UTC 月份归档，显示时间采用本机时区。查询时须区分“没有版本”和“没有读完”：目录被服务截断、XML 无效、身份异常或中途限流时，应用会提示读取失败，不能把已取得的一部分当作完整列表。未完成目录不列为可恢复版本。

服务返回 HTTP 429 或 503 时，按 `Retry-After` 指定的等待时间暂停，保留冷却记录；认证失败则暂停传输和自动保存，等待修正连接后重新检查。退出应用后不运行定时任务。

## 中止续传与恢复

账号失效、目标不可写或材料损坏时，可选择“保留快照并停止本次续传…”。确认后，现有材料和检查点原样保留在本机，云端半成品与旧版本也保留，自动保存暂停。只有完整且通过校验的 `snapshot.paperdigest` 可通过“文件→恢复个人资料…”恢复；缺失或损坏材料不保证可恢复。

选择版本后，应用先核对云端清单与列表中的记录是否一致。随后下载并核对全部分块、路径和备份结构，再请求原生确认。取消或失败保留当前资料；确认后保留恢复前副本并完成替换。快照之后的笔记、解析和费用原始记录可从副本找回。

本机模型连接、网络与预算设置保留，已派发请求身份及原时间合并，不返还已使用次数。API、Zotero 与网盘凭据不随备份替换；旧备份里的本机校验密钥只核原字节、不导入，目的端现有密钥保留。含密钥的旧快照不能继续上传或重新导出，原材料仍留本机。详见[数据与恢复](mac-app-data.md)。
