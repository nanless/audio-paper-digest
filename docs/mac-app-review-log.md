# 论文速递工作台 Mac 版：独立审查说明

独立审查覆盖数据、原生操作、模型请求、Zotero、云端恢复和发行包。审查者核对实际实现与对应材料；具体使用与测试范围见[验证说明](mac-app-validation.md)。历史失败、修复前后结果及私人材料留在受保护记录中，本页说明当前维护要求。

## 审查重点

| 范围 | 当前要求 |
|---|---|
| 论文与来源 | 明确论文身份、版本和原始 PDF 字节；旧选区、晚到回复及其他页面不取得当前论文权限 |
| 原生操作 | 菜单、对话框、设置和键盘操作有明确对象；退出、维护、取消时保护编辑内容与已有资料 |
| 模型与费用 | 真实输入、响应、用量和请求身份保留；截断及保存失败仍失败，未知消费不填零、不自动重发 |
| 凭据与诊断 | 密钥只走原生安全输入与应用钥匙串；模型与代理失败使用固定安全诊断，原始响应留在私人材料中 |
| 笔记与缓存 | 保存失败保留草稿与旧文件；来源更新、目录移除和清理不删除私人研究及依赖版本 |
| Zotero | 绑定个人账号与文库实例，保存后逐项回读，保护人工编辑和部分完成记录 |
| 备份恢复 | 校验全部原字节、路径和大小，确认前不替换，保留恢复前副本、本机配置和已派发次数；本机校验密钥不迁移 |
| 安装包 | 核来源、版本、实际文件、许可、签名、架构与隐私排除，再对真实下载文件比较 |

## 结果如何使用

正常输入与失败分支分别验证。模拟服务用于错误、并发与恢复分支；原生窗口、真实服务和安装后的操作使用各自的实际记录。未变化的实现和材料可复用已核结果，新变化按影响范围复验。

1.0.1 源码与准备包已经过自动化和静态安全检查，新包未执行图形启动。既有已安装版本的实际操作继续保留原版本范围。当前包使用 ad-hoc 本地签名，未 Apple 公证；实际支持范围见[Mac 使用说明](../apps/macos/README.md)。

维护时至少完成五轮有实质改进、测试、独立审查及必要修复复验；数量不是替代质量的标准。原始失败和费用不删改，核心故障没有实际解决时不写通过。功能项目及发行条件分别见[验收矩阵](mac-app-acceptance.md)和[云端与发行清单](mac-app-cloud.md)。
