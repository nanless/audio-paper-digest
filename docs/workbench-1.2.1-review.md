# 工作台 1.2.1：沿用网站多级分类

本次纠正 1.2.0 对“分门别类”的错误理解。收藏类别应直接使用网页每篇论文已有的详细多级分类，不能让使用者另建一套。Mac 目标为 1.2.1（构建号 4），Android 为 1.2.1（构建号 7）；正式发行状态和实测结果完成后在本文登记。

## 范围与权威

两端保留网站索引中的完整分类字段，在正常同步时读取网站已发布的当前快照与历史版本目录。以原词表版本核对每篇导读的实际分类，再沿网站当前目录展示路径。当前发布网站有 386 项、九个分面；仓库中另一份作者配置不能替代已发布目录。

取消创建分类、重命名、手工归类和批量归类入口。网站祖先节点只用于层级导航，不能写入论文的直接标签。同一论文的多篇导读分别保留分类，不跨导读拼接筛选条件；按收藏时间分区继续独立使用。

个人资料格式保持兼容。旧文件夹、已有收藏时间、未知字段与历史备份保留；本次只改变分类的来源和操作方式，不删除用户旧资料。旧缓存缺结构、网站未提供分类和暂无法核对的情况须明确区分，不能猜补。

## 审改与验证

本次由 Mac、Android 和独立交叉审查三个子代理分工执行，保留首次失败和修正后的结果。下面按实际问题与验证范围记录，不把相同检查重复运行算成新一轮。

|---|---|---|

| 2：接通数据 | 两端保存各导读原分类；正常同步配对资源，支持冷载与资源失败提示 | Mac 新原生 12 项；Android 3 项正常同步、冷载与缺资源设备检查（计入下方 11 项） |
| 3：对齐原站 | 修复 Android 将合法历史版本误拒的问题，补别名歧义与祖先闭包检查 | 共享 14 条正负记录及跨导读反例；独立全 8,875 条 Kotlin 与网站原代码逐字段一致，零差异 |

共享[分类对照夹具](../tests/fixtures/workbench-website-taxonomy-golden.json)的期望由网站原始分类代码计算，涵盖真实三级路径、历史标签、科学主题、固定兼容记录与异常资料；其裁剪词表仅供测试，不是生产词表或来源资格。独立全量对照同时核对分类状态、原选中编号和标签、当前编号及完整祖先路径。

Mac 打包首轮运行 87 项，52 项通过、35 项因新增资源在隔离测试映射中缺失而失败。网站自有分类模块改放正常受版本管理的界面资源目录后，仅复验原 35 项失败集合，全部通过；新加的 1.2.1 发行说明测试另行通过。原失败记录保留，不为证明相同结果重复另外 52 项。

此次定向检查没有请求付费模型、真实服务账户或私人文库。Android 新界面设备为专用 API 35 模拟器，本次没有新增实体手机或 API 28 实测；Mac 原生数据测试与浏览器界面测试分别记录，不能代替最终安装包窗口检查。旧版未变化服务仅复用对应历史证据。
