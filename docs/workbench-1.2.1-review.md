# 工作台 1.2.1：沿用网站多级分类

本次纠正 1.2.0 对“分门别类”的错误理解。收藏类别应直接使用网页每篇论文已有的详细多级分类，不能让使用者另建一套。Mac 目标为 1.2.1（构建号 4），Android 为 1.2.1（构建号 7）；正式发行状态和实测结果完成后在本文登记。

## 范围与权威

两端保留网站索引中的完整分类字段，在正常同步时读取网站已发布的当前快照与历史版本目录。以原词表版本核对每篇导读的实际分类，再沿网站当前目录展示路径。当前发布网站有 386 项、九个分面；仓库中另一份作者配置不能替代已发布目录。

取消创建分类、重命名、手工归类和批量归类入口。网站祖先节点只用于层级导航，不能写入论文的直接标签。同一论文的多篇导读分别保留分类，不跨导读拼接筛选条件；按收藏时间分区继续独立使用。

个人资料格式保持兼容。旧文件夹、已有收藏时间、未知字段与历史备份保留；本次只改变分类的来源和操作方式，不删除用户旧资料。旧缓存缺结构、网站未提供分类和暂无法核对的情况须明确区分，不能猜补。

## 审改与验证

正在进行实现与多轮交叉审查。共享[分类对照夹具](../tests/fixtures/workbench-website-taxonomy-golden.json)的期望由网站原始分类代码计算，涵盖真实三级路径、历史标签、科学主题、固定兼容记录与异常资料；其裁剪词表仅供测试，不是生产词表或来源资格。

正式构建、升级窗口、备份恢复、远端检查与安装包验证尚未在本文登记，不把上一版的通过结果当成本次新增分类的验证结果。1.2.0 的[历史审改记录](workbench-usability-review-20261101.md)保持原样。
