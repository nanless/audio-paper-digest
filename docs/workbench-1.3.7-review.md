# 工作台 1.3.7 审改记录

Mac 和 Android 源码均为 1.3.7，构建号均为 15。审查按 Mac 原生窗口和网页资源、Android 原生页面及后台任务、两端共用的云端规则和发行脚本分工。源码审查覆盖启动、阅读、设置、备份、恢复和发行入口，以下列出已重现并修复的问题和验证范围。

## 第一轮　恢复的版本和后台任务

Mac 先列出云端备份，再由用户选定要恢复的版本。如果云端在两步之间用同一编号换了清单，旧实现会读取新内容。修复后，每次列表生成当前有效的选择编号，绑定账号、目录、凭据代次和原清单摘要。实际下载前先重新校验原清单，内容或连接变更时停止，已下载分块和本机资料不会被作为成功恢复写入。

Android 把备份任务交给系统后，界面以同一个任务编号显示排队、正在运行、取消与完成。系统未确认接收、前台启动失败或已有系统任务丢失时，结束原任务行，保留已经采集的材料。工作台拒绝重复派发同一正在执行的任务。

Mac 用隔离的 AppKit 和 WKWebView 对照检查通过 187 项，覆盖原清单替换、旧选择、取消和恢复。云端页面浏览器测试通过 66 项。Android 使用 API 35 隔离模拟器通过 7 项，覆盖前台启动失败、重复任务及取消入口。

## 第二轮　启动、阅读和笔记

Mac 新同步按钮进入标题按钮组后，目录切换控件还沿用旧的插入位置，主窗口在读取目录之前中止。修复后目录、日更、会议与读论文入口可再次启动。同步提交前还会保存正在编辑的笔记、批注及实际改变的阅读位置。干净的笔记编辑器收到远端笔记后会刷新。仍有本机草稿时，保存沿用打开草稿时的修订，避免用旧正文覆盖远端更新。

Android 将恢复确认和页面动作绑定到生成它们的工作区。安装期间拒绝旧页面的编辑，恢复完成后不再采纳旧页面卸载时的阅读位置。已替换的资料即使与旧笔记有相同修订号，也不会接受排队中的旧写入。暂存文件验证失败时保留原确认和原件，修复后可以用同一确认重试。

两端按实际 UTC 时间比较收藏记录。笔记正文一致时合并，正文不同保留各设备版本。已观察过的设备记录还会核对原始字节摘要。远端修订回退、原记录缺失、同一修订下字节变化或旧备份试图覆盖同一设备尚未确认的云端编辑时，停止这次合并。

Mac 主窗口浏览器对照通过 22 项，原生同步草稿对照通过 2 项，启动续读另通过 5 项，覆盖无历史、最近记录、目录外保留文献和失效元数据。另跑阅读返回、笔记索引、导航、设置和网站分类页面。Android 云端与个人同步单元测试通过 64 项，Mac 合并测试也通过相同的跨端资料样例。

## 第三轮　并发上传、构建和发行

两端更新已有设备同步文档时，带上服务器给出的强 ETag。ETag 是读取时收到的版本标记。服务器返回 412 时表示原记录已变化，应用保留本机编辑并提示重新同步。没有安全版本标记时，已有记录只读。首次创建使用仅在文件不存在时才可写入的条件。传输回读仍须核对实物字节。

Mac 按构建输出目录和安装目录分别排队，避免两个候选互相覆盖。安装注册失败恢复原应用目录，私有验收通道不能覆盖常用安装。联合发行计划绑定稳定草稿、固定提交、注释标签对象、两端验收和全部附件。下载副本先核对实际字节，再重新验包。返回命令前再检查来源提交。

Mac 传输测试通过 43 项，含首次创建、已有记录条件更新、无可信版本标记和竞争写入。Android 的双写测试让两个客户端先读到同一版本，再竞争上传，只有一方成功。Mac 构建替换测试通过 4 项、发行核验通过 89 项。Android 联合与独立发行脚本分别通过 47 项和 28 项。

## 补充复审　限流与取消

Mac 将服务器的限流截止时间保存在当前连接资料中。检查连接、读取版本、上传或个人同步遇到限流，重建服务后仍先等待。冷却期间不读取凭据、不发送请求。更换目标后使用新目标的状态。异常重试时间回退为一分钟，保存续传记录时遇到真实取消会保留取消状态。此轮后的 Mac 云端传输测试共 45 项。

两端跟踪的 6 个 Shell、92 个 JavaScript 和 20 个 Python 文件通过语法检查。Mac 原生源码通过 Swift 类型检查。安卓调试应用和设备测试包使用当前源码编译，发行脚本另外检查签名、资源、包内容和设备选择。

## 合入 main 后的复测

合并期间网站接口和本机资料格式也已更新。两端按各自个人资料根对象选择新旧收藏格式。新工作区同步后保存新版收藏，旧资料继续沿原格式读写。两端使用新工作区验证第一次同步、再次同步以及收藏仍可读取。

Android 合并包在隔离模拟器通过 9 项恢复、阅读位置和导航测试。先前一次导航测试被模拟器系统无响应弹窗遮挡。正常重启隔离设备后，按原断言重新完成日更链接、论文页面和返回路径。Mac 合并后的主窗口、云设置和首次配置浏览器测试也通过。
