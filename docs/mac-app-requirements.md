# 论文速递工作台 Mac 版：功能与使用范围

工作台面向桌面论文阅读和个人研究。网站继续由论文速递生产系统发布；客户端读取已有成果，个人研究单独保存。安装、配置与日常操作见[Mac 使用说明](../apps/macos/README.md)。

## 主要功能

| 功能 | 使用结果 |
|---|---|
| 资料库 | 同步全部已发布论文，浏览完整九分面、多级网站方向及零结果节点；按标题、作者、来源、日期与评分组合查找，管理收藏和待读 |
| 图文阅读 | 完整导读、原图、表格、公式、来源及评分明细；默认单栏，按需打开 PDF 双栏 |
| 原文研究 | 使用自己的模型服务，选择导读或 PDF 实际提取的文字，保存问题、回答和原文位置 |
| 个人笔记 | 自动保存 Markdown 笔记、摘录、标注和阅读位置，按论文检索与返回来源 |
| 导出与离线 | 导出引用和研究材料，保存指定版本完整离线包，查看容量与清理预览 |
| Zotero | 向本机个人文库归档选定书目、完整来源、原 PDF、自包含导读和个人材料，逐项回读 |
| 坚果云 | 保存完整研究快照，沿原快照续传，按版本下载与恢复 |
| 后台任务 | 显示真实阶段、进度、错误和取消结果，保存中断记录及可恢复材料 |

这些功能按“查找→阅读→核对原文→保存个人材料→按需归档或备份”的顺序配合。资料库和网站同步提供已发布内容；个人研究才使用自己的模型服务。Zotero 保存所选论文和材料，坚果云保存整个研究空间，两者不能互相代替。

## 数据与来源

客户端使用公开目录、搜索分片、已发布正文与引用文件。日更、会议和历史论文采用同一读取方式，保留网站原评分、分类和来源版本。相同论文按明确身份合并，缺失作者、机构、DOI 或日期保持未知。

当前采用网站公开数据和正文适配：读取网站已有目录，再从已发布页面提取导读。应用可以使用公开目录 `client/index.json` 和已发布的论文附属文件 `client/papers/`。规划中的专用详情出口尚未部署。客户端不读取生产 `.env`、账号池或可变检查点，不在本机重新生成全库论文。

个人研究存于 `~/Library/Application Support/PaperDigest/`；模型、Zotero 和持久保存的网盘密码由本应用钥匙串管理。个人模型消费与生产系统分开记录。

## 桌面操作

- 使用 AppKit 系统窗口、菜单和独立设置窗口，`⌘,` 打开设置。
- 默认单栏导读；打开 PDF 后左侧为导读、解析或笔记，右侧为原文，比例可调。切换后保留阅读与编辑上下文。
- 窗口可缩放，提供键盘导航、系统读出、浅深外观、字号及对比度支持。科学图和 PDF 保留原色。
- 关闭窗口不退出应用；退出后不运行任务或定时保存。

## 支持限制

当前源码版本为 1.4.4（构建号 20），该版已于 2026-11-05 公开发布，公开安装包以发行页为准，面向 Apple Silicon、macOS 15 及以上，使用本地 ad-hoc 签名，未 Apple 公证。1.4.4 没有重做 69 项人工图形验收，构建与签名核验见发行记录；1.4.3 的发行记录保留在上一版。1.4.4 的改动与验证范围见[1.4.4 记录](workbench-1.4.4-review.md)，安装、升级和界面操作的最新完整范围仍属 1.3.0，见[1.3.0 记录](workbench-1.3.0-review.md#正式发行与升级检查)。签名、附件与匿名下载核验见[客户端发行核验](client-release-verification.md)，性能改动见[客户端性能](client-performance.md)。正式包升级、窗口、首配和公开下载检查，以及既有服务操作的版本范围见[验证说明](mac-app-validation.md)。

个人解析只使用提取文字，没有文字识别（OCR）或图像理解。扫描页可以显示原件，但没有可提取文字时不能作为文字研究材料；资料库全文搜索也不包含 PDF 原文。

Zotero 当前支持本机个人文库，持续授权是文库范围。保存后从本机 Zotero 重新读取并核对材料，称为“回读”；这不证明 Zotero 已把文件同步到云端。坚果云保存独立版本，不提供逐字段双向合并；备份以 HTTPS 传输，没有额外端到端加密。

源码、受控说明、测试和许可提交版本库；私人资料、凭据、运行状态和构建产物分开保存。原始失败、来源、授权、请求次数、费用和恢复材料保留。模型认证、配额或保存故障停止新派发；取消和失败不视为零消费。真实模型、Zotero 写入、原生窗口与安装包检查分别记录实际范围。
