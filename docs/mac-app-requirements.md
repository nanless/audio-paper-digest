# 论文速递工作台 Mac 版：功能与使用范围

工作台面向桌面论文阅读和个人研究。网站继续由论文速递生产系统发布；客户端读取已有成果，个人研究单独保存。安装、配置与日常操作见[Mac 使用说明](../apps/macos/README.md)。

## 主要功能

| 功能 | 使用结果 |
|---|---|
| 资料库 | 同步已发布论文，按标题、作者、来源、任务、方法、日期和评分查找，管理收藏与待读 |
| 图文阅读 | 完整导读、原图、表格、公式、来源及评分明细；默认单栏，按需打开 PDF 双栏 |
| 原文研究 | 使用自己的模型服务，选择导读或 PDF 实际提取的文字，保存问题、回答和原文位置 |
| 个人笔记 | 自动保存 Markdown 笔记、摘录、标注和阅读位置，按论文检索与返回来源 |
| 导出与离线 | 导出引用和研究材料，保存指定版本完整离线包，查看容量与清理预览 |
| Zotero | 向本机个人文库归档选定书目、完整来源、原 PDF、自包含导读和个人材料，逐项回读 |
| 坚果云 | 保存完整研究快照，沿原快照续传，按版本下载与恢复 |
| 后台任务 | 显示真实阶段、进度、错误和取消结果，保存中断记录及可恢复材料 |

## 数据与来源

客户端使用公开目录、搜索分片、已发布正文与引用文件。日更、会议和历史论文采用同一读取方式，保留网站原评分、分类和来源版本。相同论文按明确身份合并，缺失作者、机构、DOI 或日期保持未知。

当前采用网站公开数据和正文适配；规划中的 `desktop/v1` 专用出口尚未部署。客户端不读取生产 `.env`、账号池或可变检查点，不在本机重新生成全库论文。

个人研究存于 `~/Library/Application Support/PaperDigest/`；模型、Zotero 和持久保存的网盘密码由本应用钥匙串管理。个人模型消费与生产系统分开记录。

## 桌面操作

- 使用 AppKit 系统窗口、菜单和独立设置窗口，`⌘,` 打开设置。
- 默认单栏导读；打开 PDF 后左侧为导读、解析或笔记，右侧为原文，比例可调。切换后保留阅读与编辑上下文。
- 窗口可缩放，提供键盘导航、系统读出、浅深外观、字号及对比度支持。科学图和 PDF 保留原色。
- 关闭窗口不退出应用；退出后不运行任务或定时保存。

## 支持限制

当前发行目标为 Apple Silicon、macOS 15 及以上，使用本地 ad-hoc 签名，未 Apple 公证。新 1.0.1 包的检查范围及既有已安装版本的实际操作范围见[验证说明](mac-app-validation.md)。

个人解析使用提取文字，没有 OCR 或图像理解；资料库全文搜索不包含 PDF 原文。Zotero 当前支持本机个人文库，持续授权是文库范围，本机回读与 Zotero 自身云同步分别处理。坚果云保存独立版本，不提供逐字段双向合并；备份以 HTTPS 传输，没有额外端到端加密。
