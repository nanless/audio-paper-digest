# 工作台 1.3.0：全站分类与两端界面改进

全站分类功能已完成定向审查，正在收尾正式窗口发现的辅助功能问题及最终发行验收，公开版本仍为 [1.2.1](https://github.com/nanless/audio-paper-digest/releases/tag/v1.2.1)。Mac 与 Android 都能从网站完整分类找到全部论文，并整理导航、筛选和阅读返回。Android 对齐功能与数据规则，界面按手机、平板和分屏分别适配。下面按实际结果记录，源码版本不能替代正式包验收与公开状态。

## 资源与操作范围

| 网站或现有能力 | 本轮处理 | 验收重点 |
|---|---|---|
| 全站论文库、日更、会议及专题 | 保留独立入口，分类浏览覆盖全部论文 | 不是只查询收藏；会议汇总与单篇论文分别沿用原来源 |
| 九分面、多级分类目录 | 使用网站实际发布的完整目录，显示零结果节点；增加目录检索、路径和说明 | 中文、英文与别名定位同一编号；父类包含子类，不把祖先写成论文的直接标签 |
| 网站高级分类筛选 | 收进高级筛选区域，保持同分面或、跨分面且、直接或含子类、全部或主要标签语义 | 类型、领域与其他组合条件须由同一篇已发布导读满足，不能跨导读拼条件 |
| 关于、研究资源、归档及订阅 | 提供明确入口，复用已发布页面或安全的官网链接 | 不复制一份容易过期的网站内容；分类浏览不触发全库 PDF 下载 |
| 收藏和待读 | 保留，收藏时间分区与网站分类独立组合 | 不新增自建分类；旧文件夹和未知时间仍按原格式保存与备份 |
| 完整导读、PDF、图片、笔记和个人研究 | 保留；改善阅读返回、信息层级与大字号 | 返回原列表位置、分类和筛选；图与 PDF 保留原色，来源与版本检查不减弱 |
| 引用、导出、Zotero、WebDAV、离线及恢复 | 保留实际能力，收拢重复说明与进阶动作 | 不因简化页面删除数据，不将已验证引用替换为界面拼接内容 |
| 重复的平面任务、方法筛选和大块说明 | 合并到分类与筛选入口，减少首屏占用 | 控件可发现、选中条件可见、有明确清除方式；首次配置仍能找到下一步 |

当前公开目录有 386 个概念、九个分面。此数量用于本次固定网站样本的对照；生产界面随正常同步读取完整新目录，不把 386 写成永久上限。分类来源、历史快照及逐导读核验沿用 [1.2.1 的规则](workbench-1.2.1-review.md)。旧版兼容数据不能充当新分类来源。

网站元数据搜索在各导读内匹配，不能把导读甲的关键词与导读乙的分类、来源或评分拼接。客户端另有本机已读正文与私人笔记的论文级搜索扩展，界面须说明这一范围；该扩展不更改任何导读原标签，也不授予原文、引用或阅读来源资格。Mac 的本机正文搜索采用明确的返回字段，普通或未知的论文编号列表不能绕过逐导读关键词匹配。

网站批量清单导出与客户端当前单篇导出存在差异。本轮保留单篇真实引用与研究导出，并提供官网资源入口；如后续增加批量导出，应独立实现选择、版本、保存和取消规则，不能把当前阅读资格扩展给未核对的其他论文。

## 界面目标

Mac 使用适合桌面的导航和分类侧栏，给论文列表与阅读内容足够空间。分类展开与应用筛选分别操作，避免找目录时不断跳页；搜索、分页、选择和滚动按视图保留。筛选摘要应说明当前范围及组合规则。

Android 使用紧凑内容流和可展开的分类面板，宽窗口再提供目录与内容并排。手机首屏优先显示可阅读的论文，避免连接提醒、标题、搜索、快捷条件和解释重复堆叠。系统返回、输入法、大字号、深色和分屏均要检查；桌面侧栏不能直接压缩成手机页面。

两端采用一致的内容层级、克制的强调色与清晰的交互状态。美观检查同时看实际信息密度、对齐、留白、中文换行、触控范围与键盘焦点，不以更换颜色代替操作改进。

## 分轮审查与实际结果

Mac、Android 与独立交叉审查分别由三个子代理承担，主执行者维护范围、文档与发行。每轮围绕真实新问题修改并按影响范围检查，保留首次失败；未变化的服务复用其原有证据，不把重复同一检查计作新的实质轮次。

|---|---|---|

本轮不读取真实服务凭据，不自动请求付费模型，不修改用户正在使用的安装包或资料目录。界面检查使用隔离资料；是否完成正式签名、安装、覆盖升级与发布，另按实际结果补记。

共享[查询对照夹具](../tests/fixtures/workbench-website-query-golden.json)由未修改的网站分类解析器生成，区分实际公开记录与明确的合成边界资料，目录为裁剪测试图。普通查询、逐导读匹配和直接／子树计数均有预期；App 的本机正文与笔记扩展另列七个向量，不能将其称为官网自带功能。首次 Android 计数重复及旧回执未声明正文类型的失败保留，修复后原范围通过。

Mac 独立全量浏览器回放使用原公开 8,875 条记录中的 8,518 条论文导读，按原公开身份投影为 8,157 篇论文，并加载完整 386 项网站词表。实际展开后有 386 个唯一目录节点、九个分面及真实三级嵌套；零结果“标点恢复”、LoRA 路径、折叠后的主要角色摘要与键盘空格操作均核对。1000×700 浅深界面无横溢，初屏第一篇位于 284 像素处。真实两导读实例分别保留 8.4、7.5 评分及各自路径。

上述回放是公共数据的界面投影，未连接用户本机窗口或原生桥，不能替代正常同步、原生冷读、正式包或科学来源资格检查。末尾多导读步骤首次因回放残留分类而超时，原报告保留，仅另续未完成步骤，不把该超时认定为产品问题。前缀查询另外分型核查：实际带有 `paperId` 的记录可查到；真实 `arxiv:2610.38696` 没有该原字段，修正前带前缀查零篇、裸编号查一篇，确认应把可信的合并论文身份也纳入搜索。早期 Node 显示索引性能测量仅对应当时的界面源码，不当作最终原生切页帧率。

Mac 原生 `LibraryService` 完整 12 组、150 条断言通过，涵盖逐导读原题与持久全文索引冷读。新目录、收藏、实际 `native.js` 的隔离桥接、旧资料库、10,005 条分页及原生收藏界面通过；字体 8 项、汇总 20 项通过。额外的上下文 8、汇总焦点 12、小窗口 12 项及正常打包 89 项在 `06a5f431` 上执行，221 个 Mac 跟踪文件起止 SHA 完全相同。

随后独立查看 1440 浅深截图发现重复平面控件和详情展开后的列对齐问题，再作一组仅界面的修正并提交 `80968919`。资料库、收藏和工作区三个入口分别复验通过；原 205 条任务加日期结果保留，新增 614 条方法关键词结果。展开长详情前后复选框、日期、评分与标题的位置不变。先前 89 项打包、32 项界面回归保留其原来源范围，没有把它们写成在后续修正上重新执行过。

Android 生产界面十个文件已固定并提交 `4795a73b`。真实正常同步取得 8,157 篇论文、8,518 篇导读和 386 项分类，原收藏元数据不变，无模型或真实账户请求。该 API 35 模拟器进程 PSS 约 277 MiB，未观察到内存溢出或无响应；这不是所有品牌设备或最低 API 的新实测证明。

新手机目录在输入法打开时收起无关标题与筛选栏，前两条 ASR 候选完整位于固定结果按钮上方；设备检查比较完整高度、可见高度及按钮位置，并实际点击复选框，两个执行者独立看图通过。旧遮挡图保留。最后设备组合首轮 20 项通过、一项多选用例在触摸注入前抓到旧布局节点；等查询终态与键盘布局稳定后，该尾例 4.452 秒通过，仍保留只加入 `context:1` 及不使用旧整数组覆盖接口的断言。随后冻结九个测试文件，最终 21 项合组全部通过，用时 63.367 秒；原分批失败和尾例结果分别保留。这是 API 35 调试版隔离 fixture 的设备回归，正常同步的全量库和正式 APK 的实际操作分别留证，不将 21 项全称为正式包全量实测。

本机检索缓存的两项单测和私人材料检索的两项单测已通过。缓存最多四个查询、十万个命中编号，目录或实际缓存身份改变即清空；显式重试只清当前查询，成功结果仍可复用。私人扩展只查笔记及批注文字、评论，不搜索原始请求、费用或整个资料 JSON。已有 `RealApp`、`RealWorkspace` 与 `Responsive` 测试只同步旧控件选择器和文案，本轮没有将它们全部重新运行，不能计入最终 21 项设备集合。

`678dd01e` 的正式 Android APK 使用原发行证书，在原 1.2.1 独立验收设备的另一个克隆中实际覆盖升级，保留原 UID 与首次安装时间。安装后首次启动前，61 份原研究文件 SHA 和个人资料原字节相同；界面检查后，收藏、收藏元数据、笔记、批注、待读、会话六个完整对象仍相同，旧文件夹只按原格式保留，没有变成自建网站分类。另一个全空 API 35 设备完成正式新装和首次配置提示检查。正式升级副本为离线状态，使用原已配对词表与缓存；联网全量同步是另一调试环境。第一次打开未缓存论文正确报离线错误，后续改用真实已缓存导读完成阅读与返回；未把离线失败或旧控件选择器错误写成通过。此范围不代表所有实体手机或最低 Android API 的新实测。

同一来源的 Mac 正式 ZIP 副本在独立旧资料副本中实际显示全量论文、三级分类、别名与零节点，打开真实已缓存导读后返回原分类、查询和选择，收藏的近期、月份及未知时间分区可操作。独立空资料首启能直达 WebDAV 三步配置及 Zotero 本机连接说明。六类原个人对象保持相同。系统辅助功能树随后漏读部分可见列表，已单独阻断发行，不以截图可见或其他功能通过替代这一项；未修改用户正在使用的 Applications 安装包或资料。
