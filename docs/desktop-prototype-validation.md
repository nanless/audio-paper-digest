# Mac 交互原型验证记录

2026-10-24，范围为 [`prototypes/macos-research`](../prototypes/macos-research/README.md)。它是桌面浏览器交互原型；原生 Mac 打包、全站同步、真实模型请求和 Zotero 写入尚未实现。以下结论不授予论文分析、来源或发布资格。

## 使用的真实内容

MiCLA（2610.27491v1）已有网站导读约 12,045 字符、15 条已发布书目样本、3 张科学图、4 张表、4 个结构化 MathML 公式、13 页原始 PDF。未重新请求 LLM，没有修改论文原记录。英文摘要来自 PDF 原页，合并排版换行而不改数值与用词。

PDF 与图每次初始化读取实际字节并核对 SHA-256。PDF.js 5.6.205 显示原 PDF 和实际文字层，页 1、5、13 的像素及文本已分别检查；原件和裁图留在忽略的本机资产目录，准备入口可按固定配方重建并核对。

## 已执行检查

- 可重复的 `smoke.mjs`：16 组实际浏览器回归，覆盖导读、评分图注、PDF 页与缩放、选区回跳、解析输入、笔记刷新、收藏与搜索、其他论文详情、设置、归档、任务、保存失败、快速切栏、多尺寸深色、缺失与篡改资产。
- 独立功能审查另有 18 条检查记录（其中 3 条为 PDF 栅格证据），并逐一测试 15 个编号、作者搜索和三种排序；页面异常为 0，网络请求仅指向本机预览服务。
- 独立内容审查核对原正文对象、书目、4 表、4 公式、3 图及 PDF 字节身份，实际展开评分与原图注，并执行第 5 页选区、翻第 9 页、回到第 5 页的来源验证。
- 独立视觉审查实际查看单栏、双栏、论文库、解析、笔记、任务、模型设置、Zotero、空态、深色及 1000、1280、1440、1728 宽的桌面预览。科学图和 PDF 保持原色，宽表局部滚动。
- 本机资产准备入口实际执行，PDF 与 3 张裁图均重建为原预期 SHA。JavaScript 语法与改动空白检查通过。

浏览器测试使用隔离上下文，不覆盖用户在展示窗口的本地笔记。自动化结果、独立报告和截图保留在本次任务输出目录，生成的 `.qa/` 不进入 Git；可用 README 的命令重新生成。

## 发现、修复与独立复验

| 问题 | 修复及复验 |
|---|---|
| 来源按钮标为选区页却固定跳第 1 页 | 绑定实际已渲染页，回跳第 5 页实测通过 |
| 翻页期间可能用新页码标记旧画布文字 | 新渲染期间隐藏旧页，只采纳有效实际渲染页；选区两端均须在原文容器内 |
| 标题整理隐藏了八维评分，文末仍引用页首 | 页首提供真实原评分与作者机构展开区，未知机构保持原状态 |
| 方法图原图注被隐藏 | 改为明确的原图注展开区，大图保留完整来源说明 |
| 缺 PDF 或图片时仍可能显示样稿完成 | 实际 GET 与 SHA 检查；缺失/篡改反例下任务标未齐、相应归档项禁用 |
| 快速开关 PDF 时平滑滚动竞争 | 布局恢复瞬时定位并关闭自动锚定；连续 8 次开关后语义段落与位置一致 |
| 分隔线可能把 PDF 压得过窄 | 按工作区宽度限制左右最小尺寸，小窗口收起侧栏并保留窗口控件 |
| 设置拖到右侧后缩窗，或关闭期间缩窗后重开，被裁切 | 拖动、resize、重新打开均约束整个窗口；1000×700、1000×760、1120×780 复验完整可达 |
| 笔记保存失败可能被误看作成功 | 真实捕获存储异常，显示失败并保留编辑文字；刷新恢复与失败反例分别通过 |

当前所列原型范围没有已知未解决的交付阻断。该结论不表示任意论文、所有系统版本或正式外部服务已通过验证；正式应用仍按[产品规划](desktop-research-workbench-plan.md)及[数据合同](desktop-data-contract.md)实现与验收。
