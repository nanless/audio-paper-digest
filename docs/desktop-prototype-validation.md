# Mac 交互原型验证记录

本页记录 2026-10-24 对[桌面浏览器原型](../prototypes/macos-research/README.md)的验证，范围仅含原型交互和固定真实样本。原型中的模型与 Zotero 保持未连接；现行原生应用另见[Mac 说明](../apps/macos/README.md)。论文分析、来源及发布仍按正常流程核验。

## 使用的真实内容

MiCLA（2610.27491v1）已有网站导读约 12,045 字符、15 条已发布书目样本、3 张科学图、4 张表、4 个结构化 MathML 公式、13 页原始 PDF。未重新请求 LLM，没有修改论文原记录。英文摘要来自 PDF 原页，合并排版换行而不改数值与用词。

PDF 与图每次初始化读取实际字节并核对 SHA-256。PDF.js 5.6.205 显示原 PDF 和实际文字层，页 1、5、13 的像素及文本已分别检查；原件和裁图留在忽略的本机资产目录，准备入口可按固定配方重建并核对。

## 已执行检查

- 可重复的 `smoke.mjs`：16 组实际浏览器回归，覆盖导读、评分图注、PDF 页与缩放、选区回跳、解析输入、笔记刷新、收藏与搜索、其他论文详情、设置、归档、任务、保存失败、快速切栏、多尺寸深色、缺失与篡改资产。
- 独立功能审查另有 18 条检查记录（其中 3 条为 PDF 栅格证据），并逐一测试 15 个编号、作者搜索和三种排序；页面异常为 0，网络请求仅指向本机预览服务。
- 独立内容审查核对原正文对象、书目、4 表、4 公式、3 图及 PDF 字节身份，实际展开评分与原图注，并执行第 5 页选区、翻第 9 页、回到第 5 页的来源验证。
- 独立视觉审查实际查看单栏、双栏、论文库、解析、笔记、任务、模型设置、Zotero、空态、深色及 1000、1280、1440、1728 宽的桌面预览。科学图和 PDF 保持原色，宽表局部滚动。
- 本机资产准备入口实际执行，PDF 与 3 张裁图均重建为原预期 SHA。JavaScript 语法与改动空白检查通过。

浏览器测试使用隔离上下文，不覆盖用户在展示窗口的本地笔记。自动化结果、独立报告和截图保留在本次任务输出目录，生成的 `.qa/` 不进入 Git；可用 README 的命令重新生成。

## 交互验证结果

| 操作 | 正常结果 |
|---|---|
| 选区后跳回来源 | 绑定实际渲染页，已检查回跳第 5 页。翻页时隐藏旧画布；选区两端均在原文容器内。 |
| 查看评分和方法图 | 页首可展开八维评分与作者机构，未知机构保留原状态；图注展开区和大图保留来源说明。 |
| 资产缺失或变化 | 通过真实 GET 和 SHA 检查标为未齐，禁用相应归档项。 |
| 连续切换 PDF | 8 次开关后语义段落及位置一致，按当前布局即时恢复。 |
| 调节双栏和窗口 | 约束两栏最小尺寸，小窗口收起侧栏并保留控件。 |
| 拖动设置后缩窗或重开 | 整个设置窗口保持可达；检查尺寸为 1000×700、1000×760、1120×780。 |
| 笔记保存与刷新 | 正常刷新可恢复；存储异常显示失败并保留编辑文字。 |

这些结果限定于上述日期、原型和样本。正式应用的安装、同步及真实外部服务分别按[Mac 说明](../apps/macos/README.md)验收；后续可选接口见[数据设计](desktop-data-contract.md)。
