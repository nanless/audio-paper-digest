# Mac 应用图标

当前图标为“石墨边注”：石墨色底板、象牙白折页主体与少量橙色内折。黑白轮廓和负形负责小尺寸识别，橙色细节作为辅助。

构建使用本目录的 [AppIcon.png](AppIcon.png)：1024 × 1024、带透明通道。构建脚本生成 16 至 1024 像素的 10 层 ICNS，并检查尺寸和最高层像素。源 PNG 与生成的 ICNS 一同进入应用。

这是静态图标，不提供 Icon Composer 分层或随系统变化的动态材质。修改图标时保持现有视觉身份，检查浅深背景、透明边缘、小尺寸轮廓及实际 Finder、Dock 呈现。

设计原则见[图标设计说明](../../../docs/mac-app-icon-design.md)。本说明文件不参与图标生成，也不复制进应用。
