# Mac 应用图标

[English](README.en.md)

此目录保存构建 Mac 应用时使用的图标源文件。当前图标为“石墨边注”：石墨色底板、象牙白折页主体与少量橙色内折。缩小时主要依靠黑白轮廓及主体之间的留空辨认，橙色细节只作辅助；这里的留空也称“负形”。

构建读取本目录的 [AppIcon.png](AppIcon.png)：1024 × 1024 像素，带透明通道。脚本由同一源图生成 16 至 1024 像素的 10 层 ICNS，也就是系统在不同显示尺寸下使用的一组图标；随后检查各层尺寸和最高层像素。源 PNG 与生成的 ICNS 一同进入应用。

这是静态图标，不提供 Icon Composer 分层或随系统变化的动态材质。修改图标时保持现有视觉身份，检查浅深背景、透明边缘、小尺寸轮廓及实际 Finder、Dock 呈现。

设计原则见[图标设计说明](../../../docs/mac-app-icon-design.md)。本说明文件不参与图标生成，也不复制进应用。
