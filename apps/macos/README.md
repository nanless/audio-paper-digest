# 论文速递工作台 Mac 版

[English](README.en.md)

工作台把网站导读、论文原始 PDF 和个人研究放在同一个阅读环境中。你可以先读论文速递网站已经发布的图文讲解，再打开原文核对，保存自己的问题、模型回答、摘录和笔记，最后将选定材料归档到 Zotero 文献库。

安装后应用独立运行，无需下载项目源码、启动开发服务器或另装 Node。阅读和同步网站已有内容不重新分析论文；只有主动发起个人研究或连接测试，才会请求自己配置的模型服务。

## 安装与升级

| 项目 | 支持范围 |
|---|---|
| 源码版本 | 1.3.0，构建号 5；公开安装包状态以发行页为准 |
| 系统 | macOS 15 及以上 |
| 处理器 | Apple Silicon（arm64）；当前发行包不同时包含 Intel 与 Apple Silicon 两种架构 |
| 签名 | 本地临时签名（ad-hoc），未通过 Apple 公证 |
| 随包运行时 | Node 24.19.0，使用者无需另行安装 |

Mac 与 Android 的安装包和校验值在同一 [GitHub 发行页](https://github.com/nanless/audio-paper-digest/releases)提供。安装时将解压后的“论文速递工作台.app”或 DMG 中的应用拖入“应用程序”。首次打开若被系统拦截，先核对下载来源与发布校验值，再按 macOS 的“隐私与安全性”提示允许打开该应用。

1.3.0 增加全站多级分类浏览、整理桌面导航，并与 Android 对齐查询规则；本轮实现、逐轮审查和实际验收状态见[审改记录](../../docs/workbench-1.3.0-review.md)。源码版本不能替代正式安装包的公开和验收状态，下载请使用发行页实际提供的版本。

升级前保存编辑并正常退出旧应用。旧名称的应用包不会自动删除；新旧包共用原有资料目录与钥匙串服务，请勿同时运行。删除应用包会保留个人研究资料；需要清除资料时，请先自行导出备份。

## 第一次使用

### 找到论文并对照原文

1. 默认进入“日更速递”，点击同步读取完整网站目录。侧栏提供日更、全部论文、研究方向、会议论文集和网站与资源。会议按目录、总览、研究专题浏览，不要求当天已有日更。
2. 从日更或会议汇总选择论文，先读单栏导读。点击“打开 PDF”后，原文出现在右侧；拖动中间的分隔线可以调整两边宽度，不看原文时关闭该栏。
3. 顶栏“返回原汇总”回到进入论文前的来源页面；同一网页修订会恢复阅读位置。“继续阅读”则恢复这篇论文已保存的 PDF 页码、阅读页签和问题草稿。

当前源码优先读取网站的 `client/index.json`，只有服务器明确返回 HTTP 404 或 410 才读取原目录入口。新格式的论文附属文件按页面声明的论文身份、日期和 SHA 核验；旧安装包使用的原公开地址继续保留。格式损坏和网络故障不会触发旧接口回退；失败时保留已有资料。此说明针对源码的接口兼容，不代表已经重新发行安装包；完整边界见[网站数据适配](../../docs/mac-app-data.md)。

资料库搜索覆盖元数据、已读取导读和个人笔记。想查 PDF 原文时，使用阅读器内的查找；PDF 文字不参加资料库全文索引。

### 配置自己的模型并提出问题

“个人解析”是在阅读过程中追加的问题与回答，不会改写网站导读或原论文。先在设置中填写 API 端点、模型、协议、预算及必要的 HTTP CONNECT 代理。API 端点是模型服务接收请求的地址，协议决定请求的格式；这些值须使用服务实际提供的配置。密钥通过原生安全窗口存入本应用钥匙串。连接测试也会发出真实请求。

选择导读、PDF 选区、当前物理页、页范围、章节或全文作为研究材料。这里的物理页按 PDF 文件从第一页起计数，可能与论文印刷页码不同。当前只发送提取文字，不提供文字识别（OCR）或图像理解；扫描页会提示没有可提取文字。回答连同问题、实际材料、页码、版本和用量保存。

完全相同的研究输入可以复用已完成回答。主动重做会保留旧回答和费用记录；取消或失败也可能已经产生消费。若服务没有报告金额，记录保持未知，应用不会自动重发费用未知的请求。

### 保存笔记并保留来源

笔记、摘录和标注自动保存，“我的笔记”按论文汇集。来源链接回到原版本、原 PDF 文件对应的位置。来源更新后，旧笔记、回答和引用继续绑定原版本；网络失败时可阅读已有副本，界面会显示其更新时间或陈旧状态。

首次连接提醒可分别进入 WebDAV 备份或 Zotero 配置，也可以选择“以后设置”。设置中的“连接与开始”说明各自用途；阅读无需先配置账号。

## 浏览全站研究方向（1.3.0）

侧栏“研究方向”打开网站完整多级目录，右侧显示对应的全部论文。“全部论文”、收藏和待读中也能打开同一目录；切换范围后，各自保留搜索、分类和位置。零篇论文的方向仍显示，也可查看说明，不会从目录中消失。

目录搜索用于找方向，支持中文、英文、别名和编号；右侧搜索用于找论文及本机正文、笔记。点箭头只展开层级，点方向名称查看该方向，勾选多个方向才组合筛选。

“分面”是分类的不同角度，例如研究任务与研究方法。同一分面中任选其一即可，跨分面则要同时满足：选择两项任务和一项方法，表示“任一所选任务，并采用所选方法”。默认包含子类；高级分类筛选可以改为只查直接标签，或限定主要角色、研究类型和领域。展开目录只是浏览层级，不等于给论文增添标签。

面包屑与分类说明提供完整路径、定义和使用范围。来源、评分和网站日期在“筛选”中，已生效的分类规则有摘要和恢复默认入口。从列表打开论文后再返回，沿用原分类、页码和滚动位置。同一论文有多篇导读时，可在完整信息中查看各导读的日期、评分、分类和官网入口；命中其他导读时会明确提示，不能把它当作默认导读的评分。

## 整理收藏

打开侧栏“已收藏”，默认按真实收藏时间从新到旧查看，分为今天、近七天和更早，也可改按月份查看。旧版没有记录的时间显示“收藏时间未知”，不会拿论文发布日期代替。

收藏按网站已有的多级分类浏览。选择研究任务、研究方法等分面，展开父类查看子类；论文保留网页发布的分类路径，不需要自己建立或整理类别。旧目录没有分类信息时，点击同步读取网站分类。无法核对的记录会单独说明，不按标题或平面标签猜测。

收藏时间和个人资料随完整备份及跨端恢复保留。1.2.0 保存的旧自建分类字段仍留在原资料中，当前界面不再显示为分类，也不提供手工归类操作，详见[收藏说明](../../docs/favorite-collections.md)。

## 网站与资源和离线阅读

“日更速递”和“会议论文集”默认显示汇总；“网站与资源”提供关于与资源等说明，以及官网论文库、搜索、归档、RSS 等九个入口。已识别的论文链接进入本地阅读，其他 HTTPS 链接由浏览器打开；网页专属功能在浏览器使用。目录在空闲时预热，最多预载四页公开汇总 HTML；正文先显示，图片随后读取，PDF 按需下载。已存汇总先显示本机核验快照，点击“重新读取网站”检查当前正文，不把本机副本冒称网站最新版。

菜单“显示→页面操作”可进入操作栏；Control-Tab 进入正文，Control-Shift-Tab 返回导航，Escape 退出操作栏。“编辑→查找当前文档”搜索当前正文。

“保存离线”保存指定版本的完整图文和原始 PDF。“本机资料”可查看版本、容量及缓存清理预览。只有材料齐全的快照显示完整离线；普通网页缓存与完整论文离线包分别管理。

## Zotero 与坚果云

### 将一篇论文归档到 Zotero

Zotero 用来管理文献与附件。先启动 Zotero Desktop 并开启本地 API，让工作台能与同一台电脑上的 Zotero 通信，再在设置中检查连接。归档当前论文时确认分类和材料，在 Zotero 原生窗口决定授权。当前支持本机个人文库；持续授权是文库范围。

书目、完整来源、PDF、自包含导读及所选个人解析、笔记分别保存，然后逐项读取回来核对。“自包含导读”把需要的内容与图片保存在同一份可阅读材料中，不依赖工作台缓存。部分失败时保留成功项，沿原记录继续。详见 [Zotero 使用说明](../../docs/mac-app-zotero.md)。

### 备份整个研究空间

WebDAV 是应用访问网盘文件的一种协议。工作台用它把完整研究空间保存到坚果云，与“只归档一篇论文到 Zotero”用途不同。在“设置→WebDAV 备份”填写账号、生成第三方应用密码并检查连接。服务器地址已内置，默认目录为 `PaperDigest`；密码可仅本次使用或保存到本应用钥匙串，与 Zotero 附件目录分开。

备份包含研究资料、原始模型输入与响应、用量、离线材料和归档记录。钥匙串及本机响应校验密钥不迁移。恢复前会保留当前资料副本，并保留本机模型连接设置及已派发请求计数。备份以 HTTPS 传输，没有额外的端到端加密；不同设备保存独立版本，不自动合并笔记。完整步骤见 [保存与恢复](../../docs/mac-app-cloud.md)。

关闭主窗口后，未退出的应用可继续任务；退出应用会停止任务与自动备份。

## 从源码构建

需要 macOS 15+、Xcode Command Line Tools 和根项目支持的开发用 Node。完整测试还需要 Google Chrome，部分界面测试使用它的固定安装路径。**打包用 Node 必须与离线许可固定版本 24.19.0 完全一致**，不能直接采用任意 24.x 版本。

从 [Node 官方 24.19.0 下载目录](https://nodejs.org/dist/v24.19.0/)准备 `node-v24.19.0-darwin-arm64`，按官方校验文件核对下载归档后解压。将 `PD_MAC_NODE_RUNTIME` 指向自己的 `bin/node`；以下假定解压到 `~/Tools/`：

```sh
cd apps/macos
export PD_MAC_NODE_RUNTIME="$HOME/Tools/node-v24.19.0-darwin-arm64/bin/node"
npm ci
npm test
npm run build
# 保存并正常退出旧应用后安装到 ~/Applications：
npm run install:app
```

部分界面测试可通过 `PD_MAC_BROWSER` 指定浏览器；完整 `npm test` 仍含直接使用 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` 的入口，单独安装 Playwright Chromium 或设置该变量不能替代这一前提。科学排版测试需要按[样稿准备说明](../../prototypes/macos-research/README.md)准备公开 MiCLA PDF 和三张原图，校验值以受控样稿清单为准；这些本机测试资产不进入正式包。

默认构建使用 `release` 通道，输出 `.build/论文速递工作台.app`，不捆绑论文样稿。`--channel private-qa` 用于含样稿的本机测试，不能作为正式发行包。构建会检查 Node 的版本、架构、最低系统、外部动态库依赖及对应许可。安装脚本检测到 `PaperDigest` 进程仍在运行时拒绝替换，不强制结束应用。

应用标识 `com.nanless.PaperDigest`、可执行文件 `PaperDigest`、钥匙串服务及资料根 `~/Library/Application Support/PaperDigest/` 保持兼容。关于窗口提供随包第三方许可全文；更新运行时须同时按维护流程准备匹配许可，不能修改原许可正文来绕过版本检查。

原生窗口由 AppKit 提供，WebKit 排版导读，PDFKit 负责原文阅读。这些组件随应用工作，不要求使用者自行搭建网页服务。
