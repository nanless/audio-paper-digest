# 论文速递工作台 Mac 版

阅读论文速递网站已经发布的图文导读，对照 PDF，保存个人解析与笔记，并将选定材料归档到 Zotero。应用使用 AppKit 窗口、WebKit 排版和 PDFKit 阅读器；安装后独立运行，无需仓库、开发服务器或系统 Node。

## 安装与升级

| 项目 | 支持范围 |
|---|---|
| 版本 | 1.0.1，构建号 1 |
| 系统 | macOS 15 及以上 |
| 处理器 | Apple Silicon（arm64）；当前发行包不是 universal 包 |
| 签名 | 本地 ad-hoc 签名，未通过 Apple 公证 |
| 随包运行时 | Node 24.19.0，使用者无需另行安装 |

1.0.1 已与 Android 安装包一同公开，下载与校验值见 [v1.0.1](https://github.com/nanless/audio-paper-digest/releases/tag/v1.0.1)。安装时将解压后的“论文速递工作台.app”或 DMG 中的应用拖入“应用程序”。首次打开若被系统拦截，先核对下载来源与发布校验值，再按 macOS 的“隐私与安全性”提示允许打开该应用。

升级前保存编辑并正常退出旧应用。旧名称的应用包不会自动删除；新旧包共用原有资料目录与钥匙串服务，请勿同时运行。删除应用包会保留个人研究资料；需要清除资料时，请先自行导出备份。

## 第一次使用

1. 在资料库点击同步，读取网站完整目录。日更、会议和历史论文共用一个资料库，导读、图片及 PDF 按需读取，不重新分析网站论文。
2. 打开论文先读单栏导读；点击“打开 PDF”显示右侧原文，拖动分隔线调整比例。关闭 PDF 后继续单栏阅读；“继续阅读”恢复已保存的页码、阅读页签和问题草稿。
3. 使用“个人解析”前，在设置中填写自己的 API 端点、模型、协议、预算及必要的 HTTP CONNECT 代理。密钥通过原生安全窗口存入本应用钥匙串。连接测试也会发出真实请求。
4. 选择导读、PDF 选区、当前物理页、页范围、章节或全文作为研究材料。当前模型输入是提取文字，不提供 OCR 或图像理解；扫描页会提示没有可提取文字。回答连同问题、实际材料、页码、版本和用量保存。
5. 笔记、摘录和标注自动保存；“我的笔记”按论文汇集。来源链接返回同版本、同 PDF 字节对应的位置。完全相同的研究输入可复用已完成回答，主动重做保留旧回答和费用记录。

资料库搜索覆盖元数据、已读取导读和个人笔记。PDF 原文在阅读器内查找，不参与资料库全文索引。来源更新后，旧笔记、回答和引用继续保留原版本；网络失败时可阅读已有副本，界面会显示其更新时间或陈旧状态。

## 网站页面与离线阅读

“网站页面”提供日更汇总、会议汇总和网站说明的分类搜索。已识别的论文链接进入本地阅读，其他 HTTPS 链接由浏览器打开。菜单“显示→页面操作”可进入操作栏；Control-Tab 进入正文，Control-Shift-Tab 返回导航，Escape 退出操作栏。“编辑→查找当前文档”搜索当前正文。

“保存离线”保存指定版本的完整图文和原始 PDF。“本机资料”可查看版本、容量及缓存清理预览。只有材料齐全的快照显示完整离线；普通网页缓存与完整论文离线包分别管理。

## Zotero 与坚果云

- **Zotero**：启动 Zotero Desktop 并开启本地 API，在设置中检查连接。归档当前论文时确认分类和材料，再在 Zotero 原生窗口决定授权。当前支持本机个人文库；持续授权是文库范围。书目、完整来源、PDF、自包含导读及所选个人解析、笔记逐项保存和回读，部分失败可沿原记录继续。详见 [Zotero 使用说明](../../docs/mac-app-zotero.md)。
- **坚果云**：为工作台单独生成第三方应用密码，在“设置→坚果云资料”填写账号及独立目录，再选择仅本次使用密码或保存到本应用钥匙串，并主动检查连接。默认目录为 `PaperDigest`，与 Zotero 附件目录分开。详见 [保存与恢复](../../docs/mac-app-cloud.md)。
- **备份**：保存研究资料、原始模型输入与响应、用量、离线材料和归档记录。钥匙串及本机响应校验密钥不迁移。恢复前保留当前资料副本，并保留本机模型连接设置及已派发请求计数。

关闭主窗口后，未退出的应用可继续任务；退出应用会停止任务与自动保存。取消或失败的模型请求仍可能产生费用，服务未报告的金额保持未知，应用不自动重发费用未知的请求。

## 从源码构建

需要 macOS 15+、Xcode Command Line Tools 和根项目支持的开发用 Node。**打包用 Node 必须与离线许可固定版本 24.19.0 完全一致**，不能直接采用任意 24.x 版本。

从 [Node 官方 24.19.0 下载目录](https://nodejs.org/dist/v24.19.0/)准备 `node-v24.19.0-darwin-arm64`，按官方校验文件核对下载归档后解压。将 `PD_MAC_NODE_RUNTIME` 指向自己的 `bin/node`；以下假定解压到 `~/Tools/`：

```sh
cd apps/macos
export PD_MAC_NODE_RUNTIME="$HOME/Tools/node-v24.19.0-darwin-arm64/bin/node"
npm ci
# 没有 Chrome 时安装测试浏览器：npx playwright install chromium
npm test
npm run build
# 保存并正常退出旧应用后安装到 ~/Applications：
npm run install:app
```

测试浏览器可通过 `PD_MAC_BROWSER` 指定。科学排版测试需要按[样稿准备说明](../../prototypes/macos-research/README.md)准备公开 MiCLA PDF 和三张原图，校验值以受控样稿清单为准；这些本机测试资产不进入正式包。

默认构建使用 `release` 通道，输出 `.build/论文速递工作台.app`，不捆绑论文样稿。`--channel private-qa` 用于含样稿的本机测试，不能作为正式发行包。构建会检查 Node 的版本、架构、最低系统、外部动态库依赖及对应许可。安装脚本检测到 `PaperDigest` 进程仍在运行时拒绝替换，不强制结束应用。

应用标识 `com.nanless.PaperDigest`、可执行文件 `PaperDigest`、钥匙串服务及资料根 `~/Library/Application Support/PaperDigest/` 保持兼容。关于窗口提供随包第三方许可全文；更新运行时须同时按维护流程准备匹配许可，不能修改原许可正文来绕过版本检查。
