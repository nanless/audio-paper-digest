# 论文速递工作台 Mac 应用

原生 AppKit 窗口、系统菜单与快捷键，WebKit 渲染图文，PDFKit 阅读原文。已安装的应用独立运行，不依赖开发服务器、仓库目录或系统 Node。

## 使用

1. 正式构建首次启动为空目录。在资料库点击同步，读取公开网站的完整目录；日更、会议与历史成果直接读取，不重跑分析。论文原文及图片按需读取。已有本机资料和恢复的研究空间继续保留。
2. 打开论文默认显示单栏导读。点击“打开 PDF”才打开右栏，拖动中间分隔线调整比例；关闭 PDF 保留导读位置。侧栏“继续阅读”恢复上次保存的标签、问题草稿、页码和双栏状态。
3. 在“个人解析”选择导读、原文选区、当前物理页、页范围、原文目录章节或全文。实际提取文字、页码、PDF SHA、版本与回答一起保存。扫描页或缺字页会明确提示；当前没有图像模型或 OCR，不能把无文字页当作已经理解。
4. 设置自己的 API 端点、模型、协议、预算与必要的 HTTP CONNECT 代理；密钥通过原生安全输入写入本应用钥匙串。最小连接测试也是真实请求。完全相同的输入、来源和配置可复用已完成回答；明确重做保留原回答及费用历史。
5. 笔记、原文摘录与批注自动保存。“我的笔记”按论文汇集；选中摘录可跳回同 SHA 的物理页。跨版本引用不会静默定位到另一份 PDF。
6. “保存离线”封存完整图文与原始 PDF；“本机资料”打开各版本快照、查看实际容量，或检查可移到废纸篓的未引用缓存。离线快照明确不代表网站当前版本。
7. 后台任务显示真实阶段、错误和取消结果。关闭主窗口应用继续运行；退出后任务停止，费用未知的请求不会自动重发。
8. “设置→坚果云资料”保存完整研究空间的独立云端版本，可继续原快照上传、查看月份和恢复所选版本。新功能的实际验收状态见[网盘与发行验收](../../docs/mac-app-cloud.md)。

来源附有版本说明时，导读顶部显示原说明，并可展开查看全文。导读没有记录来源版本时会明确提示，不能用当前目录中的新版本号替代旧稿来源。后台任务按原记录分页；全站目录同步与单篇论文操作分别标明范围。

实际安装、真实账户操作与尚未覆盖条件见[验收记录](../../docs/mac-app-validation.md)。功能说明不替代逐项验收，也不把开发构建称为公开发行。

## 网站汇总与说明页面

在资料库打开“网站页面”，可按类别搜索日更汇总、会议汇总和网站说明。先同步来源目录，再打开需要的页面；应用读取已发布原文，不请求模型重新生成。可识别的已发布论文链接进入本地论文阅读，其他可用 HTTPS 链接交给浏览器。

正文保留原图、图注、公式与章节目录。来源信息可查看完整题名、日期、原页、保存版本和图片缺项；未知日期照实显示。只读取实际打开页面所需的图片，缺图或陈旧状态不会被藏成“完整离线”。它与论文的完整离线包是两种不同材料。

键盘可从“显示→页面操作”进入操作栏；Control-Tab 进入正文，正文内 Control-Shift-Tab 返回导航，导航内再次按下可进入操作栏。栏内用 Tab 或 Shift-Tab 移动，Escape 返回导航。“编辑→查找当前文档”查找当前已打开正文；窗口、页面或对话框变化后，旧操作不会借到新页面。

主题与字号由应用设置控制。网站页面不会执行站点脚本，也不会因为看起来像论文就获得个人研究、PDF 或归档权限；要研究某篇论文，请打开其已核对的论文条目。

## Zotero

需要正在运行的 Zotero Desktop，且本地 API 可用。通过官方本地 API 原生授权；用户亲自决定持续允许。授权是文库范围，不能承诺密钥只允许访问某个分类。应用每次只处理所选论文与目标分类。

新归档只写入本机个人文库，需要 Zotero 能提供可识别的个人账号。未能识别账号时，本机阅读仍可用，但不会开始新归档。缺少账号绑定的旧记录不会自动记到当前账号：材料完整的可选择“仅只读回读”；未完成的保留原断点，不继续写入。切换账号或文库实例后，旧归档不会改向新文库续写。

支持书目与已知原始字段、完整来源元数据、原始 PDF、自包含图文导读、选中的个人解析及笔记/摘录。作者机构等无法直接放入 Zotero 对应字段的原始信息保留在完整来源记录中，缺失信息不猜造。附件采用官方上传合同并回读校验；重复归档、用户修改冲突、部分失败、重启续传有本地检查点，原条目与用户编辑受保护。

授权和真实写库测试与模拟服务测试分别记录；见[验收矩阵](../../docs/mac-app-acceptance.md)。不能用模拟服务通过证明真实文库已经归档成功。

## 坚果云资料

为论文速递工作台单独生成坚果云第三方应用密码，在设置中填写账号、独立目录，再通过原生安全窗口选择“仅本次使用应用密码…”或“保存应用密码到钥匙串…”，然后主动检查连接。仅本次使用将密码保留在本次运行内存中，不读取或写入钥匙串，退出或更换账号后清除；这种仅内存模式在重启后自动备份保持暂停，须重新设置本次密码并检查连接。持久保存使用本应用自己的钥匙串条目，重启后条目仍保留，可主动检查连接，无需每次重填；两种方式均不会读取Zotero或其他程序保存的网盘密码。默认目录为`PaperDigest`，不使用Zotero标准附件目录。

完整备份保存本应用研究目录中的笔记、标注、收藏、待读、阅读状态、解析及原材料、费用历史、离线包和Zotero归档检查点。每个版本独立分块保存并逐项回读，未完成时沿原编码快照继续，另一设备的旧版本保留。恢复前先下载核验，再由原生窗口确认，保留恢复前副本；本机模型连接配置与已派发请求计数继续保护。Zotero自身数据库、外部文件与系统钥匙串由原存储负责。

云端完整备份目前限512MiB原文件、750MiB编码，超限明确停止，不裁掉部分文件。可选择应用运行时每6–168小时自动保存，默认24小时；退出后不运行。失效账号或损坏材料可原样保留并停止该次续传，再重新配置；完整的保留快照仍走原备份恢复校验，损坏材料不保证可恢复。详细合同和未验边界见[坚果云说明](../../docs/mac-app-cloud.md)。

## 构建与测试

需要 macOS 15+、Xcode Command Line Tools、满足根项目要求的 Node。当前本机验证的是 Apple Silicon 与 macOS 26.6.1，未声明其他机器已通过。前端开发测试需要 Chrome，或先安装 Playwright Chromium；可用 `PD_MAC_BROWSER` 指定测试浏览器二进制。

首次检出的测试环境须先按[真实样稿准备说明](../../prototypes/macos-research/README.md)准备同一份 MiCLA PDF 与三张原图，四份文件均核对 `sample.json` 的 SHA-256。测试使用这些已忽略的本机资产，不会重新分析论文；正式应用仍不捆绑样稿。

```bash
cd apps/macos
npm ci
# 没有 Chrome 时：npx playwright install chromium
npm test
npm run install:app
```

仓库Release在全部适用验收完成后发布。维护者可先使用`npm run release:inspect`、`release:prepare`和`release:verify`只读核查或准备本地ZIP/DMG、校验文件与版本说明；参数及最终发布门槛见[发行说明](../../docs/mac-app-release.md)。这些命令不会上传或公开尚未验完的候选。

默认`npm run build`与`npm run install:app`使用`release`资源通道，不捆绑论文PDF、原图或分析样稿。私有科学验收使用`npm run build -- --channel private-qa`，须先按[真实样稿准备说明](../../prototypes/macos-research/README.md)准备忽略的PDF和裁图；该通道仍核对全部原件SHA，不能发布为正式Release。两通道每次使用新的未签名暂存，不从旧签名包删文件。

“关于论文速递工作台”提供随包开源许可全文的离线入口。当前固定许可对应Node `v24.19.0`；`PD_MAC_NODE_RUNTIME`指定的二进制还须匹配当前架构、最低系统和该准确版本。更换Node版本须先准备对应完整原文并更新许可清单，不能沿用旧版本通知。自家显示名或短版本变更后运行 `python3 refresh_licenses.py`，从 `Info.plist` 重新生成许可元数据与页面；生成前后核对原许可全文及固定SHA，不手改原文或第三方出处。

新构建输出为 `.build/论文速递工作台.app`，安装位置为 `~/Applications/论文速递工作台.app`。原名应用包不会自动删除或覆盖；显示名变更不改变 `com.nanless.PaperDigest`、`PaperDigest` 可执行文件、钥匙串服务或原资料目录。短版本为1.0.1，构建号沿用当前原值1；仓库尚无自动递增策略。构建元数据保存实际每个输入文件的 SHA、时间、架构与父提交，另在忽略的 `.qa/builds/` 保留已签名二进制 SHA。开发签名为 ad-hoc，尚未 Apple 公证。仓库中的改名候选尚须正常构建、签名及实物验收；不能把源码更新当作已安装或已发布。

升级前先在应用中保存并正常退出，等待任务停止。安装脚本会在开始和替换旧包前检查 `PaperDigest` 进程；仍在运行就拒绝替换，不会代替你强制退出。锁屏期间无法安全完成保存和退出时，可先执行 `npm run build` 生成并校验候选包，解锁后再退出旧版并执行安装。构建成功、安装成功和新版本实际启动是三个独立结果；当前旧进程不会因为新包构建成功而自动更新。安装失败会保留原安装，个人研究空间和钥匙串均不随替换应用包删除。

打包的原生程序与 Node 均须匹配当前机器架构，本机产物不是 universal 包。原生程序的最低系统版本为 macOS 15，与 Info.plist 一致；脚本拒绝最低系统版本高于15或依赖未复制外部动态库的 Node，并核对其版本符合公共请求实现。直接从 `.build` 启动的旧程序仍运行时，也不覆盖该构建目录。其他架构和最低支持系统仍须分别实机验收。前端及 Node 许可证随包保存；`.env`、生产 runtime 和个人资料不属于打包输入。

## 数据与边界

个人资料位于 `~/Library/Application Support/PaperDigest/`，API 与 Zotero 授权位于应用自己的钥匙串。备份保留实际字节和 SHA；跨目录恢复仅在核验原 SHA 后重定位内部文件，恢复前副本保留。钥匙串不进入备份。模型 token 用量原样记录，服务未返回金额时显示未知。

客户端目录、正文、引用及研究上下文以公开发布层为准；不解析整张网站布局，不读取运行中的生产检查点。公共请求实现打包复用，客户端费用独立保存，不改生产 `.env`、账号冷却状态或发布流程。

需求历史、数据结论与独立审查记录见[需求](../../docs/mac-app-requirements.md)、[数据架构](../../docs/mac-app-data.md)、[Zotero 合同](../../docs/mac-app-zotero.md)、[测试记录](../../docs/mac-app-validation.md)。未验收的功能不得因文档已经说明而标成完成。
