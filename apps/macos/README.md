# 论文速递 Mac 应用

原生 AppKit 窗口、系统菜单与快捷键，WebKit 渲染图文，PDFKit 阅读原文。已安装的应用独立运行，不依赖开发服务器、仓库目录或系统 Node。

## 使用

1. 在资料库点击同步，读取公开网站的完整目录。日更、会议与历史成果直接读取，不重跑分析。初始 MiCLA 样稿及三张原图与原 PDF 均绑定真实 SHA。
2. 打开论文默认显示单栏导读。点击“原文 PDF”才打开右栏，拖动中间分隔线调整比例；关闭 PDF 保留导读位置。侧栏“继续阅读”恢复上次保存的标签、问题草稿、页码和双栏状态。
3. 在“个人解析”选择导读、原文选区、当前物理页、页范围、原文目录章节或全文。实际提取文字、页码、PDF SHA、版本与回答一起保存。扫描页或缺字页会明确提示；当前没有图像模型或 OCR，不能把无文字页当作已经理解。
4. 设置自己的 API 端点、模型、协议、预算与必要的 HTTP CONNECT 代理；密钥通过原生安全输入写入本应用钥匙串。最小连接测试也是真实请求。完全相同的输入、来源和配置可复用已完成回答；明确重做保留原回答及费用历史。
5. 笔记、原文摘录与批注自动保存。“我的笔记”按论文汇集；选中摘录可跳回同 SHA 的物理页。跨版本引用不会静默定位到另一份 PDF。
6. “保存离线”封存完整图文与原始 PDF；“本机资料”打开各版本快照、查看实际容量，或检查可移到废纸篓的未引用缓存。离线快照明确不代表网站当前版本。
7. 后台任务显示真实阶段、错误和取消结果。关闭主窗口应用继续运行；退出后任务停止，费用未知的请求不会自动重发。

## Zotero

需要正在运行的 Zotero Desktop，且本地 API 可用。通过官方本地 API 原生授权；用户亲自决定持续允许。授权是文库范围，不能承诺密钥只允许访问某个分类。应用每次只处理所选论文与目标分类。

支持书目与已知原始字段、完整来源元数据、原始 PDF、自包含图文导读、选中的个人解析及笔记/摘录。作者机构等无法直接放入 Zotero 对应字段的原始信息保留在完整来源记录中，缺失信息不猜造。附件采用官方上传合同并回读校验；重复归档、用户修改冲突、部分失败、重启续传有本地检查点，原条目与用户编辑受保护。

授权和真实写库测试与模拟服务测试分别记录；见[验收矩阵](../../docs/mac-app-acceptance.md)。不能用模拟服务通过证明真实文库已经归档成功。

## 构建与测试

需要 macOS 15+、Xcode Command Line Tools、满足根项目要求的 Node。当前本机验证的是 Apple Silicon 与 macOS 26.6.1，未声明其他机器已通过。前端开发测试需要 Chrome，或先安装 Playwright Chromium；可用 `PD_MAC_BROWSER` 指定测试浏览器二进制。

```bash
cd apps/macos
npm ci
# 没有 Chrome 时：npx playwright install chromium
npm test
npm run install:app
```

首次干净检出须按[真实样稿准备说明](../../prototypes/macos-research/README.md)准备忽略的 PDF 和裁图。构建前校验全部资产 SHA；缺失时拒绝打包。`PD_MAC_NODE_RUNTIME` 可指定与当前机器架构一致的 Node 二进制。

安装位置为 `~/Applications/论文速递.app`。构建元数据保存实际每个输入文件的 SHA、时间、架构与父提交，另在忽略的 `.qa/builds/` 保留已签名二进制 SHA。开发签名为 ad-hoc，尚未 Apple 公证；当前是本机安装版本。

升级前先在应用中保存并正常退出，等待任务停止。安装脚本会在开始和替换旧包前检查 `PaperDigest` 进程；仍在运行就拒绝替换，不会代替你强制退出。锁屏期间无法安全完成保存和退出时，可先执行 `npm run build` 生成并校验候选包，解锁后再退出旧版并执行安装。构建成功、安装成功和新版本实际启动是三个独立结果；当前旧进程不会因为新包构建成功而自动更新。安装失败会保留原安装，个人研究空间和钥匙串均不随替换应用包删除。

打包的原生程序与 Node 均须匹配当前机器架构，本机产物不是 universal 包。原生程序的最低系统版本为 macOS 15，与 Info.plist 一致；脚本拒绝最低系统版本高于15或依赖未复制外部动态库的 Node，并核对其版本符合公共请求实现。直接从 `.build` 启动的旧程序仍运行时，也不覆盖该构建目录。其他架构和最低支持系统仍须分别实机验收。前端及 Node 许可证随包保存；`.env`、生产 runtime 和个人资料不属于打包输入。

## 数据与边界

个人资料位于 `~/Library/Application Support/PaperDigest/`，API 与 Zotero 授权位于应用自己的钥匙串。备份保留实际字节和 SHA；跨目录恢复仅在核验原 SHA 后重定位内部文件，恢复前副本保留。钥匙串不进入备份。模型 token 用量原样记录，服务未返回金额时显示未知。

客户端目录、正文、引用及研究上下文以公开发布层为准；不解析整张网站布局，不读取运行中的生产检查点。公共请求实现打包复用，客户端费用独立保存，不改生产 `.env`、账号冷却状态或发布流程。

需求历史、数据结论与独立审查记录见[需求](../../docs/mac-app-requirements.md)、[数据架构](../../docs/mac-app-data.md)、[Zotero 合同](../../docs/mac-app-zotero.md)、[测试记录](../../docs/mac-app-validation.md)。未验收的功能不得因文档已经说明而标成完成。
