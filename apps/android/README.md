# 论文速递工作台 Android

论文速递工作台是“论文速递”的 Android 原生客户端。它读取网站已发布的论文目录、图文导读、日更与会议汇总，支持原始 PDF、笔记、离线阅读、个人研究、Zotero 归档和坚果云备份。阅读和同步已有文章不会重新调用模型。

当前版本为 **1.0.1（构建号 4）**，支持 Android 9 / API 28 及以上系统，包含 `armeabi-v7a`、`arm64-v8a`、`x86`、`x86_64` 四种架构。应用标识仍为 `com.nanless.paperdigest`，正式签名与旧版一致。安装、测试范围和发行状态见[验证说明](<../../docs/android-validation.md>)。

## 开始使用

1. 首次安装后，在“文献”中同步网站。正式包首次显示空目录；同步取得目录后，正文、图片和 PDF 按阅读需要下载。
2. 打开论文，在“阅读”页查看导读、原文、研究和笔记。手机以单栏为主；PDF 已打开且可用宽度足够时，可使用并排或专注布局。宽表和长公式可局部横向滚动。
3. 从文献页进入“网站汇总”，阅读日更、会议汇总和说明页。保存版本、来源和离线状态各有入口。离线材料缺失时会提示缺项；普通说明页不作为论文分析材料。
4. 在模型设置中填写自己的连接和密钥。发起研究前确认问题、选区或页范围、模型与预算。相同输入可复用已有回答；明确重做会建立新记录并保留原结果和费用。
5. 在“任务”查看同步、研究、归档和备份的进度，执行取消或继续操作。已派发但结果未知的模型请求不会因重启或恢复自动重发；未取得的金额保留为未知。

API 密钥和连接密码由本机安全存储管理。研究资料可通过系统文件选择器导出；卸载或清除应用数据会删除本机私有资料，请先备份。

## Zotero 与坚果云

**Zotero 归档**使用官方 Web API，需要在 Android 上单独配置专用授权。确认目标文库、分类和所选材料后，分别保存书目、来源信息、PDF、导读、研究和笔记，并回读核验。已有归档记录用于去重和续传；远端用户修改受到保护。个人文库可使用 Zotero Storage 或已配置的 WebDAV，群组附件不使用 WebDAV。

Zotero Storage 空间不足时，可以明确确认改用本应用已配置的坚果云附件连接。原书目和 Storage 记录保留，新材料重新回读；更改连接或重启后需要重新确认。其他 Zotero 客户端须自行配置相同的附件同步方式。详见[Zotero 说明](<../../docs/android-zotero-research.md>)。

**坚果云研究资料**保存整个研究空间的独立版本，支持取消、同一版本续传、选择版本、校验和确认恢复。默认目录为 `PaperDigest`，与 Zotero 附件目录分开。它采用不可变版本，不自动合并两台设备的笔记。

备份保留原件、文章版本、笔记、批注、研究输入、回答、用量与历史；模型密钥、连接密码、设备授权和两份本机响应完整性密钥不随备份迁移。旧包恢复会保留原包，在有效研究空间中使用当前设备的完整性密钥。备份经 HTTPS 传输，文件本身没有额外的端到端加密。详见[备份合同](<../../docs/android-cloud-contract.md>)。

## 本机构建

需要根项目要求的 Node、JDK 17、Android SDK 平台 37、Build Tools 36.0.0、NDK 27.2.12479018、CMake 3.22.1，以及 Mac 子项目锁定的 KaTeX 依赖。构建脚本使用已有 `JAVA_HOME`、`ANDROID_HOME`，也识别本机 Homebrew 路径，不修改全局设置。

```bash
./apps/android/build.sh :app:assembleDebug
./apps/android/test.sh
```

默认调试包输出到 `apps/android/app/build/outputs/apk/debug/app-debug.apk`。调试资源通道 `private-qa` 带有固定公开 MiCLA 小样；正式 `release` 通道只含空目录引导、排版资源和完整开源许可。两个通道的输出与清单分开，正式包不包含验收页面、用户资料、生产运行数据或 `.env`。

## 设备测试

使用自行创建、没有个人资料的专用验收模拟器。先核对 `adb devices` 和 AVD 名称，再将 `SERIAL` 换成所选设备的序列号：

```bash
./apps/android/install.sh SERIAL
./apps/android/test.sh --device SERIAL
```

安装脚本仅定向该设备，并核对模拟器名称 `PaperDigest_QA_API35` 或 `PaperDigest_QA_API28`；测试入口也只使用指定序列号。设备是否为空仍须执行者事先确认。请勿改用用户现有手机或研究模拟器，也不要向全部已连接设备派发测试。

正式发行核对源码、版本、签名、四种架构、16 KiB 对齐、许可、资源以及实际新装和覆盖升级。签名私钥与口令在仓库和发行包之外保存。下载入口使用本仓库实际发布的 [GitHub Releases](https://github.com/nanless/audio-paper-digest/releases)。逐项功能与验证范围见[功能表](<../../docs/android-feature-parity.md>)。
