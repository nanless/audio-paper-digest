# 论文速递工作台 Android

[English](README.en.md)

论文速递工作台是“论文速递”的 Android 原生客户端。它读取网站已发布的论文目录、图文导读、日更与会议汇总，支持原始 PDF、笔记、离线阅读、个人研究、Zotero 归档和坚果云备份。阅读和同步已有文章不会重新调用模型。

此源码版本为 **1.3.1（构建号 9）**，公开安装包状态以 [GitHub 发行页](https://github.com/nanless/audio-paper-digest/releases)为准。支持 Android 9 / API 28 及以上系统，包含 `armeabi-v7a`、`arm64-v8a`、`x86`、`x86_64` 四种架构。应用标识仍为 `com.nanless.paperdigest`，正式签名沿用旧版。安装、测试范围和发行状态见[验证说明](<../../docs/android-validation.md>)；全站分类、手机和宽窗口界面的本轮改进见[审改记录](../../docs/workbench-1.3.0-review.md)。

## 开始使用

### 同步目录，打开论文

1. 首次安装默认进入“日更”，自动取得网站目录；以后回到应用时按设置的间隔检查更新，菜单保留手动同步。底栏依次为日更、论文库、会议、任务和设置；会议入口展示完整会议目录、各会总览和研究方向。
2. 打开论文，在“阅读”页查看导读、原文、研究和笔记。手机以单栏为主；PDF 已打开且可用宽度足够时，可使用并排或专注布局。宽表和长公式可局部横向滚动，不必缩小整篇文字。
3. 从日更或会议汇总进入论文后，点击返回原汇总或使用系统返回。会议目录、总览、专题可逐级返回，同一修订保留阅读位置。

空闲时最多预载四页公开汇总 HTML 和两篇近期论文导读。打开导读时先显示已核验的文字，图片随后准备；用户操作优先于后台同步和预载。PDF 仍按需下载，离线模式不会联网。显式读取某个历史保存版本时，不联网补图，以免混入另一版本的材料。自动同步、手机排版和异常恢复的改动见 [1.3.1 审改记录](../../docs/android-1.3.1-review.md)。

### 配置模型，确认发送材料

个人研究使用你在模型设置中填写的服务连接和密钥。模型端点是接收请求的地址，协议决定消息格式；请填写服务实际提供的配置。研究在本机管理，但使用远程端点时，所选材料会发送给该服务，并不代表推理在手机上完成。

发起研究前确认问题、选区或页范围、模型与预算。当前仅发送从导读或 PDF 提取出的文字，不提供文字识别（OCR）或图像理解。页范围使用 PDF 文件从第一页起计数的物理页，可能与论文印刷页码不同。相同输入可复用已有回答；明确重做会建立新记录，并保留原结果和费用。

### 查看任务和处理失败

在“任务”查看同步、研究、归档和备份的进度，并执行当前任务提供的取消或继续操作。已派发但结果未知的模型请求，不会因重启或恢复自动重发；没有取得的金额保持未知，不能把取消或失败理解成没有消费。

API 密钥和连接密码由本机安全存储管理。研究资料可通过系统文件选择器导出；卸载或清除应用数据会删除本机私有资料，请先备份。

首次提醒可直接打开“设置→连接与开始”，分别配置 WebDAV 备份或 Zotero，也可以稍后配置并先阅读。每个连接都有官方授权入口、安全保存和连接检查步骤。凭据已保存而网络检查失败时，可只重试检查，无需重新输入密码。

## 浏览全站研究方向（1.3.0）

在论文库打开“研究方向”，手机显示可展开的目录面板，宽窗口将目录放在论文旁边。网站的九个分类维度和全部层级都保留，零篇方向也可查看。目录搜索支持中文、英文、别名和编号，与论文搜索分别使用。

点方向名称查看下一层，使用顶部的层级路径（面包屑）返回上层；勾选方向才应用筛选，浏览目录不会自行改变已选条件。手机点“查看论文”收起面板，回到结果。

可以同时选择多个方向。研究任务、研究方法等是不同分类维度，也称“分面”；同一维度任选其一，跨维度则同时满足。例如，两项任务与一项方法组合，表示符合任一所选任务、并采用该方法的论文。默认包含子类；高级选项可以改为只查直接标签，或限定主要角色、研究类型和领域。方向详情提供原定义、别名和完整路径。

“筛选与排序”提供来源、最低评分和网站发布日期范围。日期是导读在网站上的日期，和收藏时间分别处理。搜索、分类与阅读位置在全部、收藏、待读等范围分别保存；打开论文后使用系统返回，继续原列表。同一论文有多篇导读时，“论文信息与全部已发布导读”列出实际匹配的导读和各自信息，官网入口明确在浏览器打开。

论文库操作菜单中的“网站全部成果”汇集日更、会议、关于与研究资源，并提供官网论文库、搜索、归档和 RSS 等入口；网页专属功能在浏览器使用，图文导读、PDF、笔记和个人研究继续在工作台中使用。

## 整理收藏

在“论文库”顶部直接切到“收藏”。默认按实际收藏时间分区，也可选月份；旧版收藏没有时间记录时单列“收藏时间未知”。论文发布日期单独显示，不作为收藏时间。

收藏使用网站每篇导读已有的分类。按研究任务、研究方法等分面展开多级目录，选择父类可查看所属子类的收藏，论文卡片显示原分类路径。旧缓存缺少分类时先同步网站；分类暂不可核对时明确提示，不用平面标签猜测。

界面不再提供自建、重命名或手动归类。1.2.0 原有的个人分类字段留在资料与备份中，收藏时间也继续保留，详见[收藏说明](../../docs/favorite-collections.md)。

## Zotero 与坚果云

### 归档所选论文到 Zotero

Zotero 管理文献和附件。Android 通过官方 Web API 与 Zotero 服务通信，需要单独配置专用授权，不依赖 Mac 在线。确认目标文库、分类和所选材料后，分别保存书目、来源信息、PDF、导读、研究和笔记，再逐项读取回来核对。已有归档记录用于避免重复创建，并在中断后继续；远端用户修改受到保护。

Zotero 的书目同步与附件存储分别处理。个人文库可使用 Zotero Storage 或已配置的 WebDAV 文件服务，群组附件不使用 WebDAV。

Zotero Storage 空间不足时，可以明确确认改用本应用已配置的坚果云附件连接。原书目和 Storage 记录保留，新材料重新回读；更改连接或重启后需要重新确认。其他 Zotero 客户端须自行配置相同的附件同步方式。详见[Zotero 说明](<../../docs/android-zotero-research.md>)。

### 备份整个工作台到坚果云

坚果云研究资料保存整个研究空间的独立版本，支持取消、继续上传同一版本、选择版本、校验和确认恢复。默认目录为 `PaperDigest`，与 Zotero 附件目录分开。保存后的版本不会被后来的编辑覆盖，也不会自动合并两台设备的笔记；恢复时要明确选择需要的时点。

备份保留原件、文章版本、笔记、批注、研究输入、回答、用量与历史。模型密钥、连接密码、设备授权和两份本机响应完整性密钥不随备份迁移：这些材料属于设备自身，不能从另一台设备的备份接管授权或给旧响应重新签名。旧包恢复会保留原包，在有效研究空间中使用当前设备的完整性密钥。

备份经 HTTPS 传输，文件本身没有额外的端到端加密，应作为私人文件保管。字段、大小限制和恢复保护见[备份合同](<../../docs/android-cloud-contract.md>)。

## 本机构建

需要根项目要求的 Node、JDK 17、Android SDK 平台 37、Build Tools 36.0.0、NDK 27.2.12479018、CMake 3.22.1，以及 Mac 子项目锁定的 KaTeX 依赖。构建脚本使用已有 `JAVA_HOME`、`ANDROID_HOME`，也识别本机 Homebrew 路径，不修改全局设置。

以下命令从仓库根目录运行。第一条生成调试 APK，第二条运行主机测试与静态检查；它们不会替代下面的真实设备操作。`KaTeX` 是随包的公式排版依赖，不是模型服务。

```bash
./apps/android/build.sh :app:assembleDebug
./apps/android/test.sh
```

默认调试包输出到 `apps/android/app/build/outputs/apk/debug/app-debug.apk`。调试资源通道 `private-qa` 带有固定公开 MiCLA 小样；正式 `release` 通道只含空目录引导、排版资源和完整开源许可。两个通道的输出与清单分开，正式包不包含验收页面、用户资料、生产运行数据或 `.env`。

## 设备测试

使用自行创建、没有个人资料的专用验收模拟器。先核对 `adb devices` 和 AVD 名称，再将 `SERIAL` 换成所选设备的序列号：

```bash
./apps/android/install.sh SERIAL
./apps/android/test.sh --device SERIAL
```

安装和设备测试都必须明确指定一个序列号，也可通过 `ANDROID_SERIAL` 指定；未选择设备时直接停止，不会默认安装到旧模拟器。安装脚本仅定向该设备，先检查设备就绪，再核对模拟器名称 `PaperDigest_QA_API35` 或 `PaperDigest_QA_API28`；测试入口也只使用指定序列号。设备是否为空仍须执行者事先确认。请勿改用用户现有手机或研究模拟器，也不要向全部已连接设备派发测试。

正式发行核对源码、版本、签名、四种架构、16 KiB 对齐、许可、资源，以及实际新装和覆盖升级。16 KiB 对齐是安装包中原生库的布局要求，不代表已经在所有设备上实测。签名私钥与口令在仓库和发行包之外保存。下载入口使用本仓库实际发布的 [GitHub Releases](https://github.com/nanless/audio-paper-digest/releases)。逐项功能与验证范围见[功能表](<../../docs/android-feature-parity.md>)。
