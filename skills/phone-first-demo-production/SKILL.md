# 手机端产品演示制作

先确认交付物是视频、封面、发帖文案中的哪几件。分别记录用户最新确认的内容、顺序、平台名称、读法和必须删去的项目。做局部修订时复用已经通过的片段，沿时间线重查受影响的字幕、音频、转场和片尾。素材制作与向外部平台发布分别处理：封面和发帖文案只作宣传素材，不用于日更批次或文章配图；成稿交给用户自行发布，微信、飞书、小红书发布已退役，本 skill 不恢复这些发布流程。

## 何时使用与不适用

适合：

- 制作、改版或验收面向手机平台的产品演示短片、封面和发帖文案。
- 需要跨网页、桌面和手机实机录屏，处理竖屏可读性、分句配音、背景音乐和成品核对。

不适合：

- 自动发布到社交平台、账号登录、批量投放和平台运营；微信、飞书、小红书发布在本项目已经退役。本 skill 只做到用户可自行交付的素材与文案。
- 日更批次和文章配图。日更不生成封面，封面与发帖文案只作宣传素材。
- 版权素材的取得或授权判断。音乐、字体、影视片段、他人录屏和模型声音应当有可用许可，未确认的素材不能进入成片。
- 代替项目的发布授权、账号权限或平台规则审核。
- 把设备、素材或模型不可得时的抽帧、缩略图或旧版本当成实机与听感验收；这种情况只能如实记录实际检查范围。

## 实机录制与竖屏排版

- 把功能清单改写成能连续看懂的操作。记录每段从哪里开始、做什么动作、出现什么结果，以及哪些内容一定要看清。跨端声称展示同一条目时，对照标题和稳定编号。说明同步本身时，另外记录两个方向的实际操作及验证结果。
- 连续录制滚动、点击与页面反馈。优先在采集端调整窗口比例、缩放和阅读布局，先用手机预览代表性片段。宽屏双栏保住两列的边缘和关键内容。必要时在完整画面后接局部放大。连续的滚动应有稳定的速度，停留留给读者需要辨认的入口和动作。菜单、收藏状态、图和表都以观众能认出为准。
- 把标题、端别、字幕与重要控件分开放置。大段内容划分到相邻镜头，正文、提示和字幕各承担一个任务。按目标端播放器预览安全区。采用淡入淡出时检查转场两侧的点击、文字和句尾。画面展示与旁白都完成时进入下一镜。
- 封面用一套构图组织真实界面。挑能辨认的平台和功能画面，给标题足够空间。导出约 180 像素宽的缩略图检查标题、留白和画面辨识度。尺寸只是保守预检，有目标平台预览时再检查实际裁边。

## 配音、音乐与文案

- 用同一段目标语言脚本试听候选模型。样本应含真实语速、混读、易错专名和完整句尾。分别记录实际用的是本地推理、官方演示还是托管接口，以及模型、音色与费用依据。试音、正式成片和模型许可分别标明。榜单用于筛选，实际取舍依据同稿听感和读法。
- 用可单独替换的自然句或分句生成旁白，普通句直接读定稿。单独维护屏幕写法、口播写法和验收读法。全稿截断或跳词就回到分句生成。专名用局部重生成、读法提示或可控音节处理。逐句试听核对漏词、重读、声调、停连和句尾。自动转写只辅助查漏，不能核定多音字声调。修改声音后重校字幕和剪辑点。
- 用相同播放音量试听多条音乐候选。优先选择无抢耳人声、节奏稳定、与旁白频段冲突少的配乐。先听完整音乐，再听叠加旁白后的成品。用手机扬声器检查轻声句和专名能否听清。分开保留旁白和配乐轨。
- 发帖文案独立写。第一句讲清谁能用它完成什么，选能证明用途的功能和一条具体路径。标题说清主题，正文用实际能力和前提，删掉编造场景、画面复述和大段操作手册式步骤。按用户要求研究平台范例时，优先查看可核对的真实帖子或作者公开的数据，区分观察、推测与已验证结果。单篇案例可用于判断写法，不能保证传播效果。

## 交付验收

1. 将原始录屏、最终口播稿、读法表、分段音轨、封面源文件和时间线按版本留存。输出清单逐项指定最终视频、字幕、封面与发帖文案。分镜稿如仍需保存，明确其用途。对齐已审稿、导出文件与用户实际收到的版本。
2. 检查编码、画幅和音视频流，完整解码导出文件。确认字幕时间按顺序，逐一查看起止、转场、点击结果、末尾完整地址与下载指引。导出失败时保留工程、时间线、分段音轨和上一版成片，读取编码器、磁盘和权限的实际错误；修正后重新完整导出并重新解码核对，不能把上一版文件当作本次成片交付。
3. 尽量在目标手机上播放最终文件，检查网页和桌面字号、真实滚动、手机控件、字幕安全区、片尾停留及声音。平台预览和本地播放分开记录。手头只能检查缩略图、抽帧或前一版时，如实标明验证范围。
4. 核对录屏和最终输出中可见的个人资料、账号和通知。检查开源声明、模型与音乐许可、下载入口和平台适用条件。确认封面文字按当前要求保留，最后再打开清单中每份文件确认。

## 交付前检查清单

- [ ] 交付物清单逐项对应最终视频、字幕、封面和发帖文案，并与用户实际收到的版本一致。
- [ ] 导出文件完整解码，编码、画幅、帧率和音视频流符合目标平台。
- [ ] 字幕起止和顺序正确，转场、点击结果、片尾完整地址与下载指引都已查看。
- [ ] 已在目标手机播放；无法实机时写明只做了抽帧、缩略图或本地播放。
- [ ] 画面和旁白中的个人信息、账号、通知已检查，开场与片尾没有遗留。
- [ ] 开源声明、模型与音乐许可、素材来源和下载入口可核对；未授权素材没有进入成片。
- [ ] 配音模型、音色、运行方式（本地或托管）和费用依据已记录，试音与成片使用同一音色。
- [ ] 封面在约 180 像素宽缩略图下可读，成片、封面和文案的标题与核心说法一致。
- [ ] 发帖文案独立成稿，没有编造使用场景、传播效果或平台数据。
- [ ] 导出失败或设备不可用时保留原工程与错误记录，修复后重做受影响的检查。
