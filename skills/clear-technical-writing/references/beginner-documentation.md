# 面向初学者的文档

用于操作说明、领域教程、项目手册和研究长文。完整解释由读者需要和实际材料决定，不按固定字数扩写，也不把每篇文章变成相同模板。

## 先建立读者可以理解的对象

让读者先知道要解决什么问题、手上有什么、最后会得到什么。项目文档说明它属于阅读应用、内容生产、维护还是设计；使用应用的读者不应先学习服务器凭据或发布协议。

需要前置知识时，在当前动作前解释最小必要概念，或给出明确的前置阅读位置。不能一边使用新词，一边让读者到章节末尾才找定义。重要对象先说作用，再给正式名称；已经定义的名称统一使用。

按读者的任务说明模块之间的关系。不要只列目录、脚本名、缩写或参数，让读者自己猜哪个接收上一步的什么结果。说明真实输入、发生的动作、保存位置和成功后的下一步。

## 展开中间步骤

讲原理时，把输入经过关键步骤变成输出的过程写完整。每步说明它改变了什么，以及下一步为什么能使用这个结果。复杂公式或算法分步解释符号和变换，必要时给有明确假设的小例子。

讲操作时，将准备条件、动作、正常结果和失败后的继续方法分清。命令示例标明需要替换的日期、编号或路径；例子不冒充可直接使用的真实任务材料。说明哪些动作只读取、哪些会写入或调用付费服务，范围以任务实际规则为准。

讲限制时，先说它限制什么，再说明读者应怎样处理。内部错误码可以保留以便定位，但不能代替解释。判断“已经完成”时写明实际证据，区分修改、检查、保存、推送、部署和网页可读。

讲技术取舍时，同时说明好处、代价和适用条件。缺少测量数据就写机制或预期，不能为了让解释具体而补造数字、设备、用户经历或实验。

## 段落与层次

一段围绕一个问题展开，句子之间有清楚的因果、条件、顺序或解释关系。段落长度不设配额；能连起来的意思连起来，切换职责或结论时另起一段。

以下情况通常需要明显分开：

- 背景与实际操作。
- 正常流程与例外恢复。
- 实测结果与原因推测。
- 当前实现与后续计划。
- 历史验证与本次新验证。
- 通用规则与只在特定对象上生效的例外。

区分可以使用段落、具体小标题、编号或并列列表，按内容选择。不能把必要条件拆开后，让读者误以为每条都能单独授权动作。长规则分组时，在引导句中明确共同条件和适用对象。

执行顺序用编号；真正并列的对象用列表；同类对象的多个可比属性用表格；连续推理和机制说明用段落。表格单元格不塞入整套操作规程，代码围栏不承担解释段落的作用。

标题说明这一部分解决的实际问题，层级逐级推进。维护旧文档时检查已有锚点和外部引用；可以保留旧锚点，让更清楚的新标题继续承接原链接。

## 中文、术语与翻译

中文叙述用中文的句法和常用词，不把英文名词堆成句子。下面的表达只用于编辑判断，不能全局替换所有同形词：

| 原表达 | 先确定实际意思，再选择写法 |
|---|---|
| Reader-only child | 仅重写论文解读长文的子运行；首次解释它保留哪些原结果 |
| tail set 已闭合 | 本轮剩余的失败论文已处理，或各项对应关系已核对；按真实状态区分 |
| 冷核采纳 | 从保存的原文件重新核验，通过后再保存为正式结果 |
| CAS 漂移 | 写入前发现原稿已改变，程序停止以免覆盖新结果 |
| stage 后 publish | 若 stage 指页面暂存，就写“暂存页面，审查后发布”；若指模型阶段，应另作解释 |

数学上的投影、控制中的闭环等有准确含义，不因词形相同就删去。解释程序中的临时视图时，不能靠“投影”二字让读者猜它是否改写原数据。

保留产品名、机构名、模型名、程序名、变量和字段的准确拼写。只有读者需要对应原资料时才附英文；首次说明后用统一的中文称呼。一个中文概念不轮换多个英文近义词，一个英文多义词也不强行统一译成同一个中文词。

解释精确术语时，保留它真正约束的性质。例如，“原子保存”不只是“完整保存”：它还要求规定范围内的读取者看不到半份新状态。可以补一句白话说明，但不能用宽泛的好听词替换并丢掉技术含义。同样，禁止请求、只读访问、原字节保留和预算不增加都要按原范围表达。

翻译先核对定义和场景，再选择本领域已有的自然译法。没有可靠通行译名时，保留原名并用一句话解释作用，不发明生僻词，也不假称某译名是标准名称。

## 复审读者能否独立理解

沿读者实际任务读一遍，检查每一步是否知道使用哪个输入、为什么做、会得到什么、失败后怎样继续。不能依赖作者掌握的聊天背景解释文件里的省略。

核对来源、技术身份、数字、单位、否定、归因、并且或或者的关系和确定程度。删除一段前确认没有删掉必要条件；补充一段后确认没有把合理解释写成已验证事实。

独立审阅者指出具体无法理解的句子、缺失的中间步骤、错误翻译或混合短语，再按实际问题修订。最后重读修改处前后，检查段落、空行、标题、列表和链接；不能靠“禁词为零”代替这项阅读。
